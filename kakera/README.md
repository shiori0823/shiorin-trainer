# ★ 時間の内訳（受講生5名・90日）

「時間がない」の原因は、内容の多さではありません。

| | 時間 | 割合 |
|---|---|---|
| Zoom講義 6回×90分 | 9時間 | 9% |
| 個別セッション 3回×5名 | 15時間 | 15% |
| **朝活LIVE 毎日×90日** | **45時間** | **45%** |
| **オープンチャット 1日20分** | **30時間** | **30%** |
| 合計 | 約100時間 | |

※個別60分・朝活30分と仮定

> **お金をもらっている講義と個別が、時間の24%。**
> **無料で付けている朝活とチャットが、76%。**

**朝活とチャットは、人数が増えても時間が変わりません。**
5人でも20人でも45時間です。つまり**人を増やすほど割が良くなる**部分でもあります。

# ★ 朝活LIVEについて

## ① コンセプトと矛盾しかけている

この講座が壊しにいっているのは「またできなかった」という感情です。

**「毎日の朝活LIVE」は、参加できなかった日に「またできなかった」を生みます。**

やめる必要はありません。**1日目に言い切ってください。**

> 朝活は、来られない日があって当たり前です。
> **来られなかった翌日に戻ってくることが、この講座の練習そのものです。**

こうすると、朝活が**「戻れる私」のいちばん良い練習場**になります。
Lesson4でやることを、毎朝実地でやることになります。
**矛盾が、いちばんの強みに変わります。**

## ② これがバックエンド（継続課金）そのもの

`funnel/README.md` で「あとで作る」としていた月額のフォロー会は、
**すでに朝活として存在していました。**

```
90日の受講生　… 朝活は受講料に込み
卒業生　　　　… 月額（3,000〜5,000円）で継続参加
```

45時間が5人のためだけでなく、**卒業生全員のため**になります。
**いちばん時間を食っている部分が、いちばん資産になります。**

**1期生が終わった時点で始められます。**卒業生が溜まるのを待つ必要はありません。
