# ★ 「痩せてなくてもいい」を、どこで言うか

栞さんの言葉。

> ただ何キロ痩せるとか、痩せてなくてもいいなと思ってる

**これが商品の芯。ただし、そのまま入口で言うと「痩せない講座」に聞こえる。**
言う場所を分ける。

## ① 入口（案内・広告）

```
ダイエットが続かないのは、
やり方を知らないからではありません。
```

痩せたい人を否定せずに拾う。**ここで「痩せなくていい」とは言わない。**

## ② 来た人に、早い段階で

```
体重が何キロ落ちたかは、見ません。

見るのは、
「自分で決めたことを、何回やれたか」です。

結果として、ほとんどの方が落ちます。
でも、落ちなかった90日も、失敗ではありません。
```

**「見ません」と言い切る。** 「あまり重視しません」だと逃げに聞こえる。

## ③ 順番を言い切る

```
痩せたから、自信がついたのではありません。

自分で決めたことを続けられたから、自信がついた。
その結果として、体も変わっていきました。

だからその自信は、ダイエット以外にも使えます。
```

**「痩せる→自信」ではなく「続けられた→自信→体」。**
この順番だから、痩せなくても成立する。
