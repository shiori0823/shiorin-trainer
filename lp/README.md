## 申込みリンク（CTA）

ページ内4か所（ファーストビュー / 無料個別相談 / 最終CTA / 追従バー）から
同じURLへ遷移します。

```
https://mosh.jp/services/a83404f4de13474387bddb855afa44d5?openExternalBrowser=1
```

変更する場合は `index.html` 内の上記URLをすべて置換してください。

```sh
cd lp
sed -i 's|https://mosh.jp/services/[^"]*|新しいURL|g' index.html
```

## デザイン

- カラー：白 `#FFFFFF` / ワインレッド `#7A1524`（濃 `#540E19`・明 `#A02236`）/ 黒 `#141416`
- 書体：Noto Sans JP（本文・見出し）、Zen Old Mincho（引用・情緒的なコピー）、
  Oswald（数字・英字ラベル）— Google Fonts から読み込み
- 白 → 黒 → 生成り → 黒 と背景を交互に切り替え、写真の入るセクションを
  区切りとして使っています

## 文言の修正

すべて `index.html` の本文にベタ書きしています。該当箇所を直接編集してください。
セクションは `<!-- ============ 01 悩み ============ -->` のようなコメントで
区切っています。

## 動作について

- JavaScript は「スクロール表示アニメーション」「追従CTAの出し入れ」
  「画像が無いときのプレースホルダー表示」のみに使用。無効環境でも全文読めます
- FAQ は `<details>` 要素なので JavaScript なしで開閉します
- 画像が未配置でもレイアウトは崩れません
