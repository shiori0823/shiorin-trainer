# 写真について

LPで使っている写真です。差し替えるときは、**同じファイル名**で上書きすれば
そのまま反映されます（`index.html` を編集する必要はありません）。

| ファイル名 | 今入っている写真 | 使われている場所 |
|---|---|---|
| `hero.jpg` | スクワットのボトム（セコンドあり） | ファーストビュー全面 |
| `case.jpg` | スクワットのラックアウト | 「余裕で全国大会にいける」のセクション |
| `coach-1.jpg` | ジムでの一枚 | 講師プロフィール（大） |
| `coach-2.jpg` | 表彰台 | 講師プロフィール（小・左） |
| `coach-3.jpg` | デッドリフト | 講師プロフィール（小・右） |
| `closing.jpg` | デッドリフト（`coach-3` と同じ写真） | クロージング背景 |

`closing.jpg` だけ `coach-3.jpg` と同じ写真を使っています。別の写真に変えたい
場合は、`closing.jpg` を差し替えてください。

## 差し替えるときの目安

- 拡張子は `.jpg`。長辺 1600〜1800px、1枚 300KB 以下だと表示が軽くなります
- `hero.jpg` と `closing.jpg` は上に文字が重なるので、横長の写真が向いています
- 写真が無い状態でも、レイアウトは崩れずプレースホルダーが表示されます

## 写真の見え方の調整

トリミング位置は `index.html` の CSS の `object-position` で決めています。
「顔が少し切れる」「もう少し右に寄せたい」といった場合はここを調整します。

| 調整したい写真 | 該当する行 |
|---|---|
| `hero.jpg` | `.hero__media img{object-position: … }`（スマホ用）と、`@media(min-width:760px)` 内の同じ指定（PC用） |
| `coach-1.jpg` | `.prof__media .ph:first-child img{object-position: … }` |
| `closing.jpg` | `.close__media img{object-position: … }` |

左の数字が横方向、右の数字が縦方向です。数字を小さくすると、写真が
右／下にずれます。

## 受講された方の声

| ファイル名 | 今入っている写真 | 使われている場所 |
|---|---|---|
| `voice-kenny.jpg` | ケニーさん（ジムでの笑顔・800×800にトリミング済み） | 「受講された方の声」の名前の横（丸く切り抜かれます） |
| `voice-kenny-meet.jpg` | 試合でのデッドリフト（広島・83kg級） | 「一番変わったのは…」の引用の左（PCは横並び、スマホは上下） |

丸く表示されるので、**顔が中央にくる正方形**に近い写真だときれいに収まります
（推奨：正方形 1:1、長辺 600px 以上）。未配置の場合はワインレッドの丸が
表示され、レイアウトは崩れません。

元データ（`IMG_8682.JPG` など）は容量が大きいのでリポジトリには置いていません。
トリミングをやり直したい場合は、元の写真をもう一度アップロードしてください。
