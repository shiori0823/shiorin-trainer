# 写真の配置

LPは以下のファイル名で画像を読み込みます。
このフォルダに同じ名前で置くだけで反映されます（未配置でもレイアウトは崩れず、
ワインレッドのプレースホルダーが表示されます）。

| ファイル名 | 使う場所 | おすすめの写真 | 推奨比率 |
|---|---|---|---|
| `hero.jpg` | ファーストビュー全面 | スクワットのボトム（セコンド付き） | 横長〜正方形（3:2 / 4:3） |
| `case.jpg` | ケース（全国大会）のセクション | バーをラックアウトして構える一枚 | 縦 4:5 |
| `coach-1.jpg` | 講師プロフィール（大） | ベンチ台へ向かう縦の一枚 | 縦 4:5 |
| `coach-2.jpg` | 講師プロフィール（小・左） | 表彰台の一枚 | 正方形 1:1 |
| `coach-3.jpg` | 講師プロフィール（小・右） | デッドリフトのロックアウト | 正方形 1:1 |
| `closing.jpg` | クロージング背景 | デッドリフトのロックアウト（`coach-3` と同じでも可） | 横長 |

- 形式は `.jpg`（`.jpeg` や `.png` を使う場合は `index.html` の `src` も書き換えてください）
- 長辺 1600〜2000px 程度、1枚 300KB 以下を目安に書き出すと表示が軽くなります
- `hero.jpg` と `closing.jpg` は上から暗いグラデーションが重なるため、
  被写体が中央〜下寄りに来るものが向いています
