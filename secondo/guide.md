# ★ 聞き方の原則

第1回セミナーで分かったこと。

> **質問があれば書ける。なければ止まる。**

なので、**「どう思いますか」で止めない。必ず選択肢を出す。**

| ❌ 聞かない | ⭕ 聞く |
|---|---|
| 失敗したらどうなりますか | 前の試合で失敗したとき、どうでしたか |
| どんな言葉が嫌ですか | 「大丈夫」って言われたら、どう感じますか |
| どうなりやすいですか | （シートの選択肢を読み上げて）どれが近いですか |

**過去形で聞くと答えやすくなります。** 「どうなりますか」は想像ですが、
「前はどうでしたか」は事実なので、思い出すだけで済みます。

# 山ピーさん用に、用意しておくこと

## ① 1本目の話（ここから入る）

本人の言葉：**「ダウンセットは1・2rep目だけ浅くなる傾向」**

重いときではなく、**軽いとき。しかも最初の1本。**
試合の第1試技も、その日のいちばん最初の1本。

聞くこと：

```
・ダウンセットで浅くなるのは、重量のせいだと思いますか？
　それとも、レップの1本目だからだと思いますか？

・浅くなったとき、自分で気づいていますか？　あとで言われて気づきますか？

・アップの中で、深さを確認する本があるとしたら、どこに入れますか？
```

**ここで「1本目の前にやること」が1つ決まれば、この60分の元は取れています。**

## ② 成功したときのブレーキ

本人の言葉：**「ぶっちゃけもっといけるやろーって気持ち」**

これは強みですが、**1本目が通った直後がいちばん危ない**です。

```
・1本目が軽く上がったとき、2本目を予定より上げたくなりますか？
・上げていい条件を、先に決めておきませんか？
```

シート1枚目の「成功したら → 」に書き込む。

## ③ 宿題の続き

100点をどこに置くかは、**まだ出し切っていません。**

650kgは試合ベスト（610kg）から+40kg。
レップベスト（SQ 200×8／BP 135×8／DL 222.5×5）から換算して、
**100点と80点を確定させる。**

**試技の重量は、そこから逆算します。** だから先にここを片づける。
