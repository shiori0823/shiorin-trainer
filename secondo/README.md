# セコンド指示書

試合当日、セコンド（ハンドラー）についてくれる人に渡す2枚。

| | |
|---|---|
| `sheet.html` | 中身。ここを直す |
| `build-pdf.py` | PDFに書き出して、はみ出しを検査する |
| `secondo-sheet.pdf` | 配布用（A4×2） |
| `guide.md` | **60分で一緒に埋めるときの進行メモ** |

## なぜ作るか

セコンドは、メンタルをいちばん支える人です。
でも**何も渡さないと、その人の勘に頼ることになります。**

特に、移籍・転勤などで**セコンドが誰になるか分からない**選手には効きます。
書いて渡しておけば、**誰がついても同じ動きをしてもらえます。**

## 2枚の役割

| | |
|---|---|
| 1枚目 **段取り** | 試技の重量、変えるルール、アップの段取り |
| 2枚目 **私は、こうなります** | 台に向かう前／成功したとき／失敗したとき／言葉 |

**本体は2枚目です。**

1枚目は、本人が一人でも埋められます。
2枚目は、**自分がどうなりやすいかを言葉にする**ところなので、一人では書けません。
ここが60分の中身になります。

### ★ いちばん価値があるのは「かけてほしくない言葉」

「大丈夫」「落ち着いて」は、人によっては逆に効きます。
**書き出している選手は、ほとんどいません。**

## 選択肢を先に印刷してある理由

第1回セミナー（9/26）で分かったこと。

> **「10個書いてください」では止まる。質問を出したら書けた。**

なので、このシートは**質問に選択肢を添えてあります。**
「どうなりやすいですか」だけだと、手が止まります。

## 作り直しかた

```
python3 build-pdf.py
```

A4に収まっているかを検査します。**両方OKが出なければ配らないでください。**

**このリポジトリは公開されている。**

# 1人目で分かったこと（2026-10-03）

**空欄シートを一緒に埋める形にはならなかった。**
60分の会話から、こちらが書き起こして渡す形になった。

```
想定　→　シートを画面共有して、本人が埋める
実際　→　話を聞いて、こちらが4枚に書いて渡す
```

**この形のほうがいい。** 本人は自分の不安を言葉にできるが、
それを紙の形に整理するのは、別の作業だった。

## 4枚の構成（型になった）

| | 中身 |
|---|---|
| 1枚目 | 狙う数字（根拠つき）／先に確認すること／当日の朝の段取り |
| 2枚目 | 体調を落とさないための期間の過ごし方 |
| 3枚目 | 種目ごとの「崩さないもの」 |
| 4枚目 | **セコンド指示書**（お願いすること／しなくていいこと／言葉） |

### ★ 4枚目は「断る紙」ではなく「頼む紙」

1人目は**セコンドをつけない**という結論になった。
ただ当日「つきましょうか？」と言われると、断りにくい。

```
「ベッタリつかないでください」　→　言えない
「ここだけお願いします」　　　　→　言える
```

**頼む範囲を先に決めれば、断らなくて済む。**
→ これは誰にでも使える。4枚目は型として残す。

### ★ かける言葉は「事実だけ」

```
✗ 「大丈夫？」「いけるよ」　　→　良かれと思って言われるが、プレッシャーになる
✗ 事情を知らない人のアドバイス　→　自分と違う意識のことを言われると崩れる
◯ 「ここを握っていた。左右で位置が違った」
◯ 「ここまでは入っていた。それ以上は入っていなかった」
◯ 分からないときは、何も言わない
```

**「こうすればいい」ではなく「こう見えた」。** ここが指示書の芯。
