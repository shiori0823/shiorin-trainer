# セコンド指示書

試合当日、セコンド（ハンドラー）についてくれる人に渡す2枚。

| | |
|---|---|
| `sheet.html` | 中身。ここを直す |
| `build-pdf.py` | PDFに書き出して、はみ出しを検査する |
| `secondo-sheet.pdf` | 配布用（A4×2） |
| `guide.md` | **60分で一緒に埋めるときの進行メモ** |

## なぜ作るか

セコンドは、メンタルをいちばん支える人です。
でも**何も渡さないと、その人の勘に頼ることになります。**

特に、移籍・転勤などで**セコンドが誰になるか分からない**選手には効きます。
書いて渡しておけば、**誰がついても同じ動きをしてもらえます。**

## 2枚の役割

| | |
|---|---|
| 1枚目 **段取り** | 試技の重量、変えるルール、アップの段取り |
| 2枚目 **私は、こうなります** | 台に向かう前／成功したとき／失敗したとき／言葉 |

**本体は2枚目です。**

1枚目は、本人が一人でも埋められます。
2枚目は、**自分がどうなりやすいかを言葉にする**ところなので、一人では書けません。
ここが60分の中身になります。

### ★ いちばん価値があるのは「かけてほしくない言葉」

「大丈夫」「落ち着いて」は、人によっては逆に効きます。
**書き出している選手は、ほとんどいません。**

## 選択肢を先に印刷してある理由

第1回セミナー（9/26）で分かったこと。

> **「10個書いてください」では止まる。質問を出したら書けた。**

なので、このシートは**質問に選択肢を添えてあります。**
「どうなりやすいですか」だけだと、手が止まります。
