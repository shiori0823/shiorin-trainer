# 能力が最大限に出る働き方（2026-10-28）

`strategy/core.md`（やっていること）と `strategy/who.md`（誰に何を）の続き。
**どういう形で働くと、いちばん力が出るか。**

---

# 1　先に、いちばん弱いところ

```
集客
```

**提供は強い。集客が弱い。** これは記録がはっきり示している。

| | |
|---|---|
| セミナー第1回 | 6日告知して3名 |
| 5DAYS | 2週間告知して4名（みゆきさん側0名） |
| 一般レーン | 診断から4名 |
| 法人の「話」 | 2件。相手から出てきた。**ただし契約はゼロ**（2026-10-28時点） |

**自分で集めようとした場は、いちばん小さい。** ここは事実。

**ただし「法人は向こうから来る」とまでは、まだ言えない。**
話は2件出たが、**どちらもまだ契約になっていない。**（2026-10-28 訂正）

---

# 2　だから、答えは1つ

```
すでに人が集まっている場所に、自分を置く
```

**人を集める仕事を、できるだけ持たない。**
集めるのが得意な人・場所と組んで、**自分は中身に全部使う。**

---

# 3　力が出る形（上から順）

## ① 法人・団体に、継続で入る　★ いちばん合う

```
クラブチーム、実業団、学校の部活、他のジム
```

| | |
|---|---|
| 集客 | **ゼロ。** 相手がすでに人を持っている |
| 継続 | **ある。** 変化を見られる |
| 人数 | 相手が区切ってくれる |
| 報酬 | **枠で固定。** 相手の集客に乗らない |

**月額伴走サポートが、まさにこの形。**

### なぜ合うか

```
その場で数字を出して、組み替えて返す　→　得意
継続して、変化を見る　　　　　　　　　→　できたのかけらが積み上がる
自分も競技者である　　　　　　　　　 →　根拠になる
```

**年間契約が理想。** 月1回×12回。大会前に厚く、オフに薄く。

## ② ジムの中

```
夫が集めた会員に、自分が届ける
```

**集客ゼロ。** 90日伴走プログラムがこれ。

**岡山に限られるのが、唯一の弱点。**

## ③ 呼ばれて、出る

```
助産院のイベント。他団体の講習会。
```

**集客ゼロ。単発。** 継続がないので、変化は見られない。

**ただし、ここで会った人が①につながることがある。**
**断らないほうがいい形。**

## ④ プロデュース（条件つき）

**相手が、すでに人を持っている場合にかぎる。**

```
専門性がある　＋　届ける相手がいる　→　成立する
専門性がある　＋　届ける相手がいない →　こちらが集客を背負う
```

みゆきさんの件は、**後者に近い。**（5DAYSで0名だった）
だから初回は実績づくりとして受けた。**2件目から、ここを見る。**

### 選ぶときの3つの質問

```
① 個別に声をかけられる人が、何名いますか
② その人たちに、これまで何かを売ったことがありますか
③ 届ける気はありますか（つくるだけで満足していないか）
```

**③がいちばん大事。** 専門性があっても、届ける気がない人とは成立しない。

## ⑤ 自分で集めて、売る

```
note、LP、LINE、SNS
```

**いちばん苦手。** でも、ゼロにはできない。

**唯一これが要るのは、ベーシック教材（49,800円）。**
岡山にも時間にも縛られない商品は、これだけだから。

**ただし、ここに時間を多く置かない。**
①〜③で埋めて、**余った時間で書く**順番にする。

# 4　向いていない形

| | なぜ |
|---|---|
| **大人数へのセミナー（50名以上）** | 一人ずつ数字を出して返せない。**7人目から別のセミナーになる** |
| **報酬が相手の集客に乗る契約** | 中身は完璧でも0円になりうる。**自分で制御できない** |
| **一から教える／つくってあげる仕事** | やっているのは「すでにあるものを使えるようにする」こと |
| **無料で集めて、あとで売る形** | 自分で集めるのが弱い。**無料にしても集まらない**（2026-10-26 決定） |

※ 50名以上を断る必要はない。**その月の枠を全部使う前提で受ける**（月額伴走に明記済み）。

---

# 5　一言でまとめると

```
人を集めてくれる相手と組んで、
少人数に、継続で、時間ぶんの固定報酬で入る
```

**これが、いちばん力が出る形。**

```
①　相手が人を持っている　→　集客しなくていい
②　少人数　　　　　　　 →　一人ずつ返せる
③　継続　　　　　　　　 →　変化が見える
④　固定報酬　　　　　　 →　中身に集中できる
```

**4つ全部そろっているのが、月額伴走サポート。**
だから、あれを増やすのが本筋。

# 6　来年に向けて、増やすとしたら

```
いま　オーナー／ケニーさん　＝　2者
```

**同じ形を、もう1〜2者。**

探す先は、この順。

| | |
|---|---|
| 1 | **呼ばれて出た場で会った人**（助産院のような場） |
| 2 | **ケニーさん・オーナーからの紹介** |
| 3 | 岡山のクラブチーム・高校の部活 |

**話が出た2件は、どちらも知り合い経由。**
ただし契約には至っていないので、**この道が通るかどうかは、まだ分からない。**

**まず1件を契約まで持っていく。** 道があると言えるのは、そのあと。

```
「同じことを、ほかでもやっています」と言える状態をつくる
　→　5か月の記録が、それになる
```
