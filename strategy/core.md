# やっていることは、全部同じ（2026-10-28）

本人の言葉。

> そうそう、同じなんですよ。いつも同じことをやっている。
> 夫と一緒にやっているウエイトトレーニングジムでも同じことです。

---

# 一言

```
人がすでに持っているものを、使える形にする
```

**足りないものを足していない。** どの仕事でも。

---

# 同じ構造が、4か所にある

| | 相手が持っているもの | 困っていること | すること |
|---|---|---|---|
| **選手** | 技術・練習量 | **本番で出せない** | 当日の判断を減らす。決めたことをやる形にする |
| **ジムの会員** | 動ける体 | **続かない／正しく使えていない** | 正しく立つ。できたことを数える |
| **みゆきさん** | 専門性・想い | **商品として伝わらない** | 問いを渡して、本人に決めさせる |
| **できたのかけら** | できていること | **本人に見えていない** | 10個書き出す。「当たり前」を禁止する |

**全部、同じことをしている。**

```
新しく足す　→　やっていない
すでにあるものを、見えるようにする　→　これだけ
```

---

# だから、「できたのかけら」が中心にある

商品の1つではなかった。**やり方そのものの名前だった。**

```
できたのかけら　＝　すでにあるものを、見えるようにする方法
```

だから、独立展開をやめても消えない。
**90日伴走の節目にも、5DAYSにも、選手のシートにも、同じものが入っている。**

# 2本柱の心配について

`strategy/README.md` で、みゆきさんの案件を「2本柱の外」と書いた。
**形としては外。でも、中身は同じ。**

```
事業が3つある　→　ちがう
相手が3種類いる　→　こちら
```

| | 相手 |
|---|---|
| ① | スポーツの法人・団体 |
| ② | ジムの会員 |
| 例外 | 専門を持っている個人 |

**やることは1つ。渡す相手が変わるだけ。**

だから「気づいたら3本目」にはなりにくい。
**散らかるとしたら、やり方が変わったときだけ。**

# 使いみち

## 自己紹介が、1行で済む

```
×　メンタルトレーナーで、パワーリフターで、ジムもやっていて、プロデュースも
○　人がすでに持っているものを、使える形にする仕事をしています
```

**肩書きを並べると、何屋か分からなくなる。**（`mosh/profile.md` で指摘したのと同じ）

## 法人に出すときの、最初の1行になる

```
選手に足りないものを足すのではなく、
すでにできていることを、本番で使える形にします。
```

**「メンタルを強くします」より、何をするのかが伝わる。**

## 迷ったときの判断基準になる

```
この仕事は、相手がすでに持っているものを使えるようにする仕事か
　　はい　→　やっていい
　　いいえ（一から教える・つくってあげる）　→　たぶん向いていない
```

**マナー講座の監修を断ったのは、正しかった。**
あれは「つくってあげる」側の仕事だった。
