# 数字を見た（目標配分であって、予測ではないという前提で）

## 法人600万円

例として挙がっているのは `30万×20件／60万×10件／100万×6件`。

**いま法人案件は2件。どちらも営業ではなく、相手から出てきたもの**（`b2b/README.md`）。
**待ちのまま20件は埋まらない。**

```
単発20件を追う　→　毎回ゼロから探す
継続2〜3社　　　→　1件決まると12か月分
```

**継続のほうが、1〜2月に仕事量を抑える前提と噛み合う。**
単発は日程が相手都合で動く。継続は月の時間を自分で置ける。

### いちばん効く1つの数字

```
月額伴走サポートの、2027年4月からの本運用価格
```

試験運用はいま **月55,000円／月5時間**。知り合い限定・期間限定と明記済み。

| 本運用の月額 | 2社 | 3社 |
|---|---|---|
| 10万円 | 240万 | 360万 |
| 15万円 | 360万 | 540万 |
| 20万円 | **480万** | 720万 |

**20万×2社＋単発数件で600万に届く。** 20件より、2社のほうが近い。

## ジム内400万円

**ここは、こちらの読みが外れていた。**（10/16 本人より）

3か月98,000円を売る形ではなく、**オーナーとの共同商品がすでにある。**
それを売って、**配分する。**

配分があるということは、**「自分の400万」に必要な売上が、400万とは限らない。**
→ `strategy/verify.md` の「1,000万が何の数字か」へ。

## 自分の動きは、3つに絞られた

```
① ジムの会員を集める
② ジムの中でパーソナルを受ける人を増やす
③ 企業・チーム研修を、収入の柱にする
```

**③だけが配分のない収入。** だから「柱にする」は構造として正しい。
**①は②の母数。** 単体の売上では見ない。

# 3日以内に決めること（10/19 5DAYS開始）

## 5日目に、どこへ案内するか

`funnel/front.md` の5日目の文面は、90日講座へ案内する形になっている。**使えない。**

**いちばん無理がないのは、個別相談30分で止めること。**

```
5日間、おつかれさまでした。

初日に「5日後こうなっていたい」を1つ決めてもらいました。
今日、確かめてもらったところです。

ここから先をどうするかは、人によって違います。

一度30分、個別でお話しする時間を無料でお渡ししています。
受けたからといって、何かに申し込む必要はありません。

気になる方は、あとでお送りするリンクから取ってください。
```

**商品名を出さない。** 出すものが決まっていないから。
相談の中で、その人に合うものを出せばいい。**4名なら、それができる。**
