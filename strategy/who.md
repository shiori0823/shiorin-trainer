# 誰に、何を届ける仕事か（2026-10-28）

`strategy/core.md` の続き。
**やり方**は分かった。次は、**誰に**と**何を**。

---

# 誰に

```
やっていないのではなく、
やっているのに、手応えがない人
```

## これまでの相手を、並べてみる

| | その人は | でも |
|---|---|---|
| 山ピーさん・ケニーさん・ひなのさん | 練習している | **本番で出せない** |
| もっちさん | 毎日やっている | **できたことが、自分で見えていない** |
| ジムの会員 | 通っている | **続かない／変化が分からない** |
| みゆきさん | 20年やってきた | **商品として伝わらない** |
| 5DAYSの4名 | 仕事も家庭も回している | **自分のことが、後回しになっている** |

**一人も「何もしていない人」がいない。**

## 90日講座に、すでに書いてあった

```
仕事や家庭はこなしているのに、
自分のために前進している実感がない
```

**これがそのまま答えだった。**（`funnel/README.md`）

## 届けていない人

```
これから始める人
やり方を教えてほしい人
一から作ってほしい人
```

**ここは別の仕事。** 向いていない、という話ではなく、**やっていることが違う。**

マナー講座の監修を断ったのも、同じ線の上にある。

---

# 何を

```
やってきた事実を、使える形にして返す
```

## 渡しているものは、3つしかない

### ① 決めておくことを、決める

当日の自分に判断させない。
第一試技の重量。やらないこと3つ。朝の15分。

**考えることを減らす。**

### ② できたことを、数える

できたのかけら。10個書き出す。「当たり前」を禁止する。
80点・100点・120点。

**見えていないものを、見えるようにする。**

### ③ 答えではなく、問いを渡す

「それはなぜ？」
「お客様はどう変わる？」
「今日の私、どうしたい？」

**本人に決めさせる。**

---

# その結果、何が起きるか

本人が、企画書にこう書いている。

```
「できると思い込む」のではなく、
これまでやってきた事実を根拠に、自分を信頼できる状態
```

**これが、売っているものの正体。**（`gym/README.md`）

```
自信をつけさせる　→　やっていない
事実を見せる　　　→　これ
```

---

# 一文にすると

```
やっているのに手応えのない人に、
やってきた事実を使える形にして返し、
自分を信頼できる状態をつくる仕事
```

## 短い版（自己紹介用）

```
すでにやっている人が、
自分のやってきたことを使えるようにする仕事をしています
```

## もっと短い版

```
「できている」を、見えるようにする仕事
```

**中身は同じ。入れ物が違うだけ。**

| | 相手 |
|---|---|
| 大会前の設計・セコンド | 選手 |
| 90日伴走 | ジムの会員・選手 |
| 研修・講演 | 法人・団体 |
