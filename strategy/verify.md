# 1,000万円を検証する（2026-10-16）

**いまの1,000万円は、やりたい目標であって、積み上げた数字ではない。**
ここを正直に置いたうえで、何が分かれば現実になるかを並べる。

---

# 0　はっきり決まっていること

```
① できたのかけらの独立展開　→　進めない
② ダイエット・コーチング　　→　ジムのサービスにする
③ 自分の動き　→　ジムの会員を集める
　　　　　　　　ジムの中でパーソナルを受ける人を増やす
　　　　　　　　企業・チーム研修を、収入の柱にする
```

**ここは動かない。以下は、この3つで1,000万に届くのかという話。**

---

# 1　先に決める1つ　──「1,000万」が何の数字か

これが決まらないと、何を計算しても意味が変わる。

| | 意味 | 1,000万の重さ |
|---|---|---|
| A　生み出した売上 | 自分が動いて立った売上。配分前 | 軽い |
| B　自分に入るお金 | 配分したあと、手元に残る | **重い。場合によっては2倍の売上が要る** |

**ジムの商品は、オーナーと配分する。** だからAとBで、必要な仕事量が変わる。

```
例：配分が半分なら　──　Bで400万 ＝ Aで800万を売る
```

**法人研修は配分がないので、AもBも同じ。**
つまり、Bで考えるほど、**法人の比重が上がる。**

**→ まずここを、オーナーと決める。**

---

# 2　3つの動きを、同じ形で並べる

数字は分からないので、**空けてある。埋めると自動で見える。**

## ① ジムの会員を集める

| | |
|---|---|
| 会費（月） | 　　　　円 |
| 自分の配分 | 　　　　％ |
| いま何名か | 　　　　名 |
| 1年で何名増やすか | 　　　　名 |

```
自分の年間 ＝ 会費 × 12 × 増えた人数 × 配分
```

**いちばん遅い。** 月額なので、1名増えても年間では会費12か月分。
ただし**②の母数になる。** ここが増えないと②が増えない。

## ② ジムの中でパーソナルを受ける人を増やす（オーナーとの共同商品）

**共同商品＝90日伴走プログラム。** 中身と価格は `gym/README.md`、
1,000万の側から見た検証は `gym/review-1016.md`。

分かったこと：**時間は足りる。足りないのは人数。**
ベーシック（49,800円・オンラインのみ）だけが岡山にも時間にも縛られない。


| | |
|---|---|
| 商品の価格 | 　　　　円 |
| 自分の配分 | 　　　　％ |
| 1人あたり、自分が使う時間 | 　　　　時間 |
| 1年で何名 | 　　　　名 |

```
自分の年間 ＝ 価格 × 名数 × 配分
自分の年間時間 ＝ 1人あたり時間 × 名数
```

**ここが400万の本体。** 共同商品の価格と配分が分かれば、必要人数が出る。

## ③ 企業・チーム研修

> **2026-10-28　オーナーからの月額はなくなった。**
> 売上に計上できないため。**法人側の数字に、ジムは一切入らない。**
> ジムは②（配分）だけで数える。

| | |
|---|---|
| 継続契約（月額） | 　　　　円 × 　　社 |
| 単発（1件） | 　　　　円 × 　　件 |
| 配分 | **なし（全部自分）** |

```
自分の年間 ＝ 月額 × 12 × 社数 ＋ 単発 × 件数
```

**いちばん速くて、いちばん自分に残る。**

---

# 3　時間の上限を先に置く

1,000万に届く組み合わせがあっても、**時間が足りなければ机上のまま。**

```
1〜2月　　　試合に集中　→　仕事量を抑える
約5週ごと　 高重量期　　→　ここも抑える
家族の時間　子どもと遊ぶ時間を、家事と分けて確保する
```

**使える月は、実質10か月。** そのうち高重量期がある週も抑える。

| | |
|---|---|
| 週に、仕事に使える時間 | 　　　　時間 |
| うち、提供（人に会う）に使える時間 | 　　　　時間 |

**ここが先。** 売上から逆算すると、必ず時間が足りなくなる。
**時間から逆算して、足りない分を単価で埋める。**

---

# 4　いま言えること（数字が入る前でも）

## ③だけが、配分のない収入

```
① 会員　　　→　配分あり・月額・遅い
② パーソナル →　配分あり・単価は高い
③ 法人研修　→　配分なし・単価がいちばん高い
```

**「企業・チーム研修を収入の柱にする」は、構造として正しい。**
自分で価格を決められて、自分に全部残るのは③だけ。

## ①と②は、順番がある

```
会員が増える　→　パーソナルを受ける人が増える
```

**②を先に増やそうとしても、母数がなければ増えない。**
①は、②のための仕込み。**①単体の売上では見ない。**

## 1年目で1,000万は、たぶん重い

法人の「話」は2件。どちらも相手から出てきたが、**契約はゼロ**（2026-10-28時点）。
**ゼロから20件も、2社の継続契約も、1年目で立つとは限らない。**

段階に分けるなら、こういう形になる。

| | 法人 | ジム（自分の取り分） | 計 |
|---|---|---|---|
| **1年目** | 300〜400万 | 100〜200万 | **400〜600万** |
| **2年目** | 600万 | 400万 | **1,000万** |

**1年目に全部を立てるのではなく、1年目に「2年目に1,000万が立つ形」を作る。**

その形とは、具体的にこれ。

```
法人の継続契約が、2社ある
ジムの共同商品が、売れる形になっている
```

**この2つが1年目に揃えば、2年目の1,000万は机上ではなくなる。**

| 1 | オーナー | **1,000万がAかBか**（売上か、手元か） |
