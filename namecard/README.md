# 第1部　何を書くか

## 誰に渡す名刺か

**パワーリフターではなく、企業・法人・学校・起業家の人**に渡す前提です。

ここが全部の前提になっています。同じ材料でも、置く場所を変えてあります。

| | 相手の受け取り方 |
|---|---|
| パワーリフティングを**対象**に書く | 企業の人「自分向けじゃないな」 |
| パワーリフティングを**根拠**に置く | 企業の人「この人は本物だ」 |

**肩書きはメンタルトレーナーが主、パワーリフターが従。
キャッチに競技用語を使わない。競技の実績は下に一行でまとめる。**
これで一枚で両方に渡せます。

## 載せるもの（表）

```
メンタルトレーナー
パワーリフター

佐藤　栞　　さとう　しおり
　　　　　　しおりん

ここぞの場面で、
自分の力を出しきる。

競技歴11年｜日本一2回｜スクワット日本記録｜世界大会出場
```

| 要素 | なぜこう書いたか |
|---|---|
| 肩書きの主従 | 渡す相手が企業・学校・起業家だから。パワーリフターは残すが従に置く |
| ローマ字読み | 「栞」は読めるが、初対面で名前を呼んでもらえるかは大きい |
| キャッチ | **LPの「ここぞの一本を、取り切る。」は使わない。**「一本」は競技用語で、企業や学校の人には通じない。「出し**きる**」にすると、LPの「取り**切る**」と動詞の形が揃うので、競技用語なしでブランドの声だけ引き継げる |
| 「〜人へ」を外した | 「出せる人へ」だと、すでに出せている人への呼びかけに読める。名刺は2秒で読まれるので、一瞬でも迷わせない |
| 日本記録に種目を入れた | パワーリフターでない人も「どの種目？」で止まる。具体性が上がる |
| 競技歴11年 | 継続は、記録とは別の種類の信頼になる |

### ★「日本記録保持者」とは書かない

**記録は破られます。名刺は2年後も相手の名刺入れにあります。**

「日本記録」「日本記録樹立」なら過去の事実なので、いつまでも嘘になりません。
「保持者」だけは避けてください。

## 載せるもの（裏）

```
メンタルは強さではなく、鍛えられるスキル。
小さな「できた」を積み重ねて、
自分を信頼できるようにする。
──────────────────────
ご依頼いただけること
研修・講演・個別コーチング

✉ （メールアドレス）
Instagram @nolimits.shiorin
                              [QR] ご相談・お申し込み
```

| 要素 | なぜこう書いたか |
|---|---|
| 「強さではなく」 | 「メンタルが強い／弱い」という世間の言い方をまっすぐ否定している。研修を頼む理由になる |
| 「小さなできた」 | 方法。主張だけだと頼めない。**主張→方法の順**で置く |
| 研修・講演・個別コーチング | **これがないと名刺は自己紹介で終わる。**人事の人が「で、何を頼めるの？」で止まらないようにする一行 |
| Instagramは文字 | QRは1つしか置けない。見たい人だけが見にいければ足りる |


## なぜInstagramではないか

> **Instagramは「見つけてもらう場所」。MOSHは「申し込める場所」。**

名刺は手渡しです。**その人はもう会っています。**
見つけてもらう必要は終わっているので、必要なのは動ける場所のほうです。

Instagramに送ると、そこからまたプロフィールのリンクを踏んでMOSHへ行くことになります。
一段よけいです。

## なぜセミナーやLPではないか

- **セミナーの個別ページ** … 9/26で切れる。名刺のほうが長生きする
- **LP** … パワーリフター向け。学校の先生が読み取ると話が合わない

## ユーザー名は変更済み

2026-09-22に `surikuki_suski0823` → **`nolimits-shiorin`** に変更済み。
QRも新しいURLで作り直してあります。Instagram（`@nolimits.shiorin`）と揃いました。

**今後これを変えると、配った名刺のQRが全部つながらなくなります。**

※ サービスの個別ページ（`mosh.jp/services/404875` など）はユーザー名と

# 第3部　デザイン仕様

## 寸法

| | |
|---|---|
| 仕上がり | **91×55mm**（日本の標準サイズ） |
| データ | **97×61mm**（塗り足し上下左右3mm込み） |
| 安全領域 | 仕上がりから内側3mm（＝データ端から6mm） |
| 面 | 両面。PDFの1ページ目が表、2ページ目が裏 |

文字はすべて安全領域の内側に入れてあります。
**裁断が1mmずれても切れません。**

## 色

| 名前 | 値 | どこに |
|---|---|---|
| ワイン | `#7A1524` | 表の左の柱、肩書き、罫線のアクセント |
| ワイン（濃） | `#540E19` | 裏の地色、表のキャッチ |
| ピンク | `#F0B9C3` | 裏の小見出し |
| 墨 | `#17151A` | 表の名前 |
| 白 | `#FFFFFF` | 表の地色、裏の文字、QRの下地 |

LP・チラシ・ジム掲示ポスターと同じ色です。**並べたときに同じ人のものだとわかります。**

※ 印刷所によってはCMYK変換を求められます。ワイン `#7A1524` は
おおよそ **C25 M100 Y75 K25** あたりです。色校正が出せるなら見てください。

## 書体

| | 現物 | 印刷所に頼むとき |
|---|---|---|
| 名前・キャッチ | IPA明朝 | 游明朝 / ヒラギノ明朝 |
| それ以外すべて | IPAPゴシック | 游ゴシック / ヒラギノ角ゴ |

**名前とキャッチだけ明朝**です。ここが一番読まれるところで、
明朝のほうが落ち着いて見えます。

## 文字の大きさ

### 表

| 要素 | サイズ | 色 |
|---|---|---|
| メンタルトレーナー | 2.7mm 太 | ワイン |
| パワーリフター | 2.45mm 太 | `#5A514E` |
| 佐藤　栞 | **8.4mm 明朝 太** | 墨 |
| さとう　しおり | 2.45mm | `#6E6360` |
| しおりん | 2.8mm | ワイン |
| キャッチ（2行） | **4.5mm 明朝 太** | ワイン濃 |
| 実績 | 2.45mm 太 | `#4A4340` |

### 裏

| 要素 | サイズ | 色 |
|---|---|---|
| メンタルは強さではなく… | 3.3mm 太 | 白 |

## レイアウト

**表** … 白地。左端に **幅9mmのワインの柱**。
柱はデータの端まで伸ばしてあるので、裁断がずれても幅が変わりません。
文字は柱の右、上から 肩書き → 名前 → キャッチ、実績は一番下に罫線付きで固定。

**裏** … ワイン濃の全面。左に文章、右下にQR。
QRは **21mm角の白い箱**に入れています。地色が濃いので、白下地がないと読めません。

## QR

| | |
|---|---|
| 中身 | `https://mosh.jp/nolimits-shiorin/profile` |
| 規格 | バージョン3・誤り訂正M・**29マス** |
| 大きさ | 21mm角（白箱込み） |
| 1マス | **約0.72mm** |

1マス0.5mmを下回るとスマホで読みにくくなります。**0.72mmあるので余裕があります。**

`build-pdf.py` が600dpiで書き出して**実際にデコードして確認**しています。

# 第4部　作り直しかた

```
python3 build-pdf.py
```

`card.html` を直してからこれを実行すると、PDFを書き出したうえで

1. 文字が安全領域からはみ出していないか
2. QRが600dpiで読み取れるか

を検査します。**両方 OK が出なければ入稿しないでください。**

QRを作り直すとき:

```
python3 -c "import segno; segno.make('https://mosh.jp/nolimits-shiorin/profile', error='m').save('qr.png', scale=40, border=2, dark='#540E19')"
```

## メールアドレスの扱い

**このリポジトリは公開です。** `card.html` にアドレスを書くと
GitHubに載って、迷惑メールの収集対象になります。

そうならないようにしてあります。アドレスは `mail.txt` に置いて、
PDFを書き出すときだけ差し込みます。

```
echo 'あなたのアドレス' > mail.txt
python3 build-pdf.py
```

`mail.txt` と `meishi.pdf`、`preview.png` は `.gitignore` で除外済みです。
