# なぜ頼みづらいのか（2026-10-28）

相手から上がった声。

> お金を支払う立場だけど、私が何をやれて、
> どこで利益を出したり、時間を生み出してくれるのかが、まだよく分からない。
> なので、頼みづらい。

**これは断りではなく、設計の欠陥を教えてもらった。**

---

# 0　もう1つ　──　夫婦であること

**オーナー（夫）との契約は、お金の意味が消えやすい。**

```
同じ財布から出て、同じ財布に戻る
```

頼みづらいのは、相手の遠慮だけではない。**構造的にそうなっている。**

→ `b2b/riten.md` の「0」へ。
**月額伴走の試験運用は、第三者を相手にしないと検証にならない。**

---

# 1　何が起きているか

企画書の中心は、この一行。

```
毎月、私の時間を5時間まで自由に使えます
```

**「自由に使えます」は、相手が使い方を知っている前提の書き方。**

知らない相手にとっては、

```
料理の名前が1つも書いていない、メニュー
```

**何が出てくるか分からないものに、月55,000円は払えない。**
頼みづらいのは当たり前。

## 大会前ワークショップと比べると、はっきりする

`b2b/a4/sheet.html`（よく売れそうな方）には、こう書いてある。

```
内容（90分）　5つのステップ
完成するもの　選手一人ひとりの4点
コーチにとっての価値　選手全員に同時に手は届かない。だから選手が自分で整える
```

**何が起きて、何が手に入って、誰の何が楽になるかが書いてある。**

月額伴走サポートには、**その3つが全部ない。**

---

# 2　足りない3つ

| | いまの書き方 | 必要な書き方 |
|---|---|---|
| **何をやるのか** | 「内容は固定しません」 | **1つ目は、これをやります** |
| **何が手に入るか** | 書いていない | 終わったときに、**形として残るもの** |
| **誰の何が楽になるか** | 書いていない | **オーナーの時間／会員の継続／選手の成績** |

## 「内容は固定しません」が、裏目に出ている

**柔軟さを見せたつもりが、「決まっていない」に見える。**

```
こちら　→　相手に合わせたい
相手　　→　何を買うのか分からない
```

**試験運用だからこそ、最初の1つは決め打ちでいい。**

---

# 3　2つの直し方

## 案A　月額のまま、1か月目を決め打ちする

```
1か月目にやること（決まっています）

　① 会員・選手へのアンケート（15分・こちらで作ります）
　② 結果をもとに、オーナーと60分の振り返り
　③ 「いま、誰が何で止まっているか」を1枚にしてお渡しします

2か月目以降は、その1枚を見ながら決めましょう。
```

**「何をするか分からない」が消える。**
そして**2か月目以降を一緒に決める理由**にもなる。

## 案B　単発を1回やってから、月額を出す　★ こちらを推す

```
大会前ワークショップ　1回 55,000円
　↓
実際に見てもらう
　↓
「毎月あったら、どうですか」
```

**価値を知らない相手に、定額は売れない。**
`funnel/front.md` で自分が書いたことと、同じ構造。

```
フロント　→　体験　→　継続
```

**月額伴走は、いきなり継続から入ろうとしていた。**

### 案Bのいいところ

| | |
|---|---|
| 相手が買いやすい | **90分で何が起きるか、紙に書いてある** |
| こちらも出しやすい | 「まず1回やらせてください」は言いやすい |
| 実績になる | 単発でも、記録は取れる |
| 断られても小さい | 5.5万円の1回なら、ノーのコストが低い |

### 案Bにすると、失うもの

```
5か月の継続記録　→　取れない
4月の本運用価格の根拠　→　弱くなる
```

**ただ、契約が1件も取れなければ、記録はゼロ。**
**ゼロよりは、単発1回の記録のほうがある。**

# 4　どちらにしても、先に言葉にすること

**「どこで利益を出し、時間を生むのか」に、答えを用意する。**

いまは答えていない。

**→ `b2b/riten.md` に、数字で言える形にして出した。**

```
ジム　　　年に6名の退会を防げば、月55,000円の元が取れる（会費8,800円）
　　　　　年に5名が90日伴走に入れば、790,000円
ケニーさん　★ 事業の形が分からないので、まだ書けない
```

# 6　記録

**「頼みづらい」は、いちばん価値のあるフィードバック。**

```
断られた　　　　→　理由が分からない
頼みづらい　　　→　理由を教えてくれている
```

**知り合いでなければ、この言葉は返ってこなかった。**
