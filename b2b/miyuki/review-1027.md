# 2　★ 報酬が、自分の価格を壊す

```
固定 50,000円（3か月）　＋　実売上の15％
```

## 同じ時期に、法人へ出している価格

```
月額伴走サポート　月5時間　55,000円／月
```

**3か月なら165,000円。**

この企画書の中身は、

```
Zoom 月2回 × 3か月　＝ 6回
チャット相談　随時
資料・アーカイブの確認
```

**どう少なく見ても、月5時間は超える。**
それを**3か月で50,000円**は、法人向けの**3分の1以下**。

### `pricing.md` に書いた原則

```
一度出した価格は戻せない
法人と個人は別の階段
```

**みゆきさんは個人だから安くていい、ではない。**
**これは法人向けと同じ仕事。** 階段を下りる理由になっていない。

## もう1つ　──　リスクを全部こちらが背負っている

```
売れなかった場合　→　50,000円
```

3か月の設計も、募集の伴走も、改善も、全部込みで5万円。

**成果報酬は、相手の集客力に賭けること。**

### ここは、言いにくいけれど書いておく

**5DAYSで、みゆきさん側の申込は0名だった。**

責める話ではない。声はかけてくれていた。
ただ、**「かけても入らなかった」という事実がある。**

その状態で、報酬の大半を実売上に乗せるのは、こちらの取り分が消える設計。

# 3　直し方

```
月額 55,000円 × 3か月 ＝ 165,000円
＋
実売上の 10％
```

## なぜこの形か

| | |
|---|---|
| 月額55,000円にそろえる | **法人向けと同じ価格。** 説明が1行で済む |
| 15％→10％に下げる | 固定が上がったぶん、成果報酬は下げる。**合計の期待値は変わらない** |
| 売れなくても165,000円 | **設計の仕事に、ちゃんと値段がついている状態** |

## 言い方

```
法人向けに出している月額伴走と同じ条件にさせてください。
月5時間で、月55,000円です。

そのうえで、売れた分の10％をいただく形でどうでしょうか。
```

**「みゆきさんだから安くします」を、やらない。**
やると、次にみゆきさんが誰かに紹介してくれたとき、その価格が基準になる。

# 4　日程が、たぶん間に合わない

```
今日　　　　10月27日
講座開始　　11月末
```

**商品設計から募集まで、1か月しかない。**

```
商品設計　→　告知文を作る　→　募集　→　個別相談　→　申込
```

5DAYSは、**告知から締切まで2週間あって、4名だった。**
4か月の講座は、5DAYSより高い。**決めるのに、もっと時間がかかる。**

### 提案

```
11月末　→　講座の開始を1月にずらす
　　　　　 12月いっぱいを募集期間に使う
```

**ずらせないなら、12月開始の少人数（3名まで）で始める形も言っておく。**
初回を小さく始めるのは、失敗ではない。

# 5　書き足したほうがいいこと

| | なぜ |
|---|---|
| **開始日と終了日** | 「約3か月」だと、いつ終わったか分からない |
| **支払いのタイミング** | 固定はいつ、成果報酬はいつ。**月額なら毎月末に翌月分** |
| **売上の確認方法** | 10％の元になる数字を、どう見せてもらうか。**ここは必ずもめる** |
| **返金・キャンセルが出たとき** | 成果報酬の対象から外すのか |
| **チャットの返信目安** | 月額伴走では「原則1営業日以内」と決めた。**同じ一文を入れる** |
| **Zoom 1回の長さ** | 月2回の「2回」が、30分か90分かで総量が変わる |
| **実績として使う許可** | 月額伴走には入れた。**ここにも要る。初のプロデュース案件になる** |

## やるなら、例外として決める

**やめたほうがいい、とは言わない。**

```

売れれば、実績として大きい
相手の専門が、こちらと重ならない（やりやすい）
```

ただ、**「気づいたら3本目が立っていた」にしないこと。**

```
今回かぎりの1件　→　やる
これを柱にする　　→　2本柱を決め直す話になる
```

**どちらなのかを、先に自分の中で決めてから出す。**
