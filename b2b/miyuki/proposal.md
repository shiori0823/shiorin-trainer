# 初回講座立ち上げ・販売伴走サポートのご提案

みゆきさんへ

今回「私ファーストプログラム5DAYS」を一緒につくる中で、みゆきさんがこれまで培ってきた
マナー・所作・日本文化の知識や経験には、まだまだ形にできるものがたくさんあると感じました。

一方で、専門性や伝えたいことが多いからこそ、

「誰に届けるのか」
「受講後どう変わるのか」
「何を、どんな順番で届けるのか」
「どうすれば価値が伝わるのか」

を一緒に整理する人がいることで、より伝わる講座になるのではないかと思っています。

そこで、今回の4か月講座について、**初回講座の立ち上げ・販売・実施初期の改善まで、
3か月間伴走させてもらえたら**と思っています。

## サポート内容

### 1｜商品設計

- ターゲットの明確化
- お客様のBefore／Afterの整理
- 講座コンセプトの言語化
- 価格、サービス内容の整理
- カリキュラム全体の流れの壁打ち
- 「懐紙をすべての女性に！」など、みゆきさんならではのメッセージづくり

### 2｜募集・販売伴走

- 募集までの導線整理
- 告知内容、文章の壁打ち
- Instagram、LINEなどで何を伝えるかの整理
- 個別相談につなげる流れづくり
- 募集期間中の反応を見ながら改善

### 3｜講座開始後の改善

- 受講者さんの反応、感想の確認
- 内容や順番の見直し
- 「伝えたいこと」と「お客様が価値を感じたこと」の整理
- 次回開催に向けた改善点の言語化

## 私だからこそできること

AIを使えば、文章やアイデアを形にすることはできます。

でも私は、これまで実際にみゆきさんと一緒に企画をつくり、お客様へ届け、
その反応まで見てきました。

だからこそ、言葉だけではなく、

「みゆきさんが本当に大切にしたいこと」
「まだ言葉になっていない強み」
「お客様が実際に反応しているポイント」

を対話の中から拾いながら整理することができます。

答えを渡すのではなく、

「それはなぜ？」
「お客様はどう変わる？」
「みゆきさんだからこそ伝えられることは何？」

と一緒に考えながら、みゆきさん自身が納得して選べる商品にしていく。

それが、私が伴走する一番の価値だと思っています。

### 3か月の流れ

```
10月末　　商品設計（90〜120分・1回で決めます）
11/9　　　告知文・募集ページ 完成
11/10　　 募集開始
11/20　　 締切
11月末　　開講
12月　　　受講者さんの反応を確認しながら、内容と順番を調整
 1月　　　次回開催に向けた整理
```

### 間に合わせるために、2つだけお願いがあります

**① 最初の打ち合わせで、全部決めさせてください。**

価格・回数・日程・定員・講座名。**ここが決まらないと、告知文が1行も書けません。**
持ち帰って考えると、それだけで2週間が過ぎてしまいます。
仮でも構わないので、その場で置いていきましょう。

**② 定員を、先に小さく決めましょう。**

```
定員5名　→　「あと2名です」が言える　→　締切が本物になる
定員なし →　「いつでも入れる」　　　 →　今日決める理由がない
```

**初回を少人数で始めるのは、失敗ではありません。**
1回やってお客様の声を聞いてから2回目を大きくするほうが、結果的に早く育ちます。

## 報酬

**今回は、成果報酬のみとさせてください。**

| | |
|---|---|
| 伴走料 | **なし** |
| 成果報酬 | **今回募集する講座の実売上の 25％** |

通常は、月額55,000円×3か月（165,000円）＋実売上10％でお受けしています。

**今回は、私にとって初めてのプロデュース案件です。**
一緒につくって、売れた分だけいただく形にさせてください。

### 成果報酬について

- 対象は、**今回の募集期間に販売した講座の売上のみ**です
- **税込の受講料を基準**に計算します
- 分割払いの方がいる場合は、**受講料の総額**を対象とします
- **途中返金・キャンセルが出た場合は、その分を対象から外します**
- 次回以降の募集や販売伴走については、必要に応じて改めて相談します
