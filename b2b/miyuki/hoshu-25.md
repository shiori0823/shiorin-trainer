# 成果報酬25％で受けることについて（2026-10-27）

みゆきさんに伝えた内容。

```
本来　月額55,000円 × 3か月（165,000円） ＋ 実売上10％
今回　成果報酬 25％ のみ（初めてのプロデュース案件のため）
```

**本来の金額も一緒に伝えてある。** ここが大事。
「安くした」のではなく「今回だけこの形にした」と分かる。

---

# 1　分かれ目は、売上110万円

```
25％ × 売上　＝　165,000 ＋ 10％ × 売上
　　　　　　　→　売上 1,100,000円
```

**110万円を超えたら、通常の形よりも多い。下回ったら少ない。**

## 受講料ごとの早見

| 受講料 | 3名 | 5名 | 8名 |
|---|---|---|---|
| 100,000円 | 75,000 | 125,000 | 200,000 |
| 150,000円 | 112,500 | 187,500 | 300,000 |
| **200,000円** | 150,000 | **250,000** | 400,000 |
| 300,000円 | 225,000 | 375,000 | 600,000 |

※ 通常の形なら、受講料20万×5名で265,000円。**25％なら250,000円。ほぼ同じ。**

```
受講料20万 × 5名前後　→　どちらでも変わらない
それ以下　　　　　　　→　25％のほうが少ない
それ以上　　　　　　　→　25％のほうが多い
```

**受講料と定員が決まった時点で、どちらに転ぶかが分かる。**
設計Zoomで、ここを見ながら価格を決められる。

---

# 2　負っているリスク

```
申込ゼロ　→　3か月働いて、0円
```

**リスクを全部こちらが取る形になった。**
しかも、売上をつくるのは**みゆきさん側の集客**。

5DAYSでは、みゆきさん側の申込は0名だった。

## だから、変わること

**集客の決め方に、口を出していい立場になった。**

```
伴走料をもらう立場　→　提案する
成果報酬だけの立場　→　一緒に責任を持つ
```

**「20名に個別で送ってください」が、言いやすくなる。**
これは、この形のいいところ。

**遠慮しないこと。** 遠慮すると、0円になる。

---

# 3　だから、必ず決めておくこと

**報酬の100％が売上に乗っている。** 曖昧なところを残さない。

| | 企画書に書いた |
|---|---|
| 税込か税抜か | **税込の受講料を基準** |
| 分割払い | **受講料の総額**が対象 |
| 返金・キャンセル | **その分を対象から外す** |
| 確認のしかた | 申込者数と受講料を教えてもらう |
| 支払い | 申込確定後に請求 |

**ここを書かずに始めると、最後に気まずくなる。**
お金の話は、始める前がいちばんしやすい。

---

# 4　売れなかったときに、残るもの

**0円でも、残るものを先に確保しておく。**

```
「立ち上げから一緒につくった講座」として、公開できること
```

企画書の「お願いしたいこと」に、こう書き足した。

```
今回、伴走料をいただかない代わりに、ここをお願いしています。
「立ち上げから一緒につくった講座」として出せることが、私にとっての報酬です。
```

**これがあれば、申込が1名でも、この3か月は無駄にならない。**
プロデュースの実績は、**件数ではなく、1件目があるかどうか。**

---

# 5　次からは、この形にしない

**初めての1件だから、この条件。**

```
2件目からは　月額55,000円 × 期間 ＋ 実売上10％
```

**企画書に「本来は」と書いてある。** これが次の交渉の土台になる。

→ `pricing.md` の「一度出した価格は戻せない」に対して、
　 **「本来の価格を先に言ってある」が、唯一の戻し方。**
