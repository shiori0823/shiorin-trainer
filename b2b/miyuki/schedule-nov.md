# 11月スタートから逆算する（2026-10-27）

**今日が10月27日。11月末の開講まで、4週間ない。**

できないとは言わない。**できる形にするために、削るものを先に決める。**

---

# 1　いちばん大事なこと

```
商品設計は、1回で決める。持ち帰らない。
```

**ここが全部を決めます。**

価格・回数・日程・定員が決まらないと、告知文が1行も書けません。
持ち帰って考えると、**それだけで2週間が溶けます。**

**今週中に、90〜120分のZoomを1回。**
その場で、下の7つを全部決める。

| | |
|---|---|
| 1 | 誰に届けるか（一人、具体的に思い浮かぶ人で） |
| 2 | 4か月後、その人は何ができるようになっているか |
| 3 | 全4回（または何回か）の流れ |
| 4 | **価格** |
| 5 | **定員** |
| 6 | **開講日と、各回の日程**（4か月ぶん全部） |
| 7 | 講座の名前 |

**「あとで考えます」をゼロにする。** 決まらなければ、仮で置いて進める。
**仮でも決まっていれば告知は書けます。決まっていないと書けません。**

---

**募集期間は10日。** 短いです。だから次の3が要ります。

---

# 3　募集は、広げない

**ここが、いちばん言いたいところです。**

5DAYSのとき、みゆきさん側の申込は0名でした。
InstagramやLINEへの投稿では、**入りませんでした。**

```
投稿する　→　見た人が自分で決める　→　入らない
一人に送る →　その人が考える　　　　→　入る
```

**5DAYSで実際に効いたのは、1対1のDMです。**
1人目は、20行のDMで申し込んでくれました。

## だから、11月はこうする

```
① みゆきさんに、声をかけられる人を20名、名前で書き出してもらう
② 投稿は出す。ただし「見て申し込んでもらう」ことを期待しない
③ 20名に、一人ずつ送る
```

**20名に送って3名。** それが普通です。
**定員を3〜5名にしておけば、それで埋まります。**

### 定員を先に小さく決める理由

```
定員5名　→　「あと2名です」が言える　→　締切が本物になる
定員なし →　「いつでも入れる」　　　 →　誰も今日決めない
```

**少人数は、売れなかった言い訳ではなく、売り方そのものです。**

---

# 4　しおりんの稼働が、11月だけ増える

企画書には「Zoom打ち合わせ 月2回」と書いてあります。

**11月は、それでは回りません。**

```
11月　週1回ペース（4〜5回）
12月　月2回
 1月　月2回
```

**先に書いておく。** あとから「思ったより多いな」になると、
3か月ぶんの気持ちが削れます。

→ 企画書の「期間と進め方」に、この一文を入れてある。

# 5　聞いておくこと（設計Zoomの前に）

**これが分からないと、計画が立ちません。**

| | なぜ |
|---|---|
| **講座の開講日（候補でいい）** | ここから全部が決まる |
| **Instagramのフォロワー数／LINEの登録者数** | 届く人数の上限 |
| **個別に声をかけられる人は、何名いるか** | **ここが実際の母数** |

**3つめがいちばん大事です。**
ここが5名なら、定員3名の設計にする。20名なら、5名で組める。

---

# 6　間に合わなかったときの線

**11/20の締切で、申込が1名だったら。**

決めておくのは1つだけ。

```
1名でも開講するのか、しないのか
```

**これを先に決めておかないと、締切の日に判断することになります。**

おすすめは、**1名でも開講する。**

```
初回は、実績と声をつくる回　→　人数ではない
1名でも、4か月分の感想が手に入る　→　2回目の告知が書ける
```

**ただし、それをみゆきさんと先に合意しておく。**
当日に「どうしましょう」になると、みゆきさんが一番つらいです。
