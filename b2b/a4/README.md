# 企画書（A4・1枚）

```
python3 build-pdf.py
```

`proposal-a4.pdf` が出ます。**はみ出し検査でOKが出なければ渡さないこと。**

| | |
|---|---|
| `sheet.html` | 中身 |
| `style.css` | 体裁 |
| `proposal-a4.pdf` | 書き出したもの |

長いほう（`../proposal-meet.md`）は、メールに貼る・相手に読み込んでもらう用。
**この1枚は、その場で見せる用。**

## 他の大会・チームに使うとき

書き換えるのは3か所だけ。

```
・見出し（必要なら大会名を入れる）
・実施概要の「時期」
・料金（人数が違う場合）
```

**中身の1〜5は変えない。** どのチームでも同じです。

## 入れてあるもの、入れていないもの

| | |
|---|---|
| 入れた | 実施までの流れ（日程→ヒアリング→当日） |
| 入れた | 全員が同じ時間に集まる条件、コーチ同席の推奨、定員8名 |
| **外した** | 講師の経歴の長い話（2024年JCPで2位など） |

**1枚に収めるため、講師紹介は資格だけにしてあります。**
物語は、口で話すか、長いほうの企画書で。

## 右下の「実施までの流れ」が主役

```
① 日程を決める　←　まずここだけ押さえてください
```

**期限のある提案は、金額ではなく日程で決まります。**
この紙を見せたあと、相手に最初に言ってもらうのは「いつにしますか」です。
