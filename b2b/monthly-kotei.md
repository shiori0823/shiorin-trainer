# 1　先に決める　──　いつから数えるか

**10月はもう終わる。** 今日は26日。

| | |
|---|---|
| A　10月〜3月のまま出す | **6か月が、実質5か月になる。** 10月分の55,000円をもらう理由が弱い |
| B　**11月〜3月の5か月にする** | **4月から本運用、という線が守られる** |
| C　11月〜4月の6か月にする | **4月とぶつかる。** 法人の予算年度に合わせた意味がなくなる |

**→ B を推します。**

```
2026年11月 〜 2027年3月　試験運用（5か月）
2027年 4月 〜　　　　　　 本運用
```

「6か月」にこだわる理由はない。**守りたいのは、4月で切り替わることのほう。**

5か月 × 55,000円 ＝ **275,000円**

# 2　5時間に、準備を含めるか

企画書の書き方が、2か所でずれている。

```
2章　「私の時間を5時間まで自由に使えます」
7章　「実働時間　準備を含めて」を毎月記録する
```

**読む人は、2章しか読まない。** ここが曖昧なまま始めると、必ずもめる。

## 決め方

| | |
|---|---|
| A　5時間＝**提供時間**。準備は別に数える | 相手に分かりやすい。**準備が青天井になる** |
| B　5時間＝準備を含めた時間 | 自分を守れる。**90分のセミナーで枠がほぼ埋まる** |

**→ A を推します。**

理由は、この6か月の目的が利益ではないから。
**「可能性を広げてもらう」と決めている**（10/10）。

そのうえで、**準備時間は必ず別に記録する。**
4月の価格は、提供時間ではなく**かかった時間の合計**から出す。

### 企画書に足す1行

```
5時間は、実際にお会いする時間です。
資料の準備にかかる時間は、この5時間には入れません。
```

# 3　使わなかった月を、翌月に繰り越すか

企画書には「使わない月があっても構いません」とある。
**繰り越せるとは書いていないが、書いていないだけ。**

**→ 繰り越さない、と明記する。**

繰り越せると、3月に15時間まとめて使われることが起こりうる。
**1〜2月は競技集中期**（`strategy/README.md`）。そこへ寄せられると破綻する。

### 企画書に足す1行

```
使わなかった時間は、翌月への繰り越しはありません。
```

# 4　1〜2月のことを、先に言うか

```
1〜2月　試合に集中し、仕事量を抑える
```

**月5時間なら、両立する。** だから条件を変える必要はない。

ただし、**大きなセミナー（50名以上＝その月の枠を全部）が1〜2月に来ると厳しい。**

**→ 先に一言だけ入れておく。**

```
1月と2月は、私自身の試合期にあたります。
月5時間は変わりませんが、大きな規模の回は
できれば12月までか、3月に置かせてください。
```

**先に言えば調整。あとから言えば言い訳になる。**

# 6　支払いのしかた

企画書に書いていない。**聞かれる前に決めておく。**

```
毎月末、翌月分を前払い
初回は、始める前に
```

**先払いにする理由**は、使わない月があってもいいから。
後払いだと「今月は使っていないので」という話が毎月出る。

**定額であることが、この商品の形そのもの。**

# 7　3月のあと、どうするか

```
3月で、いったん終わる
4月から本運用を、改めて提案する
```

**自動継続にしない。** 自動で続くと、値段を上げる場がなくなる。

### 4月の価格を決める締切

**2027年2月末まで。**

1〜2月は競技集中期なので、2月に慌てて決めることになる。
**実際は、1月の記録が出た時点（2月頭）で決める。**

→ `strategy/verify.md` の試算では、**月20万×2社で480万。**
　 55,000円からの上げ幅が大きいので、**6か月の記録が根拠になる。**
