# 私を月55,000円で雇うと、相手に何が生まれるか（2026-10-28）

**ここに答えを用意していなかった。** だから頼みづらかった。

数字で言えるものだけを並べる。**言えないものは、聞く。**

---

# 0　先に　──　夫婦であることの難しさ

**オーナー（夫）との契約は、お金の意味が消えやすい。**

```
同じ財布から出て、同じ財布に戻る
```

**「払う意味」が成立しにくい。** 頼みづらいのは、相手の遠慮だけではない。
**構造的にそうなっている。**

## だから、オーナー案件は性格が違う

| | |
|---|---|
| ケニーさん・第三者 | **本当の試験運用。** 払う／払わないの判断が働く |
| オーナー | **払う判断が働かない。** 練習台にはなるが、検証にはなりにくい |

**月額伴走サポートの「売れるかどうか」を見るなら、相手は第三者でないと分からない。**

### 代わりに、オーナーとはこうする

```
月額伴走の契約　→　無理に結ばない
90日伴走プログラム　→　ジムのサービスとして、一緒につくって一緒に売る
```

**夫婦でやるなら、売上を分ける形のほうが自然。**
請求書を出し合う形は、お互いに気持ちが悪い。

**→ 月額伴走の相手は、ケニーさん＋もう1者（第三者）を探す。**

# 1　ジムにとっての利益（数字で言える）

## ① 退会が減る

```
会費　月8,800円
1名が1年長く続く　＝　105,600円
```

**年間6名の退会を防げば、633,600円。**
月55,000円×12か月＝660,000円。**ほぼ同じ。**

```
年に6名、辞めるのを止められるか
```

**これが、月額伴走がジムにとって元を取る線。**

★ **オーナーに聞くこと：いま、年に何名辞めているか。辞める理由は何か。**

## ② パーソナル・講座に入る人が増える

```
会員パーソナル　60分 6,600円
90日伴走（会員）　158,000円
```

**年に5名が90日伴走に入れば、790,000円。**

メンタル面を見る人が月1回いると、
**「大会に出てみようかな」が出やすくなる。** そこが90日伴走の入口。

★ **オーナーに聞くこと：いま、大会に出ている会員は何名か。**

## ③ 入会の理由が増える

```
「メンタルサポートのあるジム」
```

岡山で、ここを言えるジムは多くない。
**会員を迎えるときの材料が1つ増える。**

※ これは数字にしづらい。**①と②が本線。**

## ④ オーナーの時間が空く

★ **オーナーに聞くこと：会員の相談（技術以外）に、月何時間使っているか。**

技術以外の相談（モチベーション、続かない、迷い）をこちらが受ければ、
**その時間がそのまま空く。**

# 2　ケニーさんにとっての利益

```
月額コーチング　約15名
パーソナルのお客さんは、それとは別にいる
```

**この15名が、全部。** ここに向けて何ができるかで決まる。

## ★ いちばん大きいのは、1名あたりで割れること

```
月 55,000円 ÷ 15名 ＝ 1名あたり 月 3,667円
```

**ケニーさんが客単価を月5,000円上げれば、15名で 月75,000円。**
**差額の 20,000円が、毎月そのまま残る。**

### 値上げをしなくてもいい

既存の15名の料金を上げる必要はない。
**上に1段、プランを足すだけでいい。**

```
いまのプラン　　　　　　　　　　　　　そのまま
メンタルサポート付きプラン（＋5,000円）　新設
```

**15名のうち5名が上がるだけでも、月25,000円。**
**全員が上がれば、月75,000円。**

★ **聞くこと：いまの月額コーチ料はいくらか。**
　 ここが分かれば、+5,000円が現実的かどうかが出る。

## ② 解約が減る

★ 月額コーチ料が仮に15,000円だとすると、

```
1名が1年続く　＝　180,000円
年に4名の解約を防げば　＝　720,000円
```

月55,000円×12＝660,000円。**年4名で元が取れる。**

★ **聞くこと：15名は、平均どれくらい続いているか。**

## ③ ケニーさんの時間が空く

**月額コーチングで来る相談は、技術だけではないはず。**

```
続かない
やる気が出ない
試合が近いのに不安
人と比べてしまう
```

**ここを、こちらが受ける。**
ケニーさんは、トレーニングの設計に集中できる。

★ **聞くこと：15名からの相談で、技術以外は何割くらいか。**

## ④ 新規が入りやすくなる

```
「メンタルコーチもついています」
```

パーソナルのお客さんを、月額コーチングへ引き上げる理由にもなる。

---

## ★ ケニーさんは、すでに体験している

**ここがいちばん大きい。**

```
2026年9月　ワークショップに申し込んでくれた（1人目）
2026年10月　国スポの振り返りセミナーを受けている
```

**「何が起きるか分からない」人ではない。**

だから、言い方はこうなる。

```
ケニーくんが受けてくれたあれを、
ケニーくんのお客さん15名に、月1回やる形です。
```

**説明が、ほぼ要らない。**

---

## 出し方の案

**15名向けのグループセッションを、月1回。**

```
月1回 60〜90分　オンライン　15名まで
　→　月額伴走サポートの5時間のうち、2時間ぶん
残り3時間　ケニーさんとの振り返り／個別相談の枠
```

**「5時間を自由に」ではなく、「月1回、15名に、これをやります」。**
ここまで決めて出す。

# 3　法人一般（これから探す相手）に出す言い方

どこにでも使える形にしておく。

## 利益の出方は、3つしかない

| | |
|---|---|
| **続く人が増える** | 退会・離脱が減る＝売上が残る |
| **上の商品に行く人が増える** | 単価が上がる |
| **指導者の時間が空く** | 技術以外の相談を、こちらが受ける |

## 言い方

```
選手やお客様が辞める理由は、
結果が出ないことよりも「できている実感がない」ことのほうが多いです。

そこを月に1回見る人がいると、続く人が増えます。

続く人が増えると、売上は残ります。
そして、指導者の方は技術に集中できます。
```

★ **「できている実感がない」は、いまは仮説。**
　 オーナーとケニーさんに聞いて、本当にそうなら、この一文が武器になる。

```

② オーナーに、辞める理由と人数を聞く
③ 答えを入れて、企画書の冒頭に「こう元が取れます」を1節足す
④ ケニーさんから出す（オーナーではなく）
```

**④の順番が変わった。**

```
オーナー　→　夫婦なので、払う判断が働かない

```

**検証になるのは、ケニーさんのほう。**

**いま出しても、また「よく分からない」で止まる。**
