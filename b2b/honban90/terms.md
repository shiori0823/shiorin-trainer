# 本番実力発揮 90日伴走プログラム
## サービス内容・料金・契約条件のご案内

```
練習の力を、本番の力に。
```

本プログラムは、スポーツ指導者の外部メンタルパートナーとして、
選手が練習で培った力を本番で発揮するための準備を支援する90日間の伴走サービスです。

選手の目標設定・メンタルトレーニング・振り返りを中心に、
監督・コーチと連携しながら日常の実践を支えます。

---

## 1. ご利用いただける方

- スポーツクラブ・学校・競技団体などの組織
- 個人で選手を指導する監督・コーチ

支援対象は、選手・指導者・保護者です。
**個々の選手からの直接申込みは本サービスの対象外です。**

## 2. 提供プラン

### 少人数プラン　148,000円（税込）／90日間　対象選手：1〜4名

- 合同セッション60分×4回
- 選手個別面談30分×3枠
- 指導者ミーティング45分×2回
- 週次振り返りと共通フィードバック（12週）
- 最終成果レポート1回

### スタンダードプラン　198,000円（税込）／90日間　対象選手：5〜8名

- グループセッション60分×6回
- 選手個別面談30分×3枠
- 指導者ミーティング45分×3回
- 週次振り返りと共通フィードバック（12週）
- 保護者向けグループ説明会45分×1回
- 最終成果レポート1回

## 3. 契約期間

原則として、合意したサービス開始日から90日間とします。
セッションおよび面談は契約期間内に実施します。契約期間の延長は自動では行いません。

提供者側の事情や、双方が認めるやむを得ない事情がある場合には、
書面または電子的な記録で合意したうえで、期間や日程を変更できます。

## 4. お支払い方法

一括払い、または3回分割払いを選択できます。

**一括払い**　サービス開始日の7日前までに、契約総額をお支払いください。

**3回分割払い**

```
第1回：サービス開始7日前まで
第2回：サービス開始30日後
第3回：サービス開始60日後
```

少人数プランは49,334円・49,333円・49,333円、
スタンダードプランは66,000円を3回お支払いいただきます。

分割手数料はありません。分割払いの場合でも契約総額は変わりません。
支払方法は銀行振込を基本とし、その他の決済方法は事前合意によります。

## 5. 個別面談の利用

各プランには、30分の個別面談3枠が含まれています。

- 3枠は契約対象選手全体で共有します。
- 同じ選手が複数枠を利用することも可能です。
- 本人の希望や必要性を踏まえて実施します。
- 追加面談は契約者の承認を得て実施します。

**追加面談料金（税込）**

```
1回　11,000円
3回　29,700円
6回　55,000円
```

未使用枠については契約終了前に利用状況を確認します。
通常の期間満了時と中途解約時の取扱いを区別し、
返金・精算については適用法令と合意した契約条件に従います。

## 6. 実施形式と連絡方法

原則としてオンラインで実施します。
対面実施、大会帯同、遠方への出張は別途見積もりとします。

連絡窓口は、原則として契約者側の代表者1名です。
質問対応は契約内容に定める範囲で行い、無制限の個別相談は含みません。

## 7. 日程変更・キャンセル

予定したセッションの変更希望は、原則48時間前までにご連絡ください。
急病・災害その他やむを得ない事情がある場合は、双方で対応を協議します。

欠席時の振替可否、提供済みの役務の扱い、日程変更に伴う追加費用については、
事前に合意した条件を適用します。

## 8. 中途解約・返金

契約期間中の解約については、解約の申し出を受け付け、
提供済みのサービス、着手済みの準備、未提供のサービスおよび発生した費用を確認します。

返金・追加請求の有無と金額は、
あらかじめ定めた精算方法および適用される法令に従って決定します。

分割払いであっても、実施済みサービスの金額と既払額を照合して精算します。
具体的な精算表は契約締結前に別途提示します。

## 9. 個人情報・守秘義務

選手の相談内容や振り返り記録は、事前に説明した利用目的の範囲内で取り扱います。
監督・コーチ・保護者と共有する情報は、必要性と本人の同意を踏まえて決定します。

未成年の選手には年齢や理解力に応じて説明し、必要な保護者の同意を確認します。

**選手が安心して相談できる関係を大切にし、
個別面談の内容を無条件に契約者へ報告することはありません。**

## 10. 成果について

本サービスは、目標設定・日常の行動改善・振り返りなどを通じて、
選手の実力発揮に向けた取り組みを支援するものです。

**試合での勝利、記録更新、特定の大会成績を保証するものではありません。**

## 11. 契約終了・継続

契約は90日間の期間満了により終了し、自動更新はありません。
継続を希望する場合は、期間満了前に次の目標と支援内容を相談し、別途契約します。
