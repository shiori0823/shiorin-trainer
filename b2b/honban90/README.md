# MY BEST LIFT PLAN（3か月98,000円）について

**売り出さないことにした。**（2026-11-03 本人）

## 理由

```
「試合が楽しい」と言える状態まで、
無料のフロントセミナーと無料の個別相談で解決してしまった
```

ジムメンバーであること、オーナーのLINEサポートメンバーであることも大きい。
ただ、**無料の中で解決できる内容を、3か月98,000円では売り出せない。**

## ここから分かること

**無料で出しすぎていた。**

```
無料セミナー90分　＋　無料個別相談　＝　98,000円の商品が要らなくなる状態
```

**10/26に「無料でやらない」と決めたのは、正しかった。**
その判断の根拠が、ここで数字のない形で裏づけられた。

### 本番実力発揮90日では、同じことを起こさない

```
入口は、導入相談30分（無料）
ただし、相談で解決まで持っていかない
```

**導入相談は「合うかどうかを見る」場。**
その場で設計まで終わらせると、商品が要らなくなる。
