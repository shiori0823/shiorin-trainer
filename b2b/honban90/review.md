# 出す前に詰めておきたいところ（2026-11-03）

条件案そのものは、よくできている。**特にいいのは、この4つ。**

| | |
|---|---|
| 個々の選手からの直接申込みは対象外 | **指導者経由を、はっきり切った。** 柱①と一致する |
| 成果を保証しない | 10の書き方がちょうどいい |
| 個別面談の内容を無条件に契約者へ報告しない | **ここがこの商品の信用そのもの。** よく書けている |
| 自動更新なし | `b2b/README.md` の「4月の値上げが自然になる」と同じ考え方 |

**未成年への説明と保護者同意**まで入っているのは、学校を相手にするときに効く。

# ★ 1　「週次振り返りと共通フィードバック（12週）」が、定義されていない

**ここがいちばん危ない。**

| | |
|---|---|
| 選手は何を出すのか | 紙？フォーム？動画？ |
| いつまでに出すのか | 締切がないと、ばらばらに届く |
| こちらは何を返すのか | 一人ずつ？まとめて1本？ |
| 分量は | 3行？1ページ？ |
| 出さなかった週は | 催促する？しない？ |

**定義がないと、ここが青天井になる。**

## 工数で見ると

```
少人数（4名）　12週 × 4名 ＝ 48本
スタンダード（8名）12週 × 8名 ＝ 96本
```

**1本5分でも、スタンダードは8時間。**
セッションの合計（10.5時間）とほぼ同じだけ、ここで消える。

## 提案

```
週次振り返りシート（所定のフォーム・5分で書ける）を毎週1回提出
→ こちらからは、週1回まとめて全員へ共通フィードバックを1本返す
→ 個別の返信は含まない（個別は面談枠で）
```

**「共通フィードバック」と書いてあるので、たぶんこの意図。**
**それを、そのまま書いておく。**

# 2　個別面談3枠が、8名で共有されること

スタンダードは対象5〜8名。**個別面談は3枠。**

```
8名のうち、個別を受けられるのは最大3名
```

**設計としては正しい。** グループ主体の商品だから。

**ただ、契約者がそう理解しているかは別。**
申込むときは「8名みんなが個別面談を受けられる」と読む人がいる。

## 提案

条件案の5に、1行足す。

```
個別面談は、対象選手全員が受けられるものではありません。
必要な選手に、必要なタイミングで使っていただく枠です。
```

**先に書けば、説明になる。あとで言えば、言い訳になる。**

# 3　保護者向け説明会が、スタンダードにしかない

```
少人数プラン（1〜4名）　→　保護者会なし
```

**少人数こそ、中高生を抱えたチームかもしれない。**

## 提案

**オプションにしておく。**

```
保護者向けグループ説明会45分　＋ 22,000円（税込）
```

※ 追加面談1回11,000円から逆算した仮の金額。

# 4　最終成果レポートの中身が、決まっていない

**何が書いてあるのか。** ここが、継続につながる唯一の紙。

## 提案（4項目）

```
① 90日で、選手が決めたこと（目標・やること・やらないこと）
② 実際にやれたこと（できたのかけら）
③ 試合・本番で起きたこと（事実のみ）
④ ここから90日、次に取り組むこと
```

**④があると、継続（A④）の話が自然に出る。**
**④がないと、90日で終わる。**

→ `b2b/riten.md` の「毎月記録する4項目」と同じ考え方。

---

# 5　継続サポート（A④）の形が、まだない

**90日の最終日に、次の形を出せないと継続は起きない。**

```
最終成果レポート　→　④「次の90日」　→　継続サポートのご案内
```

**この流れをつくるために、レポートの④が要る。**

**価格と中身は未定。** 90日が1件走り出す前に決めなくてもいいが、
**1件目が終わる前には決めておく。**

---

# 6　同時に何件持てるか　──　売上の上限

**週次フィードバックが毎週ある。** ここが上限を決める。

```
少人数（4名）　セッション7時間 ＋ 週次48本 ＋ レポート
スタンダード（8名）セッション10.5時間 ＋ 週次96本 ＋ レポート
```

**準備を含めると、1件20〜30時間。**

```
同時2件　→　90日で約35万〜40万
年4期　 →　約140万〜160万
```

★ **法人600万には、これだけでは届かない。**
②実践ワークショップ（単発）と④継続サポートを、並べて回す必要がある。

→ `strategy/verify.md` に戻して数える。

# まとめ　──　出す前にやること

```
① 週次振り返りの中身を決める（★ いちばん重要）
② 個別面談3枠について、1行足す
③ 保護者会をオプションにする
④ 最終成果レポートの4項目を決める
⑤ 精算表を作る
```

**①だけは、出す前に必ず。**
ここが決まっていないと、1件目で自分が潰れる。
