# 価格の考え方

| | 時間 | 金額 |
|---|---|---|
| 講演 | 90分 | 100,000円 |
| 研修 | 半日 | 300,000円 |
| **大会前ワークショップ** | **90分＋前後** | **55,000円** |

## ★ 整合していない

ワークショップは90分の講演より**作業量が多い**（事前ヒアリング＋5名分のプラン＋個別フォロー）のに、
**金額は約半分。**

実働はおよそ6〜7時間。

```
事前ヒアリング　　　 30分
ワークショップ　　　 90分
資料と準備　　　　　 60分
プラン整理（5名分）　60分
個別フォロー　　　　150分（30分×5名）
```

### 意図的ならそのままでよい

初回で、相手が知っている人で、実績をつくる回。**それなら55,000円で問題ない。**

意図していなかった場合は、88,000円にすると講演の価格と並ぶ。

**決めるのは栞さん。** ここに書いてあるのは、気づいていないまま安くしていないか、の確認だけ。

## 人数が増えたときの式を決めてある

```
6名以上　→　1名につき +10,000円
```

**当日「7人になりました」と言われたときに困らないようにするため。**

# 月額伴走サポート（2026-10-10 開始）

```
2026年10月 〜 2027年3月　試験運用　月額55,000円／月5時間
2027年4月 〜　　　　　　 本運用（価格は改めて）
```

## ★ これは「売る」ではなく「買う」

```
払うもの　→　時間（月5時間 × 6か月）
買うもの　→　100名規模の実績、使われ方のデータ
```

利益で見ると割に合わない。**それでいい。**
栞さんの判断は「可能性を広げてもらうため」。
100名にセミナーをした実績ができれば、そこから法人に売っていける。

**だから、単発55,000円とのカニバリや時給の話は、ここでは当てはまらない。**

## 書き足した3つ（どれも投資を回収するために要るもの）

### ① 実績として使う許可

**これが買いたいものそのもの。** 企画書に書かれていなかった。

```
後から頼む　→　断りにくくさせる
先に書く　　→　ただの前提になる
```

ジム名も一緒に出す形にして、**相手の実績にもなる**ようにしてある。
「メンタルサポートを導入しているジム」は、会員を迎えるときの強みになる。

### ② 50名以上はその月の枠を全部使う

100名は、8名の延長線にない。問いかけて書いてもらう形が使えないので、
**組み立てから変わる。** 準備だけで6〜8時間。

受けるのは賛成。**これが欲しい実績だから。** ただ、先に書いておけば揉めない。

### ③ 毎月記録する

| | |
|---|---|
| 実働時間 | **準備を含めて。** ここがないと4月の価格が出ない |
| 何に使ったか | |
| 届いた人数 | |
| 変化 | |

**これがないと、6か月後に「よかったですね」で終わる。**

## 1〜3月を空けなかった理由

```
10〜12月　試験
1〜3月　　★ ここを空けると関係が切れる
4月〜　　 本運用
```

4月を年度始まりに合わせるのは正しい（法人の予算年度）。
ただ12月で区切ると、1月に流れで同じ金額が続くか、関係が切れるかのどちらか。

**「3月までは今の条件です」と先に言ってあるので、4月の値上げが自然になる。**

## 金額について

**「今回の試験運用に限ったもの」と本文に明記してある。**

これを書いておかないと、他の法人に適正価格を出すときに説明できない。
知り合い価格であることを、角を立てずに伝える一文。
