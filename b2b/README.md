# 価格の考え方

| | 時間 | 金額 |
|---|---|---|
| 講演 | 90分 | 100,000円 |
| 研修 | 半日 | 300,000円 |
| **大会前ワークショップ** | **90分＋前後** | **55,000円** |

## ★ 整合していない

ワークショップは90分の講演より**作業量が多い**（事前ヒアリング＋5名分のプラン＋個別フォロー）のに、
**金額は約半分。**

実働はおよそ6〜7時間。

```
事前ヒアリング　　　 30分
ワークショップ　　　 90分
資料と準備　　　　　 60分
プラン整理（5名分）　60分
個別フォロー　　　　150分（30分×5名）
```

### 意図的ならそのままでよい

初回で、相手が知っている人で、実績をつくる回。**それなら55,000円で問題ない。**

意図していなかった場合は、88,000円にすると講演の価格と並ぶ。

**決めるのは栞さん。** ここに書いてあるのは、気づいていないまま安くしていないか、の確認だけ。

## 人数が増えたときの式を決めてある

```
6名以上　→　1名につき +10,000円
```

**当日「7人になりました」と言われたときに困らないようにするため。**

# この商品の位置づけ

```
大会前ワークショップ（チーム）　→　選手と全員会える
　　　　　　　　　　　　　　　→　希望者に個別フォロー30分
　　　　　　　　　　　　　　　→　3か月講座（98,000円）
```

**1回で5名に会える。** 個人へのDMを5通送るより速い。

個別フォローを企画書に明記してあるのは、コーチに隠れて選手に売らないため。
**先に書いておけば、あとで気まずくならない。**
