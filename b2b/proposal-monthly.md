# 月額伴走サポートのご提案（試験運用）

2026年10月

---

## 1. やってみたいこと

これまで、単発のセミナーや個別コーチングという形でやってきました。

今後は

**「必要なときに、必要な形で使える月額伴走サポート」**

という形をつくっていきたいと考えています。

ただ、どんな使い方がいちばん価値につながるのかが、まだ分かりません。

**なので、まず実際に使っていただきながら、一緒に形をつくらせてください。**

---

## 2. 期間と金額

| | |
|---|---|
| 期間 | **2026年10月 〜 2027年3月**（6か月） |
| 金額 | **月額 55,000円（税込）** |
| 内容 | 毎月、私の時間を**5時間まで**自由に使えます |
| 人数 | 制限はありません |

**この金額は、今回の試験運用に限ったものです。**
2027年4月からの本運用については、この6か月を踏まえて、改めてご提案させてください。

---

## 3. 使い方

5時間の中で、その月の課題に合わせて自由に組み合わせます。

**毎月決まった形にする必要はありません。** 使わない月があっても構いませんし、
大会前に集中して使っていただいても構いません。

### 例① 選手のサポート中心

```
選手向けメンタルセミナー　　90分
選手の個別セッション　　　　30分 × 5名
コーチとの振り返り　　　　　60分
```

### 例② コーチ・指導者のサポート中心

```
コーチとの振り返り　　　　　60分 × 2回
チーム向けセミナー　　　　　90分
個別相談　　　　　　　　　　30分 × 3名
```

### 例③ 大会前の集中サポート

```
大会前セミナー
出場選手との個別セッション
大会後の振り返り
次に向けた目標の整理
```

---

## 4. お渡しできるテーマ

- 大会前のメンタル準備
- 試合中の切り替え、セルフコントロール
- 目標設定
- 大会後の振り返り
- 自己信頼を高めるコーチング
- 選手との関わり方
- チームビルディング
- 指導者自身の振り返り、思考整理

内容は固定しません。**その月の課題に合わせて、相談しながら決めます。**

---

## 5. 大きな規模のとき

**50名以上の講演やセミナーも、ぜひやらせてください。**

ただ、人数が増えると組み立てから変わります。
8名までなら一人ずつ数字を出していけますが、100名では別のつくり方が要ります。

**その場合は、その月の枠をすべて使わせてください。**
資料のつくり直しと準備に、それだけの時間がかかるためです。

---

## 6. お願いしたいこと

**この取り組みを、今後ほかのジムや団体へご提案していくための実例にさせてください。**

- 実施した内容・人数を、対外的に公開させていただくこと
- 当日の写真を撮らせていただくこと
- 参加された方に、感想をいただくこと

公開したくない内容があれば、そのつど外します。
**選手個人のお話は、ご本人の許可なく外に出すことはありません。**

### これは、そちらの実績にもなります

**「メンタルサポートを導入しているジム」**は、
選手や会員さんを迎えるときの強みになります。

公開するときは、ジム名も一緒に出させてください。

---

## 7. 毎月、記録させてください

6か月後に、お互いにとっていい形を決めるためです。

| 記録するもの | |
|---|---|
| 実働時間 | 準備を含めて |
| 何に使ったか | セミナー／個別／振り返り／その他 |
| 届いた人数 | のべ何名か |
| 変化 | 選手・指導者に起きたこと |

毎月まとめて、お渡しします。

---

## 8. 確認したいこと

この6か月で、私が知りたいのはここです。

```
どんな使い方がいちばん価値になるか
5時間という設定が適切か
どんなサポートの需要が多いか
継続することで、どんな変化が起こるか
```

**使ってみて「これは要らなかった」も、そのまま教えてください。**
それがいちばん役に立ちます。
