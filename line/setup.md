# LINEの設定手順（これ1枚で終わります）

2026-10-01 に設定する用。**上から順に、コピーして貼るだけです。**

使うのは **LINE公式アカウントManager** です。

---

# 全体の流れ

```
登録
 ↓
あいさつメッセージ　…　「1か2を送ってください」と聞く
 ↓
 ├─「1」競技をしている　→　ここぞの一本 準備シート（3通）
 │                          ↓
 │                     「100点の数字は？」に返信
 │                          ↓
 │                     無料個別相談60分 → 3か月講座
 │
 └─「2」競技はしていない　→　できたのかけら診断（2通）
                            ↓
                       「少なかったかけらは？」に返信
                            ↓
                       できたのかけらセミナー → 90日間プログラム
```

**分けるのは最初の1回だけです。** そのあとは手でやりとりします。

# なぜ「先に聞く」のか

プレゼントを先に渡して、あとから聞く方法もあります。
でも**先に聞くほうを推します。**

| | |
|---|---|
| 先に渡す | 登録数は減らない。でも**返信が来ない** |
| **先に聞く** | 少し減る。でも**返信した人は、そのあとずっと反応する** |

いま登録者は4名です。**数ではなく、話せる人が要ります。**

そして9/27、山ピーさんは「A/B/C/Dを1文字」で返信し、
そこから3往復して個別相談まで進みました。**同じ仕組みです。**

# ① あいさつメッセージ

**ホーム →「あいさつメッセージ」**

吹き出しを**2つ**作ります。

## 1通目

```
ご登録ありがとうございます。
佐藤栞（しおりん）です。

メンタルトレーニングのことを、ここでお伝えしています。
```

## 2通目

```
最初に、ひとつだけ教えてください。


　1　パワーリフティングなど、競技をしている

　2　競技はしていない


番号だけ送ってもらえれば大丈夫です。
合うほうのプレゼントをお送りします。
```

**お願いは1つだけです。** 8/24の配信はお願いが3つあって、返信ゼロでした。

# ③ 返信が来たときの返し方

**自動にしません。ここは手でやります。**

| | |
|---|---|
| **すぐ返す** | 数時間以内。返信した直後がいちばん開いています |
| **短く返す** | 相手が2行なら、こちらも3行 |
| **答えを渡さない** | 「見えていないもの」を指す |

答えを渡す（「100点は635kgですね」）→ 要らなくなります。
見えていないものを指す（「〇〇さんは、こういう人ですね」）→ もっと知りたくなります。

## 「1」の人に返すとき

返ってきた数字と、試合ベストを比べます。

| | 分かること |
|---|---|
| 試合ベストから大きく離れている | **120点を100点に置いている** |
| 試合ベストとほぼ同じ | **100点を80点に置いている** |

→ 実例は `followup/seminar-01/`（山ピーさんとのやりとり3往復）

## 「2」の人に返すとき

4つの分岐の原稿があります。→ `line/mail-02.md`

# ⑤ あとでやること（今日はやらなくていい）

## リッチメニュー

画面の下にずっと出るメニューです。**登録済みの人が、あとから自分で選べます。**

```
［ 選手の方へ ］［ そのほかの方へ ］［ 個別相談 ］
```

**人が増えてからで足ります。** いまは4名なので、手で足ります。

## ステップ配信

診断のあとの5通は書いてあります（`line/mail-01`〜`mail-05`）。
でも**まだ組まないでください。**

> **返信を書くのが「負担だな」と思ったとき。**

だいたい30人くらい、または週に10人入ってくるようになった頃です。
**そのときには、手で返した文章が何十通も溜まっています。** 並べ替えるだけで済みます。
