# LINE

## いまの状況（2026-09-26）

登録者 **6名**。ジャンルばらばら。**ステップ配信は動いていない。**

## ★ 6名にステップメールは要らない

3本作ると**1本あたり2人**になる。2人のために書いた文章は誰にも刺さらないし、
**当たっているか確かめる方法がない。**

6名なら手で書ける。**この人数では、手で書くほうが強い。**

いま足りないのは仕組みではなく、**その6名が誰なのかという情報。**
それは送らないと手に入らない。

→ **まず `first-message.md` を6名全員に送る。**

## 3パターンのうち、1つはLINEに来ない

| | どこから来るか | LINEに入るか |
|---|---|---|
| A 一般 | できたのかけら診断 | **入る** |
| B 選手 | セミナー・note | 入る |
| C 指導者・保護者 | 名刺・紹介・MOSH | **来ない** |

学校の先生は、登録して育ててもらうことを望んでいない。
名刺を見て、MOSHで30分相談に申し込む。そこで終わり。

**LINEで考えるのは実質2パターン。**

**いま新しく書くものはない。**

## 仕組みが要るようになる合図

人数ではなく、感覚で決める。

> **返信を書くのが「負担だな」と思ったとき。**

だいたい30人くらい、または週に10人入ってくるようになった頃。

そのときには**手で返した文章が何十通も溜まっている。**
並べ替えるだけでステップメールになる。

## メルマガではなくLINEでいい理由

**返信が来るから。**

しおりんのやり方は送りっぱなしではなく、**返してもらって、返す**形。
メールだと返信のハードルが上がる。

セミナー参加者へのメールは、いまのまま続ける。**統一しなくていい。**
3人と3人なら、2つあっても困らない。
