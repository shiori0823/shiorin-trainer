# LINE ステップ配信（できたのかけら診断のあと）

診断を受けた人を、フロントセミナーまで連れていくための5通。

```
LP → LINE登録 → ①診断を渡す＋少ないかけらを聞く
                    ↓（返信）
                 ②分岐（A/B/C/D）
                    ↓
                 ③「ちゃんとやらなきゃ」の話
                    ↓
                 ④私が3年遠回りした話
                    ↓
                 ⑤できたのかけらフロントセミナーへ
                    ↓
                 90日間 目標達成プログラム
```

## 3つの設計判断

### 1. 分岐は「多かったほう」ではなく「少なかったほう」で切る

診断は2つの結果を返します。多かったかけら（得意）と、少なかったかけら（次に見つけてほしいもの）。

**分岐に使うのは少ないほうです。**

多いほうは「あなたはこういう人です」で終わります。
少ないほうは「今日ここを見てみてください」になります。
**行動が出てくるのは、少ないほうだけです。**

### 2. 1通目で、アルファベット1文字を返してもらう

これは分類のためだけではありません。

- 診断を**実際にやったかどうか**がわかる
- 一度でも返信した人は、あとで反応が続く
- 名前ではなく記号なので、返すのに勇気がいらない

**最初の返信のハードルを、これ以上下げられないところまで下げています。**

### 3. 5通目の行き先は、90日講座ではなくフロントセミナー

無料のPDFを読んだ人に、いきなり90日のプログラムは遠すぎます。

**間にフロントセミナーがすでにあります。** そこを使ってください。
選手側（note記事 → 9/26セミナー → 3か月講座）とまったく同じ形になります。

## 売り込みは5通目まで出しません

1通目で案内すると、診断が集客の道具に見えます。
診断を受けた人は、まだ自分の話をしている最中です。

**1〜4通目には、リンクを1本も入れません。**

## 配信のタイミング

| 通 | いつ |
|---|---|
| ① | 登録直後 |
| ② | 返信が来たらすぐ（返信がなければ翌日に共通版） |
| ③ | ②の翌日 |
| ④ | ③の2日後 |
| ⑤ | ④の2日後 |

②に返信がない人向けの共通版も `mail-02.md` の最後に入れてあります。

## 診断PDFに足りないもの

**8ページ目に次の一歩がありません。**

読み終えた人がいちばん温まっている場所です。最後に1行足してください。

```
見つけた3つを、LINEで送ってみませんか。
一緒に、次の「かけら」を探します。
```

書いたものを人に見せると、その人は自分の「できた」を認めやすくなります。
**診断の効果そのものが上がります。**
