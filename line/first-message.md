# 登録者への最初の1通（全員に同じ文面）

2026-09-26 時点で登録者は**4名**（表示6名のうち、本人と夫を除く）。

**4名は「配信」する人数ではない。「連絡」する人数。**
一斉送信をやめて、**1人ずつ、名前を呼んで送る。** 10分で終わる。

---

## 本文（1人ずつ送る。1行目だけ書き換える）

（その人に宛てた一行）


最近、自分の中で「できた」と思えたことを、
1つだけ教えてもらえませんか。


大きなことでなくて大丈夫です。

朝起きられた。やめると決めた。一度休んだ。
全部「できた」に入ります。

返してもらえたら、私からも一つ、
その中にある「まだ見えていないかけら」をお返しします。

---

## ★ 1行目がすべて

> 「この前ジムで話した〇〇の件、その後どうですか」
> 「〇〇さんが前に言っていた〜を思い出して」

**この1行があるかないかで、返信は9割変わる。**
「私に送ってきた」と分かるから。

## 診断は入れない

4名には要らない。**お願いは1つだけにする。**

---

## この1通が同時にやること

1. 返ってきた内容で、**その人がA（一般）・B（選手）・C（指導者）のどれか分かる**
2. 一度返信した人は、以後ずっと反応が続く
3. **返した文章が、そのままステップメールの原稿になる**

3本のステップメールを書こうとして止まっていたものが、
**返信を集めれば勝手に書けるようになる。**

## 誰にでも答えられる文にしてある

「いま何に困っていますか」だと、人によって答えが変わりすぎる。
「最近のできた」なら、**競技をしていてもいなくても答えられる。**

そして、**答えた内容にその人の属性が出る。**

| 返ってきた例 | この人は |
|---|---|
| 「ベンチが更新できた」「サイクルを完遂した」 | B 選手 |
| 「朝起きられた」「家事を1つやめた」 | A 一般 |
| 「部員にこう声をかけられた」 | C 指導者 |

# 前回の配信（2026-08-24・返信ゼロ）から分かったこと

原文は `archive-2026-08-24.md`。

| 何が起きたか | なぜ |
|---|---|
| **4名に「配信」した** | 4名はメルマガの人数ではない。他人行儀さと知り合いの人数という、いちばん悪い組み合わせになる |
| **お願いが3つ入っていた** | ①診断をやる ②できたを3つ探す ③LINEに送る。**増えるたびに返信は半分になる** |
| **「送ってもらえたら嬉しいです」** | 気持ちの表明であって、相手にやる理由がない。「私からも一つ返します」なら交換になる |
| **Googleドライブのリンク** | スマホのLINEからだとアプリが切り替わる・ログインを求められる。そこで脱落する |
| **PDFに答える仕組みがない** | 読んで、閉じて、LINEに戻って、打つ。**戻ってくるまでが遠い** |
| **文章が本人のものでない** | 絵文字が多く、押しが強い。noteもセミナーも静かで短く押さない。**その違和感のほうが残る** |

## いちばんの学び

同じ人が、翌月のセミナーでは**3名全員から感想を引き出している。**

違いは**押さなかったこと**だけ。
