# フロントから、その先へ（2026-10-13）

5DAYSの4名と、10/18の助産院イベント。
**この2つは、同じ「フロント」ではない。** 先に分けておく。

---

# 1　この2つは、買ったものが違う

| | 5DAYS | 助産院イベント |
|---|---|---|
| 払った相手 | **栞さん** | 助産院 |
| 金額 | 3,300円 | （参加者は無料／主催者から受け取る） |
| 連絡先 | **ある** | **ない** |
| 接触時間 | 15分 × 5日 ＝ 75分 | 60分 × 1回 |
| 次に連絡していいか | **いい** | **よくない** |

## 5DAYSの4名は、フロントを買ってくれた人

**お金を払って、名前と連絡先を渡して、5日間の朝を空けてくれている。**

3,300円という金額の大小ではない。
「この人にお金を払う」という線を、**一度またいでいる。**
次に298,000円の話をするとき、またぐ線は2本目になる。1本目より、ずっと低い。

## 助産院の60名は、まだ栞さんのお客さんではない

厳しいようだけれど、ここは正確にしておきたい。

**その人たちが買ったのは、助産院のイベント。** 栞さんの名前で来ていない。
だから、その日のうちに**自分から連絡先を渡してもらわないと、動線はそこで切れる。**

借りている場。**次につなげる責任は、全部こちら側にある。**

# 2　行き先は、1つでいい

```
できたのかけらメソッド　90日間　298,000円
```

ここに向かう。**ただし、3,300円から298,000円へ直接は跳べない。**

間に、**無料の個別相談30分**がある。すでに作ってある（Googleフォーム）。

```
5DAYS 3,300円 ──┐
                 ├──→ 個別相談30分（無料）──→ 90日 298,000円
LINE診断 ────────┘
```

**階段は2段。** 増やさない。

---

# 3　5DAYSの4名に、いつ・どう伝えるか

## 結論：5日目に、1回だけ

```
1日目〜4日目　　売らない。一言も出さない。
5日目　　　　　 最後の3分だけ。
```

**途中で出すと、残りの朝が「売られる時間」になる。**
4名は毎朝6:30に起きてくれている。その時間を売り場にしない。

## 5日目に言うこと

キックオフで「5日後どうなりたいか」を1つ決めてもらっている。
5日目は、それを**本人が確かめる日**。だから、次の問いが自然に出てくる。

```
5日間、おつかれさまでした。

初日に「5日後こうなっていたい」を1つ決めてもらいました。
今日、どうだったかを確かめてもらったところです。

ここからは、5日ではなく90日の話になります。

私は、90日かけて同じことをやるプログラムを作っています。
ただ、これが合う人と合わない人がいます。

合うかどうかを一緒に見る30分を、無料でお渡ししています。
受けたからといって、申し込む必要はありません。

気になる方は、あとでお送りするリンクから取ってください。
```

### この言い方にした理由

| | |
|---|---|
| 「作っています」 | 売り込みではなく報告。必要な人だけが反応する |
| 「合う人と合わない人がいる」 | **選ぶのは相手だと先に渡す。** 追われている感じが消える |
| 「申し込む必要はありません」 | 相談の場が売り場でないと先に言う |
| その場で取らせない | 4名の前で手を挙げさせない。**あとで1人で決めてもらう** |

## 送るのは、終わった直後

その日のうちに、4名へ個別に。**一斉送信にしない。**

```
〇〇さん、5日間ありがとうございました。

初日に決めてもらった「〇〇」、今日確かめてみて
どうでしたか。

最後にお話しした30分の相談、こちらです。
（フォームのリンク）

もちろん、今じゃなくて大丈夫です。
```

**個別に書く。** 「〇〇」のところに、その人が初日に決めたことを入れる。
**これがいちばん効く。** 4名だからできる。

# 4　助産院の60分で、どう渡すか

## 連絡先をもらえなければ、ゼロ

その場で何人が喜んでくれても、**LINEに登録してもらえなければ、翌日にはもう会えない。**
60分の目的は、良い指導をすることと、**もう一度会う約束を取ること**の2つ。

## 渡すものを、先に用意する

口で「LINEやってます」と言っても登録されない。**手に残るものが要る。**

```
QRコードを印刷した紙　1枚
```

載せるのは3つだけ。

| | |
|---|---|
| 今日やった正しく立つ方法 | **その日の中身の続き。** 持ち帰る理由になる |
| できたのかけら診断のQR | 登録先 |
| 名前と肩書き | 誰からもらった紙か分かるように |

**チラシではなく、今日の資料。** 売るものは載せない。

## 最後の1分（`kakera/README.md` に記載済み）

```
今日やったのは、体をゆるめて、正しく立つことでした。

私は、ダイエットが続かない人のサポートをしています。

痩せ方を知らないから痩せないのではなくて、
知っているのに続かない。
そういう方のための90日間を作っています。

興味があれば、LINEで「できたのかけら診断」をお渡ししています。
```

**この紙を配りながら言う。** 言葉だけにしない。

## 主催者への確認（事前に）

```
最後に1分だけ、今日の内容をまとめた紙をお配りしてもいいですか。
```

**勝手に配らない。** 借りている場なので、先に許可を取る。
断られたら、紙はなしで口頭だけにする。それはそれでいい。

# 5　この2つを、同じ場所で受ける

どちらから来ても、行き先は同じ。

```
5DAYSの4名　　→　個別相談30分　→　90日
助産院のLINE　→　メール3通　　→　個別相談30分　→　90日
```

LINEから来た人には、すでに3通のメール（`nurture/`）が流れる。
**5DAYSの4名は、そこを飛ばして直接相談に行ける。** 75分すでに会っているから。
