# フェーズ1：いま、なぜつながっていないのか

商品が足りないのではありません。**4つのズレがあります。**

## ズレ① いちばん人が集まる入口と、いちばん完成した商品が、別の対象

```
Instagram（ほぼ毎日・できたのかけら）  →  対象A（一般）
MY BEST LIFT PLAN（98,000円・完成度が高い）  →  対象B（選手）
```

**毎日いちばん人を集めている場所から、いちばん売れる商品に行けません。**
これが「つながっていない感じ」の正体のひとつです。

悪いことではありません。**A の商品を育てるか、B の入口を作るか、どちらかです。**
（→ 後者を推します。理由は下）

## ズレ② 選手には、名前が残る入口がない

| 対象 | 無料の入口 | 連絡先が残るか |
|---|---|---|
| A 一般 | できたのかけら診断 | **残る**（LINE） |
| B 選手 | note記事 | **残らない** |
| C 団体 | 30分相談 | 残る |

**noteを読んだ選手は、読んで、閉じて、消えます。**

note記事は4本あって、中身は良い。でも受け皿がないので、
**書くたびに人が流れて出ていきます。** ここが最大の穴です。

## ズレ③ 3つのレーンを、並列に置いている

A・B・C を横並びの3本だと思うと、それぞれ別々に集客が要ります。
**実際は並列ではありません。**

> **C（団体）は、A と B に人を供給する上流です。**

講演を1回やると、その場に**選手が30人、保護者が30人、指導者が数人**います。
つまり——

> **1回10万円をもらいながら、同時に60人の見込み客に会っています。**

これは他のどの入口にもない性質です。**Cは売上であり、集客装置でもあります。**

いまは、その60人が名簿に残らずに帰っています。

## ズレ④ 発信の着地点が決まっていない

noteもInstagramも、読んだ人がどこへ行くのかが決まっていません。

なお、**発信はAとBにしか効きません。** 学校の先生はInstagramで研修を探しません。
Cは名刺と紹介です。**名刺を作ったのは正しい判断でした。**

## そして、全部を束ねられる言葉がすでにあります

```
              小さな「できた」を積み重ねて、自分を信頼する
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
   A 一般                  B 選手                 C 団体
 できたのかけら        ここぞの一本を         選手の「できた」を
   を見つける             取り切る            大人が見つける
```

**3つは別の商売ではありません。同じ1つの方法の、当てる先が違うだけです。**

# 階層別（プロンプトの7段階）

**各段階で「もう持っているもの」を先に置きます。** 足すのは、穴があるところだけです。

## ① リードマグネット（無料）

| | 対象 | 状態 |
|---|---|---|
| できたのかけら診断（PDF・8ページ・4タイプ） | A | **あり** |
| 30分の無料相談 | C | **あり** |
| **ここぞの一本 チェックシート** | **B** | **★新設** |

### ★ 作るのはこれ1つです

**選手向けのリードマグネットがありません。** ここだけが空いています。

しかも、**作る必要がほぼありません。**
9/26セミナーのワークシートがすでに2種類あります。**あれを1枚のPDFにするだけです。**

中身の案：
- 次の試合で、本当に取りたい一本は何か
- いま、それを邪魔しているものは何か
- 試合当日、頭が真っ白になったときに戻る手順

note記事4本の末尾を、全部これに向けます。**そこから選手が名簿に残り始めます。**

### 今はやらないもの

- 無料メール講座 … LINEと役割が重なります
- 無料相談の枠を増やす … 時間が足りません

## ② フロントエンド（低価格）

| | 対象 | 価格 | 状態 |
|---|---|---|---|
| 実践メンタルトレーニング セミナー | B | 3,300円 | **あり**（9/26） |
| できたのかけらセミナー | A | 未定 | **あり** |
| **動画版セミナー** | A・B | 3,300〜5,000円 | **★新設・ただし急がない** |

### 動画セミナーの置き場所について

**リードマグネットではなく、フロントエンドに置いてください。**

無料の診断（1分）の次に、いきなり90日や3か月は遠すぎます。
**間に「見るだけで済む、お金を払った経験」が1段あると効きます。**

そして——**もう作ってあります。**
58枚のセミナースライドを録画すれば、それが動画版です。

これができると、**ライブのセミナーを毎月やらなくてよくなります。**
栞さんの時間がいちばん増えるのはここです。

ただし**9/26が終わってからです。**

## ③ メイン商品

| | 対象 | 価格 | 状態 |
|---|---|---|---|
| MY BEST LIFT PLAN（3か月・最大10回） | B | 98,000円 | **あり** |
| 90日間 目標達成プログラム | A | 未定 | **あり** |
| 講演90分／半日研修 | C | 10万／30万 | **あり** |

**3つとも揃っています。新しく作るものはありません。**

→ 90日間の価格だけ決めてください。**3か月が98,000円なので、
　 同じくらいか、少し下（68,000〜98,000円）が自然です。**

## ④ アップセル

**いま手を出さないでください。**

アップセルは、メイン商品を買った人が「もっと」と言ったときに出すものです。
**まだ、そう言った人がいません。**

言われてから作れば間に合います。想像で作ると、たいてい外れます。

## ⑤ クロスセル

| | 中身 |
|---|---|
| **B → C** | 個別を受けた選手が指導者でもある場合、チームへの講演につながります |
| **C → A/B** | 講演を聞いた保護者が90日へ、選手が個別相談へ |

**ここが③のズレの答えです。** 新商品はいりません。**線を引くだけです。**

### ★ いますぐできること

**講演・研修の最後に、診断のQRを1枚出す。**

スライドを1枚足すだけです。
これで**1回の講演が、10万円＋60人のリード**になります。

## ⑥ バックエンド（継続課金）

| | 対象 | 価格 | 状態 |
|---|---|---|---|
| **月イチのフォロー会** | 卒業生全員 | 月3,000〜5,000円 | **★新設・ただし後で** |

### なぜ必要か

**90日も3か月も、終わる商品です。** いま、終わった人は全員いなくなります。

いちばん自分を知ってくれていて、いちばん満足している人たちが、
**毎回ゼロに戻っています。**

理由の言い方は、すでに持っています。診断のLINE5通目と同じです。

> **自分の「できた」は、自分ではいちばん見えにくい。ひとりだと戻ります。**

### ただし、急がないでください

**卒業生が10人くらい溜まってから**です。
3人で月額を始めると、続けるのがしんどくなります。

A と B の卒業生を**同じ会に混ぜて構いません。**
「できた」の話は、競技をしていてもいなくても同じだからです。

## ⑦ プレミアム（高額）

**いまは作らないでください。**

プロンプトは認定制度やインストラクター育成を挙げていますが、
**研修の実績がまだ1件もありません。**

実績ゼロで認定制度を作ると、**中身が空のまま名前だけができます。**
一度そうなると、後から埋めるのは難しいです。

→ **講演・研修を3件やってから**考えてください。
　 そのとき、いちばん自然なのは「指導者向けの継続コンサル（年間契約）」です。

## ③ かけら会（月イチのフォロー会）

| | |
