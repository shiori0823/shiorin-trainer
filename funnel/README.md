# フェーズ1：いま、なぜつながっていないのか

商品が足りないのではありません。**4つのズレがあります。**

## ズレ① いちばん人が集まる入口と、いちばん完成した商品が、別の対象

```
Instagram（ほぼ毎日・できたのかけら）  →  対象A（一般）
MY BEST LIFT PLAN（98,000円・完成度が高い）  →  対象B（選手）
```

**毎日いちばん人を集めている場所から、いちばん売れる商品に行けません。**
これが「つながっていない感じ」の正体のひとつです。

悪いことではありません。**A の商品を育てるか、B の入口を作るか、どちらかです。**
（→ 後者を推します。理由は下）

## ズレ② 選手には、名前が残る入口がない

| 対象 | 無料の入口 | 連絡先が残るか |
|---|---|---|
| A 一般 | できたのかけら診断 | **残る**（LINE） |
| B 選手 | note記事 | **残らない** |
| C 団体 | 30分相談 | 残る |

**noteを読んだ選手は、読んで、閉じて、消えます。**

note記事は4本あって、中身は良い。でも受け皿がないので、
**書くたびに人が流れて出ていきます。** ここが最大の穴です。

## ズレ③ 3つのレーンを、並列に置いている

A・B・C を横並びの3本だと思うと、それぞれ別々に集客が要ります。
**実際は並列ではありません。**

> **C（団体）は、A と B に人を供給する上流です。**

講演を1回やると、その場に**選手が30人、保護者が30人、指導者が数人**います。
つまり——

> **1回10万円をもらいながら、同時に60人の見込み客に会っています。**

これは他のどの入口にもない性質です。**Cは売上であり、集客装置でもあります。**

いまは、その60人が名簿に残らずに帰っています。

## ズレ④ 発信の着地点が決まっていない

noteもInstagramも、読んだ人がどこへ行くのかが決まっていません。

なお、**発信はAとBにしか効きません。** 学校の先生はInstagramで研修を探しません。
Cは名刺と紹介です。**名刺を作ったのは正しい判断でした。**

## そして、全部を束ねられる言葉がすでにあります

```
              小さな「できた」を積み重ねて、自分を信頼する
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
   A 一般                  B 選手                 C 団体
 できたのかけら        ここぞの一本を         選手の「できた」を
   を見つける             取り切る            大人が見つける
```

**3つは別の商売ではありません。同じ1つの方法の、当てる先が違うだけです。**

**各段階で「もう持っているもの」を先に置きます。** 足すのは、穴があるところだけです。

| 30分の無料相談 | C | **あり** |
| **ここぞの一本 チェックシート** | **B** | **★新設** |

### ★ 作るのはこれ1つです

**選手向けのリードマグネットがありません。** ここだけが空いています。

しかも、**作る必要がほぼありません。**
9/26セミナーのワークシートがすでに2種類あります。**あれを1枚のPDFにするだけです。**

中身の案：
- 次の試合で、本当に取りたい一本は何か
- いま、それを邪魔しているものは何か
- 試合当日、頭が真っ白になったときに戻る手順

note記事4本の末尾を、全部これに向けます。**そこから選手が名簿に残り始めます。**

### 今はやらないもの

- 無料相談の枠を増やす … 時間が足りません

### ★ 2026-09-26 方針変更：動画化より、リアルで繰り返す

第1回（参加3名）の記録を読んで、**動画化の優先度を下げました。**

効いたのは、**動画にできない部分**でした。

| 場面 | 何が起きたか |
|---|---|
| 山ピーさんの650kg | レップベストをその場で聞き出し、120点に組み替えた |
| もっちさんの「やめられない」 | 生活のことを聞き出して崩した |

どちらも**その人の数字と生活を聞かないとできません。**

そして**準備はもう終わっています。**
スライド63枚・ワークシート2枚・QR。**追加で1回開くコストは90分だけです。**

90分で複数人に届くので、60分の個別相談を1人ずつやるより効率がいい。
**時間の問題は、動画ではなく回数で解決します。**

#### 定員は6名まで

第1回は3人全員に対して、一人ずつ数字を聞いて組み替えて返していました。
**それが効いた理由です。**

記録の時間配分から見ると、**6名を超えると「全員に返す」が物理的に無理**になります。
7人目からは別のセミナーになるので、そこは守ること。

#### 動画版はいつ作るか

**やめたわけではありません。** ただし役割が変わります。

- ❌ ライブの代わり（→ 中心が消える）
- ⭕ **日程が合わない人のための別版**

開催を重ねて、**申し込んだのに来られない人が出てから**作れば足ります。

### （参考）動画セミナーの置き場所について

**リードマグネットではなく、フロントエンドに置いてください。**

## ⑦ プレミアム（高額）

**いまは作らないでください。**

プロンプトは認定制度やインストラクター育成を挙げていますが、
**研修の実績がまだ1件もありません。**

実績ゼロで認定制度を作ると、**中身が空のまま名前だけができます。**
一度そうなると、後から埋めるのは難しいです。

→ **講演・研修を3件やってから**考えてください。
　 そのとき、いちばん自然なのは「指導者向けの継続コンサル（年間契約）」です。

# 個別相談を2本立てにする（2026-09-26 決定）

| 来た人 | 相談 | なぜ |
|---|---|---|
| **セミナー参加者** | **30分** | 下書きができている |
| note・LP・名刺から来た人 | 60分 | 下書きがない |

## なぜ30分で足りるのか

**セミナーが「説明」を担当するようになったから**です。

9/25にセミナーへ講座の説明を6枚入れました。
**60分の相談が抱えていた仕事が、ひとつ減っています。**

| | 前 | これから |
|---|---|---|
| 講座の説明 | 個別相談の中で | **セミナーで済んでいる** |
| 目標の整理 | 個別相談で | **セミナーで下書き済み** |
| 残る仕事 | — | **その人の数字を見る。それだけ** |

**削ったのではなく、仕事が減りました。**

## 30分の中身

これ1つでいい。

> **「書いたシートを持ってきてください。数字を一緒に見ます。」**

第1回で山ピーさんが証明しています。
650kgを100点と書いたが、試合ベストは610kg。
レップベストから換算して120点に組み替えた。

**自分の数字を客観的に見るのは、一人ではできません。**

## 30分では講座の案内をしない

セミナーで6枚見せてあります。
最後に「気になったら言ってください」で足ります。

**これで売り込みが完全に消えます。**

## 導線は一方通行ではない

```
セミナー → 個別相談30分 → 3か月講座
個別相談60分 → セミナー → 3か月講座　← もっちさんの経路。これも正しい
```

個別相談から入った人は、**次のセミナーに誘う。**
経験者が部屋にいると、他の参加者の基準が上がり、感想もその場で出る。

## セミナー参加者だけの特典にする

30分をMOSHに公開せず、**セミナーに出た人にだけ案内する。**

セミナーに出る理由がもうひとつ増えます。
