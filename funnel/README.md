# 導線の構成

読んだ人が、迷わず自分に合うところへ行けるようにするための設計。
2026-09-22 時点。

---

## 1. いま起きていること

**入口が全部、選手向けです。**

MOSHに並んでいるのは、セミナー（9/26で終わる）・無料個別相談・3か月講座。
どれもパワーリフター向けです。

名刺を渡した相手は、起業家・企業・学校の人です。
その人がQRを読み取ると、**自分向けのものが1つもない画面**に着きます。
プロフィール文だけ書き換えても、ここは変わりません。

**もう1つ。診断とMOSHがつながっていません。**

できたのかけら診断 → LINE の流れは作ってあるのに、
MOSHのプロフィールからそこへ行く道がありません。
逆に、LINEに登録した人がMOSHの講座に戻る道もありません。
**2つの別々の箱になっています。**

---

## 2. 考え方

プロフィールのページは、読む人に「あなたは誰ですか」と聞けません。
だから**本人に選んでもらう**しかない。

選んでもらうために必要なのは、2つだけです。

1. **入口を3つまでにする**（4つ以上あると人は選ばずに閉じます）
2. **入口の名前に「誰向けか」を書く**（MOSHは一覧に名前しか出ません）

そしてもう一つ、見落としやすい軸があります。**温度です。**

| | いますぐ相談したい人 | まだ様子を見たい人 |
|---|---|---|
| 必要なもの | 話す場 | 持ち帰れるもの |
| 渡すもの | 個別相談・研修相談 | 診断 |

**片方しか置かないと、もう片方は手ぶらで帰ります。**
いまのMOSHは「いますぐ」しか置いていません。

---

## 2.5 講座は3つあるが、方法は1つ

講座が3つ（選手・一般・企業）あります。
**別々の商品として出すと、どちらの人からも「この人は自分の専門家か」と思われます。**

そうならないように、**1つの方法の、3つの当て方**として見せます。

```
        小さな「できた」を積み重ねて、自分を信頼する
                        │
    ┌───────────────────┼───────────────────┐
    ▼                   ▼                   ▼
 選手に当てる        一般に当てる        企業に当てる
MY BEST LIFT PLAN  90日間の目標達成       研修・講演
 3か月・試合        体・思考・習慣         団体向け
```

診断の名前が「できたのかけら」なので、3つとも同じ「できた」の話です。
**もともと一本の柱でつながっています。見せ方だけが分かれている状態です。**

### 一般向け講座の名前

「体・思考・習慣を整理して目標を叶える90日間」は、
説明としては正確ですが、**MOSHの一覧には長すぎます。**

案：**MY BEST LIFE PLAN**（LIFT と LIFE の一文字違い）

並べたときに、同じ人の、同じ方法の、対象違いだと一目でわかります。
ありふれた言い方でもあるので、しっくりこなければ別案を出します。

## 3. 全体図

```
  名刺        Instagram        note記事        紹介
    │             │               │             │
    └─────────────┴───────┬───────┴─────────────┘
                          ▼
            ┌──────────────────────────┐
            │  MOSH プロフィール         │  ← 交換台。売る場所ではない
            └──────────────────────────┘
                          │
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
   ①できたのかけら診断  ②選手の方へ      ③企業・学校の方へ
   （誰でも・無料）     無料個別相談60分   ご相談30分・無料
        │                 │                 │
        ▼                 ▼                 ▼
      LINE登録        3か月講座          研修・講演
        │            MY BEST LIFT PLAN    （見積・企画）
        │                 ▲                 ▲
        ▼                 │                 │
   90日間の目標達成       │                 │
   （体・思考・習慣）      │                 │
        │                 │                 │
        └── 競技をしている人／法人の人は ──┴────┘
```

**①が要です。** 3つの中で唯一、
「誰でも入れて」「無料で」「連絡先が残る」入口だからです。

②③は、来た人としか話せません。
①は、いま決められない人を**逃さずに預かって**おける場所です。

そして**①の行き先が、90日間の目標達成講座です。**
診断を受ける人の大半は競技者ではないので、
ここに講座がないと、集めた人の行き先がなくなります。

## 4. MOSHのサービス名を付け直す

**これが「迷わない」の実体です。** 一覧に出るのは名前だけなので、
名前に誰向けかが書いていないと、読む人は自分で判断できません。

| いま | 変更後 |
|---|---|
| 無料個別相談 | **【競技をされている方へ】無料個別相談（60分・オンライン）** |
| 3か月講座 | **【選手向け】3か月 実践メンタルトレーニング** |
| 90日間の講座 | **【競技をしていない方へ】90日間 目標達成プログラム** |
| （ありません） | **【企業・学校の方へ】研修・講演のご相談（30分・無料）** |

**③は新しく作ってください。** 金額は未定のままで構いません。
名刺から来た人の受け皿が、いまどこにもありません。

診断（①）はMOSHの外にあるので、**プロフィール文の最後にリンクで置きます。**

### プロフィール文の締めに足す3行

```
はじめての方は、こちらからどうぞ。

　▶ まず自分の状態を知りたい方 → できたのかけら診断（1分・無料）
　▶ 競技をされている方 → 無料個別相談（60分）
　▶ 企業・学校の方 → 研修・講演のご相談（30分）
```

「はじめての方は」と書くのが大事です。
**選ぶ責任を、読む人から下ろしてあげる一言**になります。

## 5. 診断のあと（LINE）

**→ 原稿は `line/` にあります。5通書いてあります。**

診断の結果は4パターン（成果・挑戦・選択・継続）で、
多かったかけらと少なかったかけらの2つが出ます。

**分岐は「少なかったほう」で切ります。**
多いほうは「あなたはこういう人です」で終わりますが、
少ないほうは「今日ここを見てください」になります。行動が出るのは少ないほうだけです。

| 通 | いつ | 中身 |
|---|---|---|
| ① | 登録直後 | 診断を渡す＋少ないかけらを1文字で返してもらう |
| ② | 返信後すぐ | A/B/C/D で4分岐。今日の質問を1つだけ渡す |
| ③ | ②の翌日 | 「ちゃんとやらなきゃ」に行動が入っていない話 |
| ④ | ③の2日後 | 記録を取れなかった話。3年遠回りした理由 |
| ⑤ | ④の2日後 | できたのかけらセミナーへ |

**①〜④にはリンクを1本も入れていません。**
1通目で案内すると、診断が集客の道具に見えます。

### ⑤の行き先は90日講座ではありません

無料のPDFを読んだ人に、いきなり90日のプログラムは遠すぎます。
**間にフロントセミナーがすでにあるので、そこを使います。**

### 診断PDFに足りないもの

**8ページ目に次の一歩がありません。** いちばん温まっている場所です。

```
見つけた3つを、LINEで送ってみませんか。
一緒に、次の「かけら」を探します。
```

書いたものを人に見せると、その人は自分の「できた」を認めやすくなります。
**診断そのものの効き目が上がります。**

## 6. LINEからMOSHへ戻す道がない

診断LPにもMOSHへのリンクを1本入れてください。

診断を受けている途中で「この人に直接相談したい」と思う人がいます。
**その人を7日間待たせる理由はありません。**

```
LP下部に1行： 　すぐに相談したい方は　▶ 無料個別相談（60分）
```

## 7. 9/26（土）に切り替えるもの

セミナーのページ（`mosh.jp/services/76e3ba8b…`）は、9/26で役目が終わります。
**それを指しているものが4か所あります。**

| どこ | いまの行き先 | 9/26以降 |
|---|---|---|
| note記事④ `note/chanto.md` のCTA | セミナー | 診断LP |
| Instagram プロフィールのリンク | セミナー | MOSHプロフィール |
| ジム掲示ポスター | セミナー | 貼り替え、または撤去 |
| Instagram 投稿のキャプション | セミナー | 過去投稿なのでそのまま |

**note記事④だけは診断LPに向けてください。** 記事の中身（「ちゃんと」の話）と
診断の中身がいちばん近いので、読み終わった人がそのまま入れます。

## 8. 一般向けは、すでに一通り揃っている

あとから分かったこと。一般向けは「これから作るもの」ではなく、
**選手向けと同じ形が、もう出来上がっています。**

| | 選手向け | 一般向け |
|---|---|---|
| 入口 | note記事 | できたのかけら診断 |
| 中間 | 9/26 セミナー | できたのかけらセミナー |
| 配布物 | ワークシート2種 | ワークシート |
| 本命 | 3か月 MY BEST LIFT PLAN | 90日間 目標達成プログラム |

**足りないのは中身ではなく、見えていないことだけです。**
MOSHに一般向けが1つも並んでいないので、外からは存在しないのと同じになっています。

### いつ入れるか

**構成には今すぐ。宣伝は9/26のあとで。**

MOSHに1つ並べるだけならコストはゼロで、
診断から来た人の行き先が、今日から存在することになります。

ただし**告知に力を割くのは9/26が終わってから**にしてください。
あと4日でセミナーです。ここで新しい講座の宣伝を始めると、両方が薄くなります。

### 企業向けを売るときにも効きます

人事の人が見ているのは「うちの社員に教えられるか」です。

| | 人事の人がどう読むか |
|---|---|
| 選手にしか教えたことがない | 「うちの社員はアスリートじゃないけど…」 |
| 一般の人にも90日で教えている | 「実績があるな」 |

**90日講座は、選手の仕事と企業の仕事をつなぐ橋です。**

## 9. 決めてほしいこと

1. **できたのかけら診断のURL**（プロフィールとLPに載せるため）
2. **診断の結果は何パターンあるか**（LINEの分岐を書くため）
3. **LINEはステップ配信を組んであるか**（まだなら、5通の原稿を書きます）
4. **法人向けの枠（③）を作るか**（作るならMOSHに1つ追加してください）
5. **90日間の講座の短い名前**（MY BEST LIFE PLAN でいくか、別案にするか）
