# なぜ3枚なのか

**セミナーの特典と、作りが違います。**

| | |
|---|---|
| セミナーの特典 | 栞さんが横で説明する前提。**空欄が多くていい** |
| **このシート** | **一人で読んで、一人でやる。だから説明が要る** |

そのため、各ページに「なぜこれをやるのか」を入れてあります。

---

# 第1回セミナー（9/26）で分かったことを、全部入れた

| 分かったこと | このシートでどうしたか |
|---|---|
| 「10個書いて」では止まる。質問を出したら書けた | **質問8つを先に印刷**。「3つ書いて止まったら」と書いてある |
| 10個は多い | **6個**にして、1行を広くした |
| 「やらないこと」は競技からは出ない。生活から出た | **欄を「競技」と「生活」に分けた**。生活の例も入れた |
| 「辞めた自分を認められなくなりそう」 | **「やめる」ではなく「置き換える」**。空いた時間に何を入れるかまで書かせる |
| 本人が書いた数字だけでは分類できない（山ピーの650kg） | **レップの記録欄**を入れた |

# 順番に意味がある

```
STEP1　数字を決める
STEP2　できたを数える　　← ここが2番目なのが大事
STEP3　やることを決める
```

**数字を決めたあとは、自信が減ります。** 高い数字を見たからです。
減ったままSTEP3に行くと、「足りない」から行動を決めることになります。

**間にSTEP2を入れると、「ここまでやってきた」から行動を決められます。**

# 最後のページが、個別相談への橋

```
書いてみて、数字が合っているか分からなくなったら。
60分の無料個別相談で、あなたの数字を一緒に見ます。
自分の数字を客観的に見るのは、一人ではいちばん難しいところです。
```

**これは本当のことです。** 山ピーさんは650kgを100点に置いていましたが、
試合ベストは610kg。レップから換算して120点に組み替えました。
**一人ではできなかったところです。**
