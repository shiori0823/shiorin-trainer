# 「私なんかが教えていいの？」自分の価値に気づき、起業するまでの10年間

「もっと勉強してから」
「もっと知識を身につけてから」
「もっと自信がついてから」

そう思って、なかなか一歩を踏み出せないことはありませんか？

私もそうでした。

自分の経験や知識が誰かの役に立つかもしれない。

そう思いながらも、自分にはお金をいただけるほどの価値があるとは思えなかったのです。

自分の仕事を持ちたいと思ってから、実際に個人で事業を始めるまで、約10年かかりました。

今日は、そんな私が一歩を踏み出せるようになるまでのお話をしたいと思います。

## 25歳、漠然とした夢を持っていた

> 📷1

25歳で教員を辞めたとき、私には一つの夢がありました。

「心と身体が綺麗になるサロンを作りたい」

でも、心と身体が綺麗になるって、具体的にどういうことなのか。

どんな人に、何を提供したいのか。

自分でも分かっていませんでした。

そもそも、個人で仕事をして食べていけるなんて思っていませんでした。

周りにそういう働き方をしている人もいなかったし、会社に勤めてお金をいただくものだと思っていたからです。

教員を辞めた後も教育関係の仕事を続け、ジムの仕事にも携わるようになりました。

それでも、自分の仕事を持ちたいという気持ちは、どこかにあり続けました。

たくさんお金を稼ぎたいというよりも、私がやってきた証拠が欲しかったのだと思います。

誰かの役に立っている。

自分の仕事には意味がある。

そんな実感が欲しかったのです。

## 資格を取ったら、自信がつくと思っていた

身体について学び、レッシュトレーナーの資格を取得しました。

でも、資格を取得したことで、むしろ不安は大きくなりました。

「私の指導で、相手の身体をもっと悪くしてしまったらどうしよう」

人の身体に関わることだからこそ、指導することが怖くなったのです。

さらに、

「そもそも、トレーナーは私が本当にやりたいことなのかな？」

という疑問もありました。

私はその気持ちに蓋をしました。

そして、自分が指導することよりも、ジムのオーナーである夫の価値を届けるための勉強をするようになりました。

夫の指導には信頼を置いていました。

だから、夫のパーソナルトレーニングにつなげることが、私の役目だと思っていました。

オーナーの価値なら信じられる。

でも、自分自身の価値となると、信じることができない。

パワーリフティングで日本一になった経験もある。

教員として人に教えてきた経験もある。

それでも、自分の経験がお金をいただけるほどの価値になるということが、ピンときていませんでした。

## 好きなことでお金をもらっていいの？

そんな私が、自分の価値に気づくきっかけとなったのが、ダイエットコーチングでした。

目の前に、ダイエットで困っている人がいたのです。

私は自分自身がダイエットをできていたので、その経験を伝えようと思いました。

最初は無料モニターとして協力してもらいました。

私のサポートで、本当に相手に変化が起きるのか。

実際にやってみることで、私自身も自信をつけていきました。

相手が変わっていく姿を見て、

「ああ、やってよかったな」

と思いました。

その方は数年後、今度は有料でコーチングを受けてくださり、さらに成果を出してくれました。

それでも、有料でコーチングを提供することには、違和感がありました。

「話を聞くだけなのに、お金をいただいていいの？」

昔の私は、嫌なことをするからお金をもらえるのだと思っていました。

大変なことをする。
我慢する。
苦労する。

その対価がお金だと思っていたのです。

だから、自分が好きなこと、自分にとって痛くも痒くもないことでお金をいただいていいのか、分かりませんでした。

どうやら私は、質問することが得意らしいのです。

学生時代から、自然とコーチングのようなことができていることには気づいていました。

教員になってからも、生徒と話すことは日常の一部でした。

自分にとっては、特別なことではなかったのです。

でも、夫との関わりや実際のコーチングを通して、その質問力が誰かの役に立つことに気づいていきました。

そして、お金をいただくことは、私のためだけではないことにも気づきました。

お金を支払うことが、相手にとっても「変わる」という覚悟を決めるきっかけになる。

相手の変化を本気でサポートするためにも、お金をいただくことには意味があるのだと考えるようになりました。

## 競技では挑戦できるのに、ビジネスでは挑戦できない

> 📷2

ジムのサービスとしてコーチングを提供できるようになっても、個人で事業を始める方法は分かりませんでした。

そこで、AIを活用した講座づくりやマーケティング、文章の書き方、サービスの届け方などを学び始めました。

今回の学びがこれまでと違ったのは、課題を提出しながら、小さく実践できたことです。

そして、講師の方から教えていただいた言葉が、私の考え方を変えるきっかけになりました。

「最初はエセでいい」

「成功している人はたくさん失敗している」

私はパワーリフティングという競技を10年以上続けています。

バーベルが挙がらなかったとしても、落ち込んで終わるのではなく、どうすれば次は挙げられるのかを考えます。

競技では、挑戦して改善することが当たり前でした。

その考え方をビジネスにも活かせることは、ずっと分かっていたのです。

それでも、踏み出せませんでした。

なぜなら、ビジネスで失敗することは、誰かに迷惑をかけることだと思っていたからです。

でも、小さく実践を繰り返す中で、気づきました。

お客様が来なかったら、届け方を改善すればいい。

自分が責任を持って提供できることであれば、最初から完璧である必要はない。

競技と同じように、挑戦したからこそ分かることがある。

私が失敗だと思っていたことの多くは、次に向けた改善点だったのです。

## 私が勇気を出すことで、幸せになる人がいる

> 📷3

講師の方からいただいた言葉の中で、特に心に残っているものがあります。

「目の前に助けられる人がいるのに、手を差し伸べないのは失礼だ」

それまでの私は、自分が行動することで、誰かに迷惑をかけてしまう可能性ばかりを考えていました。

でも、その反対の可能性を考えていなかったのです。

私が行動することで、助かる人がいるかもしれない。

私が経験を伝えることで、前に進める人がいるかもしれない。

私が勇気を出すことで、幸せになる人がいるかもしれない。

実際に自分でサービスを企画し、お客様に案内し、お金をいただいて提供することができたとき、本当に嬉しかったです。

もちろん、自分の商品が売れたことも嬉しかった。

でも、それ以上に嬉しかったのは、自分が勇気を出して行動したことで、喜んでくれる人がいることを目の当たりにできたことでした。

ずっと考えていたのは、

「私にできるだろうか」

ということ。

でも、本当に考えたいのは、

**「目の前の人に、私ができることは何だろうか」**

ということだったのです。

## 10年越しに踏み出した、新しい一歩

> 📷4

2026年10月1日。

35歳になった私は、ジムの仕事とは別に、自分個人の事業をスタートさせました。

25歳の頃から約10年。

決して、事業として大きな成功を収めたわけではありません。

まだまだ挑戦の途中です。

それでも、あれほど踏み出せなかった一歩を踏み出すことができました。

今はメンタルトレーナーとして、人の可能性を信じ、その人が前に進むためのサポートをしています。

そして、ジムでは身体を整えることにも関わっています。

25歳の頃に思い描いていた、

「心と身体が綺麗になるサロンを作りたい」

という夢。

サロンという形ではないけれど、私がやりたかったことは、もう叶っているのかもしれません。

## 困っている人を見捨てないであげて

もし今、あなたが、

「私なんかが人に教えていいのかな」

「私の経験なんて、大したことない」

「もっと勉強してからじゃないと」

と思っているなら、一度考えてみてほしいことがあります。

あなたが乗り越えてきたことに、今、悩んでいる人はいませんか？

あなたが当たり前にできることで、困っている人はいませんか？

あなたが過去に欲しかった言葉を、今、必要としている人はいませんか？

自分にとって当たり前のことが、誰かにとっては当たり前ではないことがあります。

自分では気づいていない価値を、すでに持っているかもしれません。

もちろん、知らないことまで教える必要はありません。

できないことまで引き受ける必要もありません。

でも、今のあなたにできることで、目の前の人を助けられるのなら。

困っている人を見捨てないであげて。

自信がつくまで待たなくてもいい。

私も、人の役に立てたという小さな経験を積み重ねながら、自分の価値に気づいていきました。

あなたが勇気を出して踏み出す一歩が、誰かの人生を前に進めるきっかけになるかもしれません。

そして、その一歩が、あなた自身の人生を変えるきっかけにもなるかもしれません。

私はこれからも、メンタルトレーナーとして、一人ひとりが持っている可能性を信じ、挑戦する人をサポートしていきたいと思っています。

このnoteでは、私自身が経験してきたことや、挑戦する中で気づいたことをお伝えしていきます。

あなたが自分の可能性に気づき、前に進むためのきっかけになれたら嬉しいです。

最後まで読んでくださり、ありがとうございます。

# よかったところ

## 「嫌なことをするからお金をもらえるのだと思っていた」

**この記事でいちばん強い一文です。**

```
大変なことをする。
我慢する。
苦労する。

その対価がお金だと思っていたのです。
```

起業までの話は世の中にたくさんありますが、
**「何が自分をとめていたのか」を、ここまではっきり名指しした文章は少ないです。**

「自信がなかった」で済ませていません。
**自信がなかった理由の、さらに下まで降りています。**

## 「競技では挑戦できるのに、ビジネスでは挑戦できない」

**この対比は、栞さんにしか書けません。**

日本一になるまで挑戦し続けた人が、ビジネスでは踏み出せなかった。
**同じ人の中に、両方があったという事実が効いています。**

そして、理由も書いてあります。

```
ビジネスで失敗することは、誰かに迷惑をかけることだと思っていたから
```

**ここで読者は「自分もそれだ」と気づきます。**

## 「困っている人を見捨てないであげて」

**いちばん強い言葉を、最後に1回だけ使っています。**

命令形です。
記事の最初から最後まで、ずっと自信のない話をしてきた人が、最後にこれを言う。

**ずっとためらっていたからこそ、この一行が届きます。**

最初に言っていたら、説教になっていました。

## お金の話に、答えを出していること

```
お金を支払うことが、相手にとっても「変わる」という覚悟を決めるきっかけになる。
```

**「好きなことでお金をもらっていいの？」に、きちんと答えています。**
ここを曖昧にしたまま終わる記事が多いところです。

# 提案（2つだけ）

## 提案1　「質問することが得意らしい」を、見出しにする

いま、この一文は「好きなことでお金をもらっていいの？」の節の中に、
**段落のひとつとして入っています。**

```
どうやら私は、質問することが得意らしいのです。
```

**これは、この記事でいちばん大事な発見です。**

```
自分の価値 ＝ 質問すること
```

記事のタイトルは「自分の価値に気づき」です。
**その「価値」が何だったのかが、ここに書いてあります。**

見出しを1つ立てて、独立させることをおすすめします。

```
例　「どうやら私は、質問することが得意らしい」
```

**いまは、お金の話にまぎれて通りすぎてしまいます。**

## 提案2　講師の方のお名前を出すかどうか

3つの言葉を引用しています。

```
「最初はエセでいい」
「成功している人はたくさん失敗している」
「目の前に助けられる人がいるのに、手を差し伸べないのは失礼だ」
```

**いまは「講師の方」とだけ書いてあります。**

お名前を出すかどうかは、栞さんの判断です。

```
出す　　相手への敬意になる。関係が見える
出さない　読者が「誰の話か」を気にせず読める
```

**どちらでも成立します。** ただ、3つも引用しているので、
一度考えておいたほうがいいところだと思います。

# 気づいたこと

**この記事でやっていることは、栞さんが仕事でやっていることと同じです。**

```
自分にとって当たり前のことが、誰かにとっては当たり前ではないことがあります。
自分では気づいていない価値を、すでに持っているかもしれません。
```

これは、「できたのかけら」のルールそのものです。

```
ルールは1つ。「こんなの当たり前」は禁止です。
```

**選手に言っていることを、読者に向けて言っています。**
そして、**自分にも言っています。**

`strategy/core.md` に書いた
「人がすでに持っているものを、使える形にする」が、
**この記事では読者に対して行われています。**

**意識して書いていないなら、それが一番いいです。**
考え方が身についているということなので。
