# 3ステップは、ご本人の手順に差し替え済み（2026-10-07）

```
① 足の裏全体で、床を捉えられていますか
② 足の裏に骨盤、骨盤の上に頭が乗っていますか
③ 力まずに、動けるか確かめましょう
```

**実際には7つある**うちの3つ。
記事には「一人でもできる3つに絞りました」と書いてあります。

### 7つのうち3つ、と書いてある理由

```
全部書く　→　読んで終わり。来る理由がない
3つ書く　 →　やってみられる。残りがあると分かる
```

**出し惜しみではなく、一人でできる範囲で区切っています。**
残り4つは、見てもらわないと確かめられないものです。

### 足すとしたら

```
やってしまいがちな間違い（例：胸を張ってしまう）
```

**1つあると、読者が自分で直せます。** 入れたい場合は②のあとに1行。

# 「ちゃんと」は使っていません（2026-10-07）

本文から全部外しました。以後、この言葉は使いません。

| 元 | 直したもの |
|---|---|
| ちゃんと立つことです | **正しく立つ**ことです |
| ちゃんとここに立てている | **正しく立てている** |
| 立ち直しました | **正しく立ち直しました** |

**「立つ」は、この記事では「正しく立つ」で統一しています。**

# ★ なぜ「やり方」が必要だったか

```
読むだけ　→　「よさそう」　→　「で、どうやるの？」　→　終わり
やってみる→　「あ、違う」　→　身体で分かる　　　　　→　また読みに来る
```

**noteで残る記事は、その場でやってみられる記事です。**

とくに今回は5DAYSへの導線なので、
**「この人の言うことは、やると変わる」**を先に体験してもらう必要があります。

# なぜパワーリフターを隠さないか

一般の方向けだからといって、競技の話を全部消すと**ただのいい話**になります。

```
日本記録を出した人が「いちばん大事なのは立つこと」と言う
```

**この落差が、この記事の説得力です。** 1行だけ置いてあります。
