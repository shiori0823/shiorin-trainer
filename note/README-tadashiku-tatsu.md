## 「実際に、やってみてください」の3ステップ

私が知っているのは、**10/3に山ピーさんへ伝えた言葉だけ**です。

> 正しく立って、正しく座る。背もたれは使わない。
> **頭が骨盤の上から外れちゃうと、筋肉を使って座ることになるから負担なんですよ。**

ここから書いたのが、この3つです。

```
① まず、ゆるめる
② 頭を、骨盤の上に置く
③ 力を抜いたまま、動けるか確かめる
```

**②は栞さんの言葉そのままですが、①と③は私が補いました。**

実際に伝えているときの手順と違っていたら、**そこだけ書き換えてください。**
足したい手がかりがあれば、足してください。

### 足すとしたら、ここが効きます

```
・足の裏のどこに体重が乗っていればいいか
・骨盤の向き
・やってしまいがちな間違い（例：胸を張ってしまう）
```

**「やってしまいがちな間違い」が1つあると、読者は自分を直せます。**

# ★ なぜ「やり方」が必要だったか

```
読むだけ　→　「よさそう」　→　「で、どうやるの？」　→　終わり
やってみる→　「あ、違う」　→　身体で分かる　　　　　→　また読みに来る
```

**noteで残る記事は、その場でやってみられる記事です。**

とくに今回は5DAYSへの導線なので、
**「この人の言うことは、やると変わる」**を先に体験してもらう必要があります。

**この落差が、この記事の説得力です。** 1行だけ置いてあります。
