# 「実際に、やってみましょう」

本人の言葉のまま。

```
足の裏の感覚。
足が、足裏全体で捉えていますか？

足の裏に骨盤、骨盤の上に頭が乗っていますか？

体が力まず、動けるか確かめてみましょう。
```

**実際には7つある**うちの3つ。記事にもそう書いてある。

```
全部書く　→　読んで終わり
3つ書く　 →　やってみられる。残りがあると分かる
```
