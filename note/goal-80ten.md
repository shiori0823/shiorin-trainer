# 本文ここから

目標を、高く決めすぎていませんか。

真面目な人ほど、そうなります。
「どうせやるなら、ここまで行きたい」と思って、いまの自分からかなり遠い数字を
置いてしまう。

その気持ち自体は、悪いものではありません。

でも、そこには落とし穴があります。

> 📷 `images/01-squat.jpg`（2024年度JCPのスクワット）

## 失敗体験だけが、積み上がっていく

遠すぎる数字を置くと、何が起きるか。

**毎回、届きません。**

そうすると、試合が終わるたびに残るものが「今回も駄目だった」になります。
次の試合でも届かない。また駄目だった。

これを1年、2年と続けると、どうなるか。

**成功体験がひとつも積み上がらないまま、失敗体験だけが積み上がります。**

体は強くなっているのに、自信だけが減っていく。
そういう選手を、何人も見てきました。

私自身もそうでした。

2023年度の日本グランプリ。スクワットの日本記録を取るつもりで臨みました。
試合の直前に体調を崩して、点滴を打って、予定していた重量から大幅に下げました。

結果は、日本一でした。

でも、そのとき私の中にあったのは、これだけでした。

**「取れなかった」**

日本一という結果は、目に入っていませんでした。
狙っていた数字に届かなかったから、この試合は失敗だった。
そういう処理しか、当時の私は持っていませんでした。

**手元には、何も残りませんでした。**

## その数字、本当に100点満点ですか

ここからが本題です。

あなたが「次はここまで行きたい」と思っている数字。

**それは、何点満点の数字ですか。**

多くの人は、それを100点だと思っています。
だから、届かなければ0点になります。

でも実際には、**それが120点であることがとても多いんです。**

120点というのは、その人が思い描いている理想です。
いつか届きたい、夢の数字。

- 取れたら最高。文句なし
- でも、いまの自分からは正直、遠い
- 条件がそろわないと、現実的には厳しい

これは、**満点ではなく、満点を超えた数字**です。

その自覚があるかないかで、まったく話が変わります。

夢の数字を毎回の目標にして、届かなくて落ち込む。
これを繰り返しているなら、置く場所が間違っています。

**「これは120点だ」と認めた瞬間に、100点と80点を置く場所が空きます。**

## 3つの数字を置く

やることは、これだけです。

```
120点　理想。いつか届きたい夢の数字
100点　ちょっと背伸びしたら、いける。ここを常に狙う
 80点　確実にいける。絶対に取る
```

数字で書くと、こうなります。
83kg級で、標準記録のトータル700kgを狙っている選手の場合です。

```
120点　710〜720kg　　理想。夢の数字
100点　700.0kg　　　 標準記録の突破。常にここを狙う
 80点　687.5kg　　　 確実に取る
```

いままで「700が取れなければ0点」だった人が、
**687.5を確実に取りにいきながら、700を狙う**形に変わります。

## 80点は、落ち込まないためのラインです

3つのうち、絶対に手を抜いてはいけないのが80点です。

ここで誤解されやすいので、はっきり書きます。

**80点は、妥協ラインではありません。必達ラインです。**

「ここまでなら、まあ届くだろう」ではなく、
**「これは絶対に取る」**という数字を置きます。

なぜここが一番大事なのか。

**確実に取れる数字を置くから、試合のたびに成功体験が残るからです。**

さきほどの例でいえば、その日700が乗らなかったとします。
でも687.5は取れた。

**そこで落ち込む必要は、ありません。**

80点は取れているからです。
狙っていた100点には届かなかった。それは事実です。
でも、決めた必達ラインは越えている。

これは、失敗ではありません。

失敗体験ばかりを積んできた人に、いま本当に必要なのはこれです。
体はすでに強くなっています。
足りていないのは、**取れた、という記憶**のほうです。

> 📷 `images/03-deadlift.jpg`（2024年度JCPのデッドリフト）

## ただし、狙うのは常に100点です

ここを外すと、全部が台無しになります。

**80点は、あくまで落ち込まないためのラインです。**
狙いにいく数字ではありません。

**試合で狙うのは、常に100点です。**

当たり前のことを書きますが、大事なところなので書きます。

**100点を狙っていかないと、標準記録は取れません。**

80点だけを取りにいく選手は、80点の選手のままです。
毎回100点に手を伸ばして、届いたり届かなかったりしながら、
**届かなかった日も80点は確保できている。** この形が理想です。

そして、80点が安定して取れるようになったら、次はこうします。

**次の試合、次のシーズンで、100点を取りにいきます。**

3つの数字は、一度決めたら固定するものではありません。
80点が当たり前になったら、全体を上げます。
そうやって、120点だった数字に近づいていきます。

## 「それは目標を下げることでは？」

必ず聞かれます。違います。

**狙う数字は、下げていません。** 100点は常に狙います。
120点も、持ったままでかまいません。

やっているのは、**どの数字にどのラベルを貼るかを変えただけ**です。

夢の数字を「100点」と貼っていたから、毎回0点になっていた。
それを「120点」と貼り直して、現実的に狙える数字を「100点」に置く。
それだけです。

むしろ、逆のことが起きます。

100点か0点かで見ていると、人は無意識に目標を低く見積もりはじめます。
0点になるのが怖いからです。

3つの数字を置けるようになると、**思いきり高い120点を持っていられます。**
それを毎回の判定基準にしないと決めたから、持っていても苦しくないんです。

## 大事なのは、試合の前に決めること

ひとつだけ、守ってほしいことがあります。

**3つの数字は、必ず試合の前に決めてください。**

試合が終わってから「まあ、ここまでできたし」と考えるのは、点数表ではなく
言い訳です。

同じ言葉でも、**先に決めてあるか、後から言っているか**で、まったく別のものに
なります。先に決めてあれば、それは計画です。

## 私のその後

日本グランプリのあと、私は考え方を変えました。

同じ年度のJCPでも、日本一になりました。記録はまだ取れていませんでした。
以前の私なら、ここで折れていたと思います。

でも、折れませんでした。
その試合で自分が何点まで行けたのかが、分かるようになっていたからです。

そして翌年、2024年度のJCPで、狙っていたスクワットの日本記録を取りました。

記録を取れたから考え方が変わったのではありません。
**考え方を変えたから、そのあとに記録がついてきました。** 順番は、こちらです。

## 今日、1つだけやってみてください

紙でも、スマホのメモでもかまいません。

いま頭にある「次の試合で行きたい数字」を書いてください。

そのあと、その横に書き足します。

**これは、120点ですか。100点ですか。**

もしそれが120点だったなら、その下に2つ書き足してください。

**100点**　ちょっと背伸びしたら届く数字。次の試合で狙う数字
**80点**　　確実に取れる数字。絶対に取ると決められる数字

狙うのは100点です。
そして、届かなかった日に落ち込まないための線が、80点です。

それだけで、次の試合の意味が変わります。
そして、そこに向かう今日の練習の意味も変わります。

## この記事の役割

記事①（自己紹介）、記事②（不安の分解・STEP1）に続く**3本目**です。
①が「私はこういう人間です」、②が「不安への向き合い方」、この③が
**「目標の立て方」**にあたります。

### 誰に向けた記事か

**目標を高く決めすぎてしまう人**です。理想が高くて、いまの自分から遠い数字を
追いかけてしまう人。真面目な選手ほどここに落ちます。

その人に何が起きているかというと、**成功体験がひとつも積み上がらないまま、
失敗体験だけが積み上がっている**状態です。体は強くなっているのに、自信だけが
減っていきます。この記事は、そこを止めるためのものです。

### この記事の一番の勘どころ

**「その数字は120点だ」と本人に自覚してもらうこと**です。

多くの人は、自分が狙っている数字を100点だと思っています。だから届かなければ
0点になります。まずそこに「120点」というラベルを貼り直してもらうと、100点と
80点を置く場所が空きます。**順番を逆にしないでください。**

そして80点は、**合格点ではなく必達ライン**です。「ここまでなら届くだろう」
ではなく「これは絶対に取る」。確実に取れる数字を置くから、試合のたびに
成功体験が残ります。

**もうひとつ、絶対に外せないのが「狙うのは常に100点」**という部分です。
80点は落ち込まないための線であって、狙いにいく数字ではありません。
100点を狙っていかないと標準記録は取れない——ここを書かないと、記事全体が
「目標を下げましょう」という話に読まれます。そして80点が安定したら、
次の試合・次のシーズンで100点を取りにいく。この進み方までがセットです。

**読んだ人がその場で1つ行動できる**ように作ってあります。最後の「その数字は
何点満点か書いてみる」がそれです。ここが実行されると、無料個別相談に来たときに
話が早くなります（すでに自分の数字を持った状態で来ます）。
