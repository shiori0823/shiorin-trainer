## リンクの書き方

noteのエディタは `[テキスト](URL)` というマークダウンのリンク記法を変換しません。
カッコごと文字として表示されてしまうため、この記事では**URLだけを1行に置く**
形にしています。noteに貼ると自動でリンクになります。

note以外（LINEやInstagramのプロフィール欄など）に貼る場合は、末尾に
`?openExternalBrowser=1` を付けた形を使ってください。アプリ内ブラウザではなく
外部ブラウザで開かせるための指定です。

```
https://mosh.jp/services/404875?openExternalBrowser=1
```
