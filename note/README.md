# note記事

- `mental-training-story.md` … 記事本文。`> 📷` の行が写真を入れる位置の目安です
  （noteに貼ったあと、その行は削除して写真に置き換えてください）
- `images/` … 記事で使う写真

## 写真

| ファイル | 使う場所 |
|---|---|
| `header.jpg` | 記事の見出し画像（カバー）。noteの推奨サイズ 1280×670 で書き出し済み |
| `01-squat.jpg` | 「2023年度の日本グランプリで、試合直前に体調を崩した」の章 |
| `02-podium.jpg` | 「同じ2023年度のJCPで、日本一になることができました」の直後 |
| `03-deadlift.jpg` | 「世界大会の舞台に立てたことが、本当に楽しかった」の章 |
| `04-gym.jpg` | 記事の最後、無料個別相談の案内の直前 |

写真はすべて縦横の向きを焼き込み済みなので、スマホから上げても回転しません。
長辺1280pxで、noteの表示に必要な解像度は確保しています。

`02-podium.jpg` が JCP の表彰台でない場合は、キャプションに実際の大会名を
入れてください。書かないと、直前の「日本一になった」という文の写真に見えます。

## リンクの書き方

noteのエディタは `[テキスト](URL)` というマークダウンのリンク記法を変換しません。
カッコごと文字として表示されてしまうため、この記事では**URLだけを1行に置く**
形にしています。noteに貼ると自動でリンクになります。

note以外（LINEやInstagramのプロフィール欄など）に貼る場合は、末尾に
`?openExternalBrowser=1` を付けた形を使ってください。アプリ内ブラウザではなく
外部ブラウザで開かせるための指定です。

```
https://mosh.jp/services/a83404f4de13474387bddb855afa44d5?openExternalBrowser=1
```
