# 表紙　──　87個のリストのスクショを推します

**自分の写真ではなく、リストの画面です。**

## 理由は3つ

**① この記事の主役は、数字だから**

```
87個
```

タイトルに数字が入っています。**その数字が、表紙で見えるのがいちばん速いです。**

**② 小さく表示されても、伝わるから**

タイムラインでは、表紙が小さく出ます。

```
顔の写真　　→　「誰かの話だな」
長いリスト　→　「うわ、多い」
```

**文字が読めなくていいんです。「量がある」ことだけ伝わればいい。**

**③ 記事⑥と、見た目を分けられるから**

**⑦のすぐあとに⑥を出す予定です。**

```
⑦　リストの画面
⑥　スタジオで撮った写真
```

**両方とも自分の写真だと、タイムラインで同じ記事に見えます。**
並ぶ2本は、表紙を変えたほうがいいです。

## 撮るときの注意

**タイトルが読める大きさにしないでください。**

```
夫婦関係　産後　お金　欲望リスト
```

**87個の中には、まだ書くと決めていないものが入っているはずです。**
読める大きさで出すと、**「あの話はいつ書くの？」と先に期待されます。**

```
全体を引いて、びっしり並んでいる様子だけ見せる
または、一部をぼかす
```

**「多い」が伝わればいい。中身は見せなくていいです。**

## 表紙の別案

```

```

**どちらも「作業したあと」が写っています。** それがこの記事に合います。

# 発信するネタがない？「普通の人生」から87個の発信ネタを見つけた方法

何か発信したい。

でも、何を書いたらいいんだろう？

自分には、人に伝えられるような経験がどれくらいあるんだろう？

そんな疑問から、私は自分の人生を振り返ってみることにしました。

その結果、見つかった発信ネタは87個。

しかも、まだまだ出てきそうなんです（笑）。

今日は、その方法と、実際にやってみて感じたことをお伝えします。

## 文章を書ける人になりたい！

きっかけは、あるYouTubeの動画でした。

自分の経験をコンテンツにしよう、という内容の動画です。

その中で、文章を書く人と、書かずに読むだけの人では、月収100万円と年収100万円ほどの差が生まれる、という趣旨の話がありました。

もちろん、この数字が誰にでも当てはまるわけではありません。

でも、その話を聞いて、私は思ったんです。

「私も書ける人になりたい！」

そこで、ふと疑問が湧きました。

そもそも、私にはどんな文章が書けるんだろう？

私が経験してきたことの中に、誰かの役に立てるものはあるのかな？

そこで始めたのが、100個の実体験を発掘するプロジェクトです。

## AIにインタビューしてもらう

> 📷1

今回、私が活用したのはChatGPTです。

自分の人生を振り返りながら、AIに一つずつ質問をしてもらい、それに答えていくという方法です。

ポイントは、新しい発信ネタを考えてもらうのではなく、**すでに自分が経験してきたことを掘り起こしてもらうこと。**

その中で印象的だったのが、学生時代についての質問でした。

「学生時代、どんなことがコンプレックスでしたか？」

そこまで遡るんだ！

と思いました。

私は昔、自分のお尻が大きいことがコンプレックスでした。

制服を着ても、ジャージを着ても、お尻が大きいことが嫌だったんです。

でも、今はどうでしょう。

トレーニングを始めてからは、むしろ大きくしたいと思っているし、自分の好きな部分にもなっています。

昔は嫌だったものが、今では好きなものになっている。

AIからさらに理由を聞かれ、深掘りしていくことで、いつの間にか自分がコンプレックスを克服していたことに気づきました。

自分一人で発信ネタを考えていたら、学生時代のコンプレックスまで振り返ることはなかったかもしれません。

## え？こんなこともネタになるの？

私はパワーリフティングという競技をしていて、日本一になった経験があります。

そういった経験は、発信ネタとして比較的思いつきやすいものです。

でも、今回面白かったのは、それ以外の経験もたくさん出てきたこと。

特に、子育ての話です。

例えば、離乳食。

一人目のときは、本を見ながら、食材や量、食べさせる時間などを気にしていました。

二人目の今は、食べてくれればOK！

市販の離乳食も活用するし、食べやすさに合わせて調整しています。

ほかにも、

・子どもに怒らないようにしようと思っていたけれど、怒らないなんて無理だと気づいた話

・人の意見を基準にしていた私が、自分の好きなものを選べるようになった話

・欲しいものを聞かれても答えられなかった私が、欲望リストを書くようになった話

・夫と私では、同じ目標に向かうにも考え方の順番が違うと気づいた話

こんなことまで、発信ネタの候補になりました。

何か大きなことを成し遂げた経験だけが、発信ネタになるわけではないんですよね。

以前はできなかったけれど、今はできること。

以前は悩んでいたけれど、今は気にならなくなったこと。

以前とは考え方が変わったこと。

そんな日常の中にも、伝えられることはたくさんありました。

## 実際に見つかった87個の発信ネタ

今回見つかった発信企画をジャンル別に分けると、こんな内訳になりました。

| ジャンル | 企画数 |
|---|---:|
| 自己肯定感・自分らしい生き方 | 14個 |
| 恋愛・夫婦関係 | 10個 |
| パワーリフティング・目標達成 | 17個 |
| 子育て・産後・家族 | 12個 |
| お金・欲望・マイルール | 6個 |
| 起業・挑戦・サービス | 15個 |
| ジム経営・マーケティング・AI | 11個 |
| 習慣・日々の達成 | 2個 |
| **合計** | **87個** |

競技や目標達成に関する話は17個。

それ以外の70個は、仕事や子育て、人間関係、自分自身の考え方などから生まれた発信企画です。

もちろん、一つの経験から違った切り口で生まれた企画もあります。

こうして並べてみると、人生のあらゆる分野に発信ネタが眠っていることが分かります。

今、何かに挑戦していなくてもいい。

特別な資格や実績がなくてもいい。

これまでどんなことに悩み、何を考え、どんな選択をしてきたのか。

そこに、あなただからこそ書ける文章のヒントがあるのかもしれません。

## 発信ネタを見つけるための4つのポイント

今回の実体験発掘を通して、発信ネタを見つけるためのポイントを整理してみました。

### ① 今だけでなく、過去の自分にも目を向ける

幼少期、学生時代、社会人になった頃。

今の自分にとっては当たり前のことでも、昔の自分にとっては難しかったことがあるかもしれません。

### ② 過去と現在を比べてみる

昔はどうだった？

今はどうなっている？

その違いの中に、自分の成長や変化が隠れています。

### ③ なぜ変わったのかを深掘りする

何がきっかけだったのか。

どんな行動をしたのか。

どんな考え方に変わったのか。

そこまで振り返ることで、誰かの役に立つヒントが見つかるかもしれません。

### ④ 経験の大小で判断しない

こんなこと、誰でもやっている。

こんな話、誰も興味ないだろう。

そう思っていることこそ、一度振り返ってみてほしいです。

自分にとっての当たり前が、誰かにとっては知りたいことかもしれないからです。

## 87個の発信ネタよりも嬉しかったこと

> 📷2

最終的に、87個の発信企画が見つかりました。

100個を目標にしていましたが、今回は87個で一区切り。

もちろん、これらすべてに需要があるかどうかは、これから発信しながら確かめていきます。

でも、今回のプロジェクトで得られたものは、発信ネタだけではありませんでした。

辛かった過去もあった。

悩んだこともあった。

乗り越えてきたこともあった。

その一つひとつの経験が、今の私を作っている。

そう思うと、自分の人生がなんだか誇らしくなったんです。

発信ネタを探すために始めたのに、まさかこんな感情が生まれるとは思っていませんでした。

そして、もう一つ。

「これから何があってもネタになるな！」

と思えるようになりました（笑）。

うまくいくことも、うまくいかないこともあると思います。

でも、いつかその経験が誰かの役に立つかもしれない。

そう考えると、これからの人生も楽しみになりました。

## あなたも、自分の人生を発掘してみませんか？

発信をしている人も、していない人も。

起業している人も、していない人も。

一度、自分の人生を振り返ってみてほしいなと思います。

そこで、今回の実体験発掘をもとに、ChatGPTで使えるプロンプトを作りました。

難しい準備は必要ありません。

以下の文章をコピーして、ChatGPTに送ってみてください。

あとは、質問に答えていくだけです。

### 【コピペOK】実体験発掘プロンプト

あなたは、私の人生に眠っている実体験を発掘するインタビュアーです。

私がこれまで経験してきたことの中から、誰かの役に立つ可能性のある発信ネタを一緒に見つけてください。

目標は100個の発信企画を見つけることです。ただし、数を達成することよりも、実際の経験を丁寧に掘り起こすことを優先してください。

【インタビューのルール】

・質問は必ず一つずつしてください。

・私の回答を待ってから、次の質問をしてください。

・幼少期、学生時代、仕事、恋愛、人間関係、家族、子育て、趣味、健康、お金、習慣、挑戦など、幅広い分野から質問してください。

・過去の悩みやコンプレックス、以前はできなかったこと、考え方が変わったことを深掘りしてください。

・過去と現在の違いだけでなく、変化のきっかけや実際に取った行動についても質問してください。

・大きな成功体験だけでなく、日常の小さな変化や工夫にも目を向けてください。

・過去との変化がなくても、私が実践していることや大切にしている考え方を発掘してください。

・私自身が「こんなことは当たり前」と思っている経験についても、発信ネタになる可能性を検討してください。

・私が実際に話した経験だけを発信ネタにしてください。事実を推測したり、成功体験を作り上げたりしないでください。

・まだ解決していない悩みを、乗り越えた経験として扱わないでください。

・話したくないことや公開したくないことは、無理に深掘りしないでください。

・発信ネタが見つかったら、企画タイトルと番号をつけて記録してください。

・一つの経験から複数の切り口が見つかった場合は、その違いを明確にしてください。

・似た内容は重複している可能性があることを伝えてください。

・発信企画の累計数を伝えてください。

・私が終了を希望したら、これまでに見つかった発信企画を分野別に一覧にしてください。

まずは、最初の質問から始めてください。
