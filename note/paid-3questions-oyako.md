# ★ 読む人は子ども。買う人は、親

この記事は、**子どもに直接話しかける形**で書かれています。
それでいいと思います。読んだ子が、自分でやれる形になっています。

ただ、**500円を払うのは子どもではありません。**

```
読む人　　小学5年生
買う人　　保護者
```

**親が無料部分を読んで、「これはうちの子に読ませたい」と思わないと、買われません。**

いまの無料部分は、最初から子どもに向かって話しています。
親が読んだときに、**自分に向けられた言葉が1つもありません。**

## 提案1　いちばん最初に「おうちの方へ」を3〜4行

```

この記事は、お子さんが読めるように書いています。
```

**これだけで、親が買う理由になります。**

そして本文は、いまのまま子どもに向かって話し続けて大丈夫です。
**最初の4行だけ、親に向ける。** それで両方に届きます。

## しつもん① できたときと、できなかったとき、何がちがった？

「今日はいつもよりタイムがおそかった」
