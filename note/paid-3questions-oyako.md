# 「できない」と言う子どもに、答えを教える前にできること
## ― 親子でできる、3つの質問 ―

「できない」
「むずかしい」
「ぼく、へたなんだと思う」

子どもがそう言ったとき、どうしていますか。

わたしは、つい答えを言いたくなります。

「こうやってみたら？」
「もっとこうすればいいよ」

その助言は、たぶん正しいです。
でも、言われた子どもは、こう覚えることがあります。

**「困ったら、誰かに答えをもらえばいい」**

これは、親が悪いのではありません。
子どもが「できない」と言っているのを見るのは、つらいからです。

この記事では、答えを教える前に、親子で一緒にできる3つの質問をお伝えします。

**うまくいかないときに、自分で考えられるようになるための質問です。**

## なぜ、答えを教えないのか

> 📷1

答えを教えると、その場は解決します。

でも、同じことがまた起きたとき、子どもはまた聞きに来ます。
聞ける人がそばにいないとき、止まってしまいます。

試合の日。
テストの最中。
友だちとの間で、何かあったとき。

**親が、いつもそばにいられるわけではありません。**

だから、答えではなく、**考え方を渡しておきたいのです。**

といっても、むずかしいことをするわけではありません。
やるのは、**3つ質問するだけ**です。

## 「しゃがめない」のは、結果であって、原因ではない

> 📷2

わたしはパワーリフティングという競技を11年続けています。
いまは、選手のメンタルサポートもしています。

以前、スクワットで深くしゃがめないことに悩んでいた選手がいました。

その選手は、深くしゃがもうと意識していました。
もちろん、その意識も大切です。

でも、わたしはこう伝えました。

**「しゃがめない」は、いま起きている事実です。**
**しゃがめないという結果と、しゃがめない原因は、別のものです。**

足幅なのか。手幅なのか。バーを乗せる位置なのか。
そうしたものが少し違うだけで、動きは変わります。

だから、ただ「しゃがもう」と意識し続けるのではなく、
**前にしゃがめていたときと、何が違うのかを探してみてほしかった**のです。

その違いは、選手自身には分かりませんでした。

そこでわたしは、技術を教えてくれるコーチに聞いてみるよう伝えました。

**自分で分からないことを、一人で解決する必要はありません。**

選手は実際にコーチに質問し、明確な答えを得て改善に取り組み、
試合ではスクワットを3本とも成功させることができました。

これは、メンタルサポートだけでスクワットが改善したという話ではありません。
技術指導者の助言と、選手自身の取り組みがあったからこその変化です。

**わたしが関わったのは、その前の段階です。**

できないという結果だけを見るのではなく、できていたときにも目を向ける。
分からないことをはっきりさせて、聞きに行く。

これは、大人にも、子どもにもできます。

では、おうちでは何ができるでしょうか。

## はじめる前に　親の3つの約束

> 📷3

質問を始める前に、保護者の方にお願いしたいことが3つあります。

**この3つを守るだけで、同じ質問でも結果が変わります。**

### 約束1　答えを言わない

子どもが考えている間、親はたいてい答えが分かっています。

**でも、言わないでください。**

言ってしまうと、その時間は「親が教える時間」になります。
子どもは、考えるのをやめます。

黙っているのは、思っているよりしんどいです。
**それでも、黙ってください。**

### 約束2　「どうしてできなかったの？」と聞かない

これは、質問のかたちをしていますが、質問ではありません。

子どもには、**責められている**ように聞こえます。

```
×　どうして、できなかったの？
○　できたときと、何がちがったと思う？
```

**同じことを聞いているのに、返ってくる言葉がまったく変わります。**

### 約束3　「そんなの当たり前」と言わない

子どもが「できたこと」を言ったとき、

```
「そんなの当たり前でしょ」
「それはできて当然」
```

と言わないでください。

一度言われると、子どもは次から言わなくなります。

**当たり前かどうかを決めるのは、本人です。**

---

ここからは、子どもと一緒に読んでください。
**ノートと鉛筆を用意します。**

## 質問①　うまくいったときと、できなかったとき、なにがちがった？

うまくいかないとき、人は「できなかったこと」ばかりを見ます。

でも、ここではちょっと見る場所を変えます。

**おなじことが、うまくいったときはなかった？**

たとえば、さか上がりができなかったとします。

「きょうは、できなかった」

で終わりにしないで、

**「まえにできたときは、どうだったかな？」**

と、思い出してみます。

```
ばしょは おなじだった？
その日の 体のちょうしは どうだった？
だれかが 見ていた？
さいごに やったのは いつだった？
```

すぐに見つからなくても、だいじょうぶです。

**「できなかったとき」だけを見るより、くらべるものがふえます。**

### ワーク①　できたときと、できなかったときをならべる

最近、うまくいかなかったことを1つ、思い出してください。
スポーツでも、勉強でも、友だちのことでも、なんでもいいです。

**1．うまくいかなかったとき、なにがあった？**

れい：さか上がりが できなかった。

```
＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
```

**2．おなじことが、うまくいったことはある？**

れい：せんしゅう、1回だけできた。

```
＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
```

**3．その2つで、ちがったことはある？**

れい：せんしゅうは、ともだちが手をもってくれていた。

```
＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
```

**「わからない」でも、だいじょうぶです。**
いま分からない、ということが分かったので、それも答えです。

---

>
> ここで、親が先に違いに気づくことがあります。
> **それでも、言わないでください。**
>
> 子どもが「わからない」と言ったら、
> 「じゃあ、こんど見てみようか」でいいです。
>
> **その場で答えを出すことが目的ではありません。**

## 質問②　ほんとうにあったことと、頭の中で思ったことは、なに？

つぎは、**2つに分けます。**

```
ほんとうに あったこと
頭の中で じぶんが 思ったこと
```

たとえば、さか上がりができなかったとき。

「ぼくは、うんどうが にがてなんだ」

と思うことが、あるかもしれません。

ここで、ちょっと考えてみてください。

**「さか上がりが できなかった」ことと、「うんどうが にがて」は、おなじですか？**

```
さか上がりが できなかった　　→　ほんとうに あったこと
うんどうが にがて　　　　　　→　じぶんが 頭の中で 思ったこと
```

**ちがいます。**

そう思ってしまうのは、わるいことではありません。

でも、**頭の中で思ったことを「そうなんだ」と決めてしまうと、
ほかの理由が見えなくなります。**

### きもちも、書いてみる

2つに分けたら、そのときの**きもち**も書いてみてください。

```
くやしい
あせる
ふあん
かなしい
もやもやする
```

**どれかに当てはめなくても、いいです。**
ぴったりの言葉がなければ、自分の言葉で書いてください。

**前向きにしなくても、いいです。**

くやしかったなら、くやしかった。
いやだったなら、いやだった。

そのまま書いてください。

### ワーク②　2つに分ける

**1．ほんとうに あったことは、なに？**

れい：さか上がりが、1回も できなかった。

```
＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
```

**2．そのとき、頭の中で なにを思った？**

れい：ぼくは うんどうが にがてなんだ。

```
＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
```

**3．そのとき、どんな きもちだった？**

れい：くやしかった。はずかしかった。

```
＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿
```

> 大人でも、混ざります。
>
> **きれいに分けられなくて構いません。**
>
> 分けることが目的ではなく、
> **「思ったこと＝事実、ではない」と気づくことが目的**です。
>
> 2と3が混ざっていても、そのままにしてください。

## 質問③　まだ わからないことは なに？ だれに なにを きく？

さいごの質問です。

ここでは、**「わからないこと」をさがします。**

わからないのは、こまったことではありません。

**「ここが わからない」とはっきりすると、だれに聞けばいいかが分かります。**

さっきの選手の話を思い出してください。

その選手も、**しゃがめるときとしゃがめないときのちがいが、自分では分かりませんでした。**

だから、コーチに聞きました。
そして、答えをもらって、できるようになりました。

**ぜんぶ自分で分かる必要は、ありません。**

```
うんどうのことなら　　　　先生、コーチ
べんきょうのことなら　　　先生、おうちの人
ともだちのことなら　　　　おうちの人、話せる人
```

**だいじなのは、「いま、なにが知りたいか」を じぶんで考えることです。**

**4．じぶんで ためしてみられることは ある？**

ぜんぶ うまらなくても、だいじょうぶです。

だれに聞けばいいか分からないときは、
**「聞けそうな人をさがす」**を つぎの一歩にしてもいいです。

## 終わったあとに、1つだけ

3つの質問が終わったら、さいごにこれを聞いてください。

```
「きょう、できたことは なに？」
```

**うまくいかなかった話をしたあとに、これを聞きます。**

**これも全部、できたことです。**

答えが出ていなくても、です。

## これは、はげますためのものではありません

最後に、保護者の方へ。

わたしは、メンタルトレーニングを「いつも前向きでいるためのもの」だとは
考えていません。

不安なときは、不安でいい。
くやしいときは、くやしくていい。
分からないときは、分からないと言っていい。

そのうえで、

```
いま、なにが起きているんだろう？
自分は、どう感じているんだろう？
```

を、一緒に考えていく。

**それが、わたしのやっていることです。**

子どもが「できない」と言ったとき、答えを渡すこともできます。

3つの質問は、何度でも使えます。
うまくいかないことがあるたびに、また開いてください。
