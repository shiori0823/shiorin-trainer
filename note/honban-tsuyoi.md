# 本文ここから

試合が近づくほど、落ち着かなくなる。

これは、気持ちが弱いからではありません。
**試合が近いほど不安が大きくなるのは、ふつうのことです。**

そして、その不安のいちばん大きな正体は、
たいてい「失敗したらどうしよう」です。

> 📷

## 当日の自分は、判断が得意ではありません

試合の日の自分を、思い出してみてください。

朝早く起きて、検量があって、
会場の音がして、まわりの選手の重量が目に入って、
アップの時間が押していて。

**その状態で、冷静に判断できる人はいません。**

私も、できません。
競技歴は11年になりますが、当日になると、やっぱり落ち着きません。

だから私は、**当日の自分に判断させない**ことにしています。

## 判断は、前の日までに終わらせておく

本番に強い人は、当日にがんばっている人ではありません。

**当日、考えることが少ない人です。**

考えることが少ないのは、前の日までに決め終わっているからです。
決まっていれば、当日は実行するだけになります。

> 📷

## 決めておくのは、この3つです

**1　第一試技の重量**

ここは「今日の調子で決める」にしない。
**確実に成功する重量**を、前の日までに決めておく。

1本目が通ると、残りの2本の景色が変わります。

**2　目標を、3つ持っておく**

ひとつの数字だけを目標にすると、
それが外れた瞬間に、その日は全部失敗になります。

3つ持っておくと、そうならない。
この話は、こちらに書きました。

→ 「高い目標」が、自信を奪うことがある

**3　当日やることの順番**

検量が何時で、そこから何を食べて、
いつアップを始めて、どの順番で体を起こすか。

**これも前の日までに決める。**
当日に考えると、それだけで消耗します。

## 紙から、判断する言葉を全部消しました

先日、ある選手のセコンドに入る準備をしていたときのことです。

当日に渡す紙を作っていて、最初はこう書いていました。

```
　この重量なら、心配しなくて大丈夫です
　ここは強みなので、思い切っていきましょう
```

**全部、消しました。**

残したのは、これだけです。

```
　第一試技　◯◯kg
　プレスコールを待つ
```

> 📷

なぜかというと、

**当日に「大丈夫かな」「思い切っていいのかな」と考えさせたくなかった**からです。

「心配しなくて大丈夫」と書いてあると、
人は一度「心配すべきかどうか」を考えてしまいます。

決めたことだけが書いてあれば、
**読んで、やるだけになります。**

## 当日は、決めたことをやるだけ

試合の日の自分の仕事は、新しく考えることではありません。

**前の日までの自分が決めたことを、やりきることです。**

うまくいかない日もあります。
3本とも失敗することもあります。

それでも、
「決めたことを、やった」は残ります。

**それは、次の試合に持っていけます。**

## 今日、できること

試合までに、紙を1枚だけ用意してみてください。

書くのは、決めたことだけです。

```
　第一試技　　　◯◯kg
　目標　　　　　120点／100点／80点
　当日の順番　　検量 → ◯◯ → アップ開始 ◯時
```

**「がんばる」「落ち着いていこう」は書かない。**

当日の自分は、それを読んで、また考えてしまうからです。

決めたことだけが書いてある紙を持って、
会場に入ってください。

**それが、本番に強い、ということです。**

いってらっしゃい。
