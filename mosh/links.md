# MOSH「リンク」の並び（2026-10-10）

いまは**できたのかけら診断（一般向け）だけ**が入口になっている。
名刺を渡した企業・学校の方、インスタから来た選手が、迷子になる。

```
1　［ 企業・学校・チームの方へ ］　→　サービス（研修・講演・ワークショップ）
2　［ 競技をしている方へ ］　　　 →　パワーリフター向けLP
3　［ そのほかの方へ ］　　　　　 →　いまのできたのかけら診断（そのまま）
```

**3は触らなくてよい。** 上に2つ置けば、自然と「そのほかの方」の枠になる。

# プロフィール本文に足す1行（元教員）

**学校案件でいちばん強い材料が、画像の中に埋もれている。**

```
元教員が、メンタルトレーニングを教えに来る
```

学校の先生から見ると、外から来たトレーナーとはまったく別の存在になる。
**話が通じる人だと、最初から分かる。**

画像の中だと読まれないし、検索もされない。**本文に入れる。**

## 「■ これまで」の冒頭を、こう変える

```
■ これまで

もともとは、教員・支援員として子どもたちと関わっていました。
いまは夫とともに、ウエイトトレーニングジム「ノーリミッツ岡山」を
運営しています。

パワーリフティングという競技を、11年続けてきました。
日本一2回、スクワットの日本記録、世界大会出場。

ただ、ずっと結果が出ていたわけではありません。
（以下、いまのまま）
```

**人としての話を先に、競技の実績をあとに。**
記録から始めると遠い人になるが、「元教員」から始まると近い人になる。

# ★ 肩書きが2つある

| どこ | 肩書き |
|---|---|
| 名刺・プロフィール上部 | **メンタルトレーナー** |
| 画像の中（講師プロフィール） | 目標達成プロデューサー／ノーリミッツ岡山共同代表 |

**同じページの中で違う。** 企業の方が見ると「この人は何の人だろう」となる。

→ **「メンタルトレーナー」に寄せる。**
「目標達成プロデューサー」は、何をする人か想像できない。
企業・学校に出していくなら、職種として伝わる言葉のほうがいい。
