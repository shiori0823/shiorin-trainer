## 説明文（ここからコピー）

企業・団体・学校の方向けの、無料相談です。


「メンタル研修を入れたい。でも、何を頼めばいいか分からない」

その状態のままで来てください。
**30分で、頼む形まで一緒に決めます。**


■ たとえば、こんなときに

【企業・団体の方】
・失敗を引きずって、次に進めない社員がいる
・プレゼンや商談など、ここぞの場面で実力が出ない
・目標は高いのに届かず、達成できないまま自信をなくしていく
・「ちゃんとやらなきゃ」と思うほど、動けなくなっている

【学校・部活動の方】
・練習ではできるのに、試合になるとできない
・大会前に、緊張で潰れてしまう生徒がいる
・メンタルをどう教えたらいいのか分からない
・受験期の生徒に、崩れない考え方を渡したい


■ 30分ですること

1. いま現場で何が起きているかを聞かせてください
2. それがメンタルトレーニングで変えられることかどうかをお伝えします
3. 変えられるなら、どんな形（時間・人数・回数）が合うかを一緒に決めます

**2番が大事だと思っています。**
メンタルトレーニングで変えられないこともあります。
そのときは、変えられませんとお伝えします。


■ お渡しできるテーマ

・**目標の立て方** … 高すぎる目標が、なぜ自信を奪うのか
・**本番で力を出す** … 「ここぞ」の場面で、自分を戻す方法
・**自分を認める** … 小さな「できた」の見つけ方
・**動けなくなる言葉** … 「ちゃんとやらなきゃ」から抜ける

1テーマ90分から、複数回の研修まで組めます。
内容は現場に合わせて作り直しますので、この通りでなくて大丈夫です。


※※※ ここから ─ 金額が固まるまで載せない（2026-09-22時点は未掲載） ─ ※※※

複数回のシリーズや、対面での実施はご相談ください。

**相談そのものは無料です。**
金額を先に出しておくのは、お互いの時間を無駄にしないためです。

## 書き方のねらい

| どこ | なぜ |
|---|---|
| 「何を頼めばいいか分からない」を冒頭に | **発注する側のいちばんの悩みがこれです。**「メンタル研修」は言葉が大きすぎて、何を頼めばいいか決められない。そこを代わりに決める時間だと言い切ると、相談する理由ができる |
| 企業と学校を分けて書いた | 学校の先生は、企業向けの例だけだと自分向けだと思えない。逆も同じ |
| 「変えられないときは、変えられないと言う」 | **無料相談がただの営業に見えないための一行。**これがあるかないかで、相談の申し込みやすさが変わる |
| テーマを4つ名前付きで出した | 「メンタル研修ください」とは頼めません。**指させるものがあると頼めます。**4つとも栞さんがすでに作ってある中身です |
| 「3名まで同席・決裁の方とご一緒でも」 | 担当者だけが聞いて、社内で説明して、また戻ってくる——この往復をなくします |
| 「持ち帰って説明するための材料まで渡す」 | 担当者は上司に説明する必要があります。**そこを助けると通ります** |

## 書かなかったこと

**導入実績を書いていません。**

「導入企業多数」「〇〇社導入」のような書き方は、
実際にないなら**絶対に足さないでください。** 一度で信用がなくなります。

いまは競技の実績と、考え方の中身だけで立たせてあります。
**1社でも実績ができたら、そのときに足してください。**

## 金額を精査するとき

金額そのものを見つめても答えは出ません。
**その金額に何時間入っているかを数える**と出ます。

### 半日（3時間）の研修に、実際に入っている仕事

| | |
|---|---|
| 事前ヒアリング | 1時間 |
| 内容を現場に合わせて組み直す | 4〜6時間 |
| 資料・ワークシート制作 | 3〜4時間 |
| 当日 | 3時間 |
| 準備・移動 | 1〜2時間 |
| 終了後の質問対応 | 1時間 |
| **合計** | **13〜17時間** |

30万円 ÷ 14時間 ≈ **2.1万円／時**

「1時間10万円」ではありません。
**当日の3時間だけを数えたときに、そう見えるだけです。**

### 90分の講演

| | |
|---|---|
| 事前打合せ | 0.5〜1時間 |
| 内容の調整 | 2〜3時間 |
| 資料 | 1〜2時間 |
| 当日 | 1.5時間 |
| 準備・移動 | 1時間 |
| **合計** | **6〜8時間** |

10万円 ÷ 7時間 ≈ **1.4万円／時**

### ★ 削りしろがないのは、講演のほう

実働で見ると、**講演のほうが安くなっています。**

当日の時間だけで見ると講演のほうが高く見えますが、
中身を数えると逆です。準備の量は、90分でも3時間でもそこまで変わりません。

**「90分だけだから安くていいか」と下げると、
いちばんしんどい仕事がいちばん安くなります。**

動かすなら研修のほうから考えてください。

### 数え方を変えるとき

上の表は目安です。実際に1件やってみたら、**かかった時間を必ず記録してください。**
2件目からは、推測ではなく実績で決められます。

## （参考）ページに金額を載せる場合の考え方

無料相談のページに金額を書くと、申し込みは減ります。
**それでも、金額が固まったら書いたほうがいい**と考えています。

- 予算が合わない相手との30分が、そもそも発生しない
- 先に出すほうが、値引き交渉が始まりにくい
- 「押さない」という栞さんのやり方と合っている

数をこなす商売ではないので、**減るのは困らない問い合わせのほうです。**

## ★ 必ず聞かれること

> 「90分が10万円なら、3時間は20万円では？」

時間単価で見ると、講演が約6.7万円／時、研修が10万円／時で、
**長いほうが高くなっています。** 発注側は必ずここに気づきます。

答えは用意できます。しかも本当のことです。

> **講演は「聞く時間」、研修は「書いて持ち帰る時間」。別の商品です。**

研修にはワークシートがあり、その場で書いてもらい、
フィードバックを返し、明日から使える形にして持ち帰ってもらいます。

**同じものの長さ違いではありません。** これを言い切れば通ります。

## 予算が足りないと言われたら

**値引きしないでください。かわりに中身を減らします。**

| 言われたこと | 返し方 |
|---|---|
| 予算が20万しかない | 半日ではなく、90分の講演＋ワークシート配布にする |
| 人数が多いので安く | **人数では変えません。** 100人でも1人でも、話す準備は同じです |
| 今回だけ安く、次から正規で | 次はありません。最初の金額がその会社の基準になります |

一度下げた金額は、その会社との間で二度と上がりません。
**弟さんのときと同じ話です。**

## まだ決まっていないこと

- **複数回シリーズの金額**。1回あたりではなく、**全体でいくら**と決めるほうが売りやすいです
- **対面の交通費**。「交通費別途・遠方は要相談」と言えるようにしておいてください
- **インボイス登録番号**。法人と取引すると請求書で求められることがあります。
  登録しているかどうかだけ、確認しておいてください

## 税の表記について

法人向けは **税別**、個人向け（講座）は **税込** にしてあります。

**ちぐはぐではありません。** 会社は税別で予算を組み、個人は払う総額で考えるので、
それぞれに合わせるのが普通です。
