# MOSH プロフィール文（書き換え案）

名刺のQRがここに届きます。読む人は **もう栞さんに会っている人** です。
「どんな人か」を探しにきたのではなく、**「何を頼めるのか」を確かめにきています。**

パワーリフティングは「対象」ではなく「根拠」の位置に置いてあります。
競技者だけでなく、企業・学校の人が読んでも自分の話として読めるようにしてあります。

## 本文（ここからコピー）

ここぞの場面で、自分の力を出しきる。

メンタルトレーナーの佐藤栞（しおりん）です。

大事な場面ほど、力が出せない。
準備はしてきたのに、本番で頭が真っ白になる。

なぜそれが起きるのかと、どうすればいいのかをお伝えしています。

メンタルは、強さではありません。
練習すれば身につく、スキルです。


■ これまで

パワーリフティングという競技を、11年続けてきました。
日本一2回、スクワットの日本記録、世界大会出場。

ただ、ずっと結果が出ていたわけではありません。

日本記録を取るつもりで臨んだ試合で、取れませんでした。
そこから取れるまでに、3年遠回りしました。

技術も筋力も足りていました。
足りなかったのは、本番で自分を戻す方法でした。

その3年でやったことを、いま人に渡しています。


■ 大切にしていること

「ちゃんとやらなきゃ」と思うほど、人は動けなくなります。
何をすればいいかが、決まっていないからです。

なので私は、小さな「できた」を一つずつ増やしていきます。

できたことが積み上がると、人は自分を信頼できるようになります。
そこまでいくと、本番が怖くなくなります。


■ ご依頼いただけること

・企業・団体向けの研修
・学校、部活動での講演
・個別コーチング（オンライン）

競技者に限りません。
仕事でも、受験でも、「ここぞ」がある方ならどなたでも。

内容に合わせて組み立てますので、まずはご相談ください。

## 書き方のねらい

| どこ | なぜそう書いたか |
|---|---|
| 1行目 | 名刺のキャッチと同じ。名刺を見た人が「同じだ」とわかる |
| 「メンタルは、強さではありません」 | 世間の「メンタルが強い／弱い」を否定している。研修を頼む理由になる |
| 記録を取れなかった話を先に | 実績だけ並べると遠い人になる。つまずきがあると相談してよさそうに見える |
| 「3年遠回りしました」 | ステップメール・note記事と同じ言い方。資料の間で数字がズレない |
| 「ちゃんとやらなきゃ」 | note記事④と同じ話。記事を読んだ人がここに来ても同じ人の声に聞こえる |
| 「競技者に限りません」 | これを書かないと、企業・学校の人が自分向けだと思えない |
