# 動画データの置き場所（台帳）

**動画ファイル本体はこのリポジトリに入れません。** ここは「どこに何があるか」を
書いておくための台帳です。

Gitは動画のようなバイナリを苦手にしていて、一度入れると消しても容量が永久に
残ります。GitHubは1ファイル100MBで拒否、50MBで警告が出ます。

---

## 保管のルール

**原本は2か所。配信先は保管庫ではありません。**

| 役割 | 場所 | 中身 |
|---|---|---|
| **① 原本** | Googleドライブ | すべての動画＋収録原本＋編集プロジェクト |
| **② 控え** | **弟さんの手元に残してもらう** | 編集時の元データ一式 |
| ③ 配信 | YouTube／Instagram | 書き出したものを公開するだけ |

**②は「元データ、しばらく消さないでおいて」と伝えるだけで完成します。**
外付けハードディスクを買う必要はありません。

YouTubeやInstagramは**配信先であって保管庫ではありません。** 規約違反の判定や
アカウントの問題で消えることがあります。原本は必ず手元に持っておいてください。

---

## フォルダの作り方

**そのまま使えるフォルダ一式を用意してあります。**
`ケニーさん対談_保管フォルダ.zip` を解凍して、Googleドライブに入れるだけです。

```
2026-09_ケニーさん対談/
├ ★さいしょに読む.txt
├ 1_動画/    ← 動画5本。中のメモにファイル名が書いてあります
└ 2_資料/    ← 掲載許可のやりとり、編集データ、文字起こし、編集指示書
```

**フォルダは2つだけです。** 細かく分けるほど続かなくなるので、これ以上は増やさない
ほうがいいです。

年月をフォルダ名の頭に付けてあります。対談が2本目、3本目と増えたときに、
同じ形でコピーして使えば、並べるだけで時系列になります。

---

## ファイル名の付け方

`1_動画/★このフォルダに入れるもの.txt` に、コピーして貼るだけの形で
書いてあります。考える必要はありません。

```
2026-09_kenny_digest
2026-09_kenny_clip01_700
2026-09_kenny_clip02_hitonosei
2026-09_kenny_clip03_2-3nenmae
```

**収録原本（`IMG_8676.MOV`）だけは、名前を変えないでください。** 編集データと
同じ場所（`2_資料`）に、この名前のまま置きます。名前を変えると、Premiereが
映像を見つけられなくなり、開くたびに手で探し直すことになります。

日付を先頭にすると、ファイル名だけで自動的に古い順に並びます。
「最終版」「修正版2」のような名前は**絶対に付けないでください。** 半年後に
どれが最終か分からなくなります。直したときは `_v2` を付けて、古いほうも残します。

## 埋め込みの仕様

```
https://www.youtube-nocookie.com/embed/IIycz9TVoAM?rel=0
```

| | 理由 |
|---|---|
| `youtube-nocookie.com` | 再生するまでCookieを置かない |
| `?rel=0` | 再生後に他人の動画を出しにくくする |
| `loading="lazy"` | その位置まで読まれるまで読み込まない（表示が速い） |

16:9で固定。スマホ（390px）・PC（1280px）どちらも横はみ出しなしを確認済み。

## ★ YouTubeの公開設定に注意

| 設定 | 埋め込み |
|---|---|
| 公開 | ◯ |
| **限定公開（リンクを知っている人のみ）** | **◯ 埋め込める** |
| 非公開 | **✗ 埋め込めない**（LPで黒い枠になる） |

**「非公開」になっていると、LP上では何も映りません。**
限定公開なら問題なく埋め込めるので、迷ったら限定公開でよい。
