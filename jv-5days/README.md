# 私ファーストプログラム 5DAYS（JV企画）

マナー講師の方との共同開催。**初JV。**

| | |
|---|---|
| 日程 | **2026-10-19（月）〜10-23（金）** |
| 時間 | 毎朝 6:30〜6:45（15分） |
| 価格 | 3,300円（税込）※次回以降5,500円も検討 |
| 目標 | 10名（最低ライン6名） |

## コンセプト

> 誰かのために動くのは得意。
> でも、自分を整えることはいつも後回し。
>
> 日々のタスクに追われ、自分のことを後回しにしてしまう起業女性・キャリア女性が、
> 1日15分だけ「私」を最優先にする5日間。

## ターゲット

起業女性／キャリア女性／仕事やタスクに追われている女性／
誰かを優先して自分が後回しになっている女性。

**「子育てが終わって時間ができた女性」ではなく、現在進行形で追われている人に寄せる。**

# ★ この企画の位置づけ

**いま、一般向けの入口に人が来ていない。**

| レーン | 入口 | 人数 |
|---|---|---|
| 一般（できたのかけらメソッド 298,000円） | 診断 → LINE | **4名** |
| 選手（3か月 98,000円） | note・セミナー | 3名＋ |

**298,000円の商品があるのに、そこへ向かう入口がほぼ空。**

5DAYSで10名集まれば、一気に10名。しかも**3,300円払っている。**

## ターゲットがほぼ一致している

| 5DAYS | できたのかけらメソッドのペルソナ |
|---|---|
| 誰かのために動くのは得意。自分を整えるのは後回し | 仕事や家庭はこなしているのに、自分のために前進している実感がない |

**別企画ではなく、一般レーンのフロントとして使える。**

## 副次的な効果

毎朝6:30を5日間やるのは、**90日講座の朝活LIVEのリハーサル**になる。

90日講座には毎日の朝活が入っている（栞さんの時間の45%を占める）。
**本当に続けられるかを、5日で試せる。** 本番前に分かるのは大きい。

# ミドル商品について

3,300円 → 298,000円は**90倍**。橋は要る。**ただし作るのは5DAYSのあと。**

## なぜ後か

### ① 10月に作る時間がない

```
10/1〜9   5DAYSと10/10セミナーの告知
10/10     セミナー
10/11〜18 フォロー＋直前告知
10/19〜23 5DAYS（毎朝6:30）
10/24     日本グランプリ
```

設計・販売ページ・決済が入る余地がない。

### ② いま作ると当てずっぽうになる

**10名が何を欲しがるかは、まだ分からない。** 5日やれば向こうから言ってくれる。

チェックシートを「手が止まったところを見てから」にしたのと同じ判断。

## 橋は、もう持っている

5日目の案内は **60分の無料個別相談** で足りる。作るものがゼロ。

そして相談をやると、ミドル商品が要るかどうかが分かる。

| 相談で言われること | 分かること |
|---|---|
| 「298,000円はいまは無理」 | 価格の問題 → **ミドルが要る** |
| 「内容は合うが時間が…」 | 形式の問題 → **軽い版が要る** |
| 「やりたいです」 | **何も要らない** |

**3人聞けば答えが出る。**

## 作るとしたらこれ（候補）

90日講座の中に、すでに設計済みのものがある。

```
実践ツール3点セット
　①「私にもあった！」できたのかけら発見BOOK（30日ワーク）
　②「止まっても大丈夫」わたしの戻り方MAP
　③「次の試技」リトライシート
```

**この3点＋使い方の録画**なら10,000円前後で成立する。

| | |
|---|---|
| 作るもの | ツールは設計済み。録画は1回撮るだけ |
| 栞さんの時間 | **ゼロ**（データで渡すだけ） |
| 90日講座への影響 | ツールで詰まった人が「一緒にやってほしい」になる。**後押しになる** |

### ★ やってはいけないこと

**「90日の1か月目だけ」を切り出して10,000円にしない。**

1か月分が10,000円だと、**3か月で298,000円の説明がつかなくなる。**

# 運用で決めること

## 5日目の案内の時間

**15分の中に、お互いの案内を入れるのは無理。** 本編が消える。

| | |
|---|---|
| A | 5日目だけ30分にする |
| **B** | **本編15分のあと、任意参加で案内タイムを別枠に** ← 推奨 |
| C | 案内は当日せず、終了後にLINE・メールで送る |

Bなら、聞きたい人だけ残るので温度が高い。**そして15分の本編が守れる。**

## まだ決まっていないこと

- **栞さんの担当日と内容**（5日のうち何日か、何を話すか）
- 集客の役割分担（それぞれ何人を目標にするか）
- 申込・決済をどちらの口で受けるか

### 15分の中身について

**できたのかけらは15分にちょうど入る。** 9/26セミナーのWORK1がそのまま使える。

```
・「できた」は成功だけではない、を説明　　3分
・6つの質問を出す　　　　　　　　　　　　2分
・書く　　　　　　　　　　　　　　　　　5分
・1人ずつシェア　　　　　　　　　　　　 5分
```

第1回セミナーで、**質問を出したら書けた**ことが分かっている。
15分なら「10個」ではなく**3個**にする。
