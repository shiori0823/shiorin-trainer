# ★ なぜこれが良いのか（残す理由）

## ① 1行目がお礼から始まっている

> 自分は好きなこと楽しんでいるだけなのに「すごい」って言ってもらえて本当に嬉しかった

**その人にしか書けない一文。**
テンプレの `〇〇さんのことを思い浮かべながら` は、この段落があれば不要。
栞さんは実際に外している。正しい。

## ② 「今度私がチャレンジする」

| | 立ち位置 |
|---|---|
| テンプレ | 「講座をやります」＝ 主催者 → お客さん |
| **送った版** | **「私がチャレンジする」＝ 挑戦する人 → 一緒にどう？** |

**売る人ではなく、やる人として書いている。**
3,300円の朝活に一番効く立ち位置。
「一緒に自分のための朝活しませんか？」も同じ効果。

## ③ 「スルーしてくださいね」

断る道を先に開けると、**断りやすくなるぶん返事が来る。**
返事ゼロが一番困るので、入れて正解。

# 2人目以降で試すこと

引いている表現が3つ重なっている。

```
おこがましいんですが…
ご興味なければお気遣いなくスルーしてくださいね
ご無理のない範囲でご検討いただけると嬉しいです
```

**「私ファースト」の案内が、少し他人ファーストになっている。**
内容と温度が逆を向いているのはここだけ。
