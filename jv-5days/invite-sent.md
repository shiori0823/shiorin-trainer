# ★ なぜこれが良いのか（残す理由）

## ① 1行目がお礼から始まっている

> 自分は好きなこと楽しんでいるだけなのに「すごい」って言ってもらえて本当に嬉しかった

**その人にしか書けない一文。**
テンプレの `〇〇さんのことを思い浮かべながら` は、この段落があれば不要。
栞さんは実際に外している。正しい。

## ② 「今度私がチャレンジする」

| | 立ち位置 |
|---|---|
| テンプレ | 「講座をやります」＝ 主催者 → お客さん |
| **送った版** | **「私がチャレンジする」＝ 挑戦する人 → 一緒にどう？** |

**売る人ではなく、やる人として書いている。**
3,300円の朝活に一番効く立ち位置。
「一緒に自分のための朝活しませんか？」も同じ効果。

## ③ 「スルーしてくださいね」

断る道を先に開けると、**断りやすくなるぶん返事が来る。**
返事ゼロが一番困るので、入れて正解。

## ★ 一番いい追加：中身が具体的になった

```
私は簡単にできる柔軟体操、スクワットなどをお伝えします！
```

「自分を最優先にする」だけでは抽象的で、朝6:30に起きる理由にならない。
**ストレッチとスクワットが入ると、15分で何が起きるかが見える。**
体を動かすのは「私ファースト」がいちばん実感しやすい形でもある。

### ただし、要確認

**名前のある個人に約束をしたことになる。**

- みゆきさんとの担当分けで、栞さん枠＝「体」が確定しているか
- 5日間の中に実際に入るか

未確定なら「お伝えします」（約束）ではなく
「体の方を担当します」（役割の説明）に弱める。

## 逃げ道の直し方：削るより、相手の事情を入れる

| | やり方 |
|---|---|
| Claudeの提案 | 削る |
| **栞さんの実装** | **「〇〇さんとのリトリート前で準備等忙しいと思いますので」** |

**こちらが正解。**
一般的な「ご興味なければ」は定型文だが、相手の予定を分かって言っているので、
**断りやすさと「見てくれている」が同時に成立する。**
「ご無理のない範囲で」も消えて、引きは1回だけになった。

→ 以後、逃げ道は「削る」ではなく「その人の事情を入れる」。

## 1人目との違い（比較用）

| | 立ち位置 |
|---|---|
| 1人目 | 「今度**私がチャレンジする**」＝ やる人 |
| 2人目 | 「開催します」＝ 主催者 |

2人目は事実として主催者なので間違いではない。
`一緒に朝活しませんか？` が companion の役を果たしている。
**どちらが返事が来るか、比べる材料になる。**

## 小さい点

`CMM9期のみゆきさん` の「CMM9期」は、**相手がCMMを知っているならそのまま**
（共通の場の話になるので効く）。知らない相手なら「マナー講師のみゆきさん」。
