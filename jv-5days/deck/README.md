## 配色

5DAYSは一般向けなので、パワーリフター向けの資料とは分けている。

| | |
|---|---|
| ワインレッド | `#7A1524`（名刺・LPと同じ） |
| 背景 | `#FDF7F7` |
| 差し色 | `#B08D5B`（金系） |

**表紙と9枚目だけ、ワインレッドの全面。** ここが一番伝えたいところ。

## 作るときに気をつけたこと

**文字を載せすぎない。** 2と3は話すほうが本体で、
スライドには着地する1行だけを置いてある。

**6と11で同じ5つの選択肢を使う。** 最初に選んで、最後に戻る構造。
