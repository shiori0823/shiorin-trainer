## 配色

5DAYSのバナーに合わせている。パワーリフター向けの資料（ワインレッド）とは別系統。

| | |
|---|---|
| ローズ | `#C9325C` / 濃いほう `#A42647` |
| 薄ピンク（筆の帯） | `#F7DCE3` / `#FCEEF2` |
| 金 | `#C4A06A` |
| 背景 | `#FDF5F6` |

**見出しの1行目にだけ、薄ピンクの帯を敷く。** バナーの筆づかいに合わせたもの。

**写真は丸く抜いて、金のふちをつける。** 表紙にふたり、2枚目にしおりん、3枚目にみゆきさん。

## 作るときに気をつけたこと

**文字を載せすぎない。** 2と3は話すほうが本体で、
スライドには着地する1行だけを置いてある。

**6と11で同じ5つの選択肢を使う。** 最初に選んで、最後に戻る構造。

**「ちゃんと」は使わない。**
