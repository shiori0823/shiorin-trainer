# スライドに文字を載せていない理由

**2と3は、話すほうが本体です。**

スライドに書いてあるのは結論だけ。そこに至る話は口でします。

## 2　しおりんの話す順番

```
パワーリフティング・仕事・子育てを頑張ってきた
　↓
パソコンの前で肩をすくめて仕事をしていると、頭も進まない
　↓
柔軟体操・トレーニング・正しく立つことで、一度自分に戻る
　↓
その後、仕事がはかどる
　↓
子育てでイライラしている時も、正しく立って深呼吸すると、
見えていなかったことが見える
　↓
身体を整えることは、もっと頑張るためではなく、自分に戻るため
```

**最後の1行が、スライドに書いてある文です。** そこへ着地します。

## 3　みゆきさんの話す順番

```
家族や仕事を優先し、自分は後回し
　↓
「私は大丈夫」と頑張り続けた
　↓
体調を崩した
　↓
姿勢・身だしなみ・食事・所作を整えることが、自分のお守りだった
　↓
マナーは「正しく見せるため」だけではない
　↓
自分を丁寧に扱うこと
```

### ★ 体調の話は、スライドに書いていません

入退院のことは、**みゆきさんご本人の話です。**
画面に文字で残すかどうかは、ご本人に決めてもらってください。

口で話すぶんには自然ですが、スライドに書くと「記録」になります。
**事前に一度、確認をお願いします。**

## 二人の違いが、ここで立ちます

```
しおりん　　→　身体から、自分に戻る
みゆきさん　→　所作から、自分を丁寧に扱う
```

目指すところは同じ。**「自分を置いていかない」。**

# 4　参加者の自己紹介

**「自己紹介してください」と言わないこと。** 緊張します。

スライドのとおり、3つだけ聞きます。
**「30秒くらいで」「話したくないことは話さなくて大丈夫」を、口でも言ってください。**

少人数なので、一人30秒〜1分で足ります。

# 6と11は、同じ5つの選択肢です

6で選んでもらい、11でもう一度戻ります。

```
朝、自分のための時間がとれている
自分の疲れに、気づける
食事を一度、丁寧に食べられる
イライラしたときに、一度止まれる
「今日の私、どうしたい？」が聞けている
```

**11では、そこから一段おろします。**

```
5日後に、どんな小さな変化があったら
「ちょっと変わった」と思えそうですか？
```

✗ 毎朝、完璧に起きられた
◯ 自分の疲れに気づけた／食事を一度、丁寧に食べられた

**小さくするほど、5日後の満足度が上がります。**
