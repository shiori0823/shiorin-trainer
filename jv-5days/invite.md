# ★ アーカイブは、案内には書かない（2026-09-30 決定）

**栞さんの判断。** 理由がそのまま正しいので、そのまま採用。

> その日の朝、自分の時間を作るということが、私ファーストなのかな

```
案内に「アーカイブあり」　→　「出られなくても大丈夫」
　　　　　　　　　　　　　→　朝、起きる理由が消える
　　　　　　　　　　　　　→　自分の時間を作る、が起きない
```

内容を受け取ることが中身の講座なら、アーカイブは価値になる。
**この企画は「朝6:30に起きて15分とる」こと自体が中身。**
最初に「出なくてもいい」と言うのは、商品を自分で薄めること。

## ただし、申込後には伝える

集客のためではなく、**脱落防止のため。**

```
案内の段階で言う　→　行かなくていい理由になる　→　✗
申込後に言う　　　→　1日落ちても戻ってこられる　→　◯
```

3日目に寝坊した人が「もうダメだ」と離れるのが、5DAYSで一番多い落ち方。
そのとき「後日アーカイブを送る」を知っていれば戻ってくる。

### 申込後の1通目に入れる文

```
アーカイブは、5日間が終わったあとにまとめてお送りします。

ただ、この5日間は「朝に自分の時間をつくる」こと自体が中身なので、
できるかぎり、その時間に来てください。

寝坊した日があっても、次の朝また来れば大丈夫です。
```

**「あるけど、来てほしい」を言葉にしておく。**
約束は守りつつ、朝の重みは消さない。

　片方が「アーカイブあります」と案内すると崩れる。
