# 5DAYSのお誘い（直接送る用）

目標3名。**投稿ではなく、1人ずつ送る。**

対象は、いまダイエットサポートをしている方など、**すでにやりとりがある人。**

---

## 本文（1行目だけ書き換える）

```
（その人に宛てた一行）


10月19日から5日間、朝6時半から15分だけの講座をやります。

マナー講師の方と一緒にやる企画で、
「私ファーストプログラム」という名前にしました。


誰かのために動くのは得意だけど、
自分のことはいつも後回しになってしまう。

そういう5日間を、1日15分だけ
「自分を最優先にする時間」にしてみる、という内容です。


　10月19日（月）〜23日（金）
　毎朝 6:30 – 6:45（15分）
　Zoom／3,300円

毎朝15分だけなので、出勤前に終わります。
アーカイブもあるので、出られない日があっても大丈夫です。


〇〇さんのことを思い浮かべながら作ったところがあるので、
よかったらどうぞ。

【申し込みフォームのURL】
```

---

## ★ 1行目がすべてです

```
「この前話していた〇〇の件、その後どうですか」
「〇〇さん、朝の時間って取れそうですか」
```

**その人に向けて書いた一行があるかどうかで、返事の来かたが変わります。**

8月のLINE（4名に一斉送信・返信ゼロ）と、
9月のメール（3名に個別送信・当日返信）の違いが、ここでした。

---

## 「〇〇さんのことを思い浮かべながら」は、本当のときだけ

**書けない相手には、書かないでください。**

お世辞になった瞬間に、全部が嘘になります。
その一行がない版でも、じゅうぶん届きます。

---

## 送る相手を決めてから書く

先に文面を作ってから相手を探すと、誰にも刺さりません。

```
① 3人の顔を思い浮かべる
② その人ごとに1行目を書く
③ 残りは共通でいい
```

**3人なら10分で終わります。**
