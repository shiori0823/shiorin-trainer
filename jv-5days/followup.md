# 5DAYSの4名に、個別相談をするか（2026-10-26）

---

# 結論

**やる。ただし「売るための時間」にはしない。**

```
2名だけに声をかける　30分　無料
目的は、売ることではなく、聞くこと
```

**4名全員には声をかけない。**（2026-10-26 決定）

---

# 1　アンケートでは足りないこと

アンケート（6問）で取れるのは、ここまで。

```
朝6:30と15分は、どうだったか
5日間で、何がいちばんよかったか
いま感じていること
```

**取れないのは、こちら。**

| | なぜ書かれないか |
|---|---|
| なぜ、申し込んだのか | 記述欄に、そこまで書く人はいない |
| その前、何にいちばん困っていたか | 聞かれていないから出てこない |
| 3,300円を、どう感じたか | **文字で値段の話はしにくい** |
| 5日が終わったあと、何が残っているか | アンケートは終わった直後。**まだ分からない** |

**この4つは、話さないと出ません。**
そして**この4つが、次をつくるときにいちばん要るもの**です。

---

# 2　ただし　──　いま、出せるものがありません

ここを先に認めておかないと、個別相談が崩れます。

```
一般レーンの行き先　→　ジムのサービス（ダイエット・コーチング）
ジムは　　　　　　 →　岡山
90日伴走プログラム →　まだ売れる形になっていない（残り7項目）
```

**4名が岡山の方でなければ、いま渡せるものは何もありません。**

だから、**売ろうとしないでください。**
出すものがないまま売ろうとすると、相手に伝わります。
**「聞きに来た」と決めて入れば、30分はきれいに終わります。**

---

# 3　誰に声をかけるか

**2名。** 全員ではない。

## 選び方

**「しおりんを応援したくて申し込んだ人」は、外す。**

その方の話は、ありがたい。でも**材料にはなりません。**
②で聞きたいのは「何に困っていたか」であって、
応援で申し込んだ人は、そこに答えを持っていないからです。

**選ぶのは、こちら。**

| | |
|---|---|
| ① | **5日間、よく来ていた方**（続いた理由が本人の中にある） |
| ② | **アンケートに、具体的に書いてくれた方**（話しても具体が出る） |
| ③ | **関係が近すぎない方**（近いほど、気をつかった答えになる） |

**3つ全部そろう必要はありません。** ①か②があれば足ります。

## 2名でいい理由

```
同じことを2人が言ったら　→　それは本物
違うことを2人が言ったら　→　4人に聞いても、ばらける
```

**4名から2名を選ぶのは、手を抜くことではありません。**
**聞く相手を決めることも、設計のうちです。**

---

# 3-2　送る文面

**一人ずつ書く。** 同じ文面を2通送らない。
違うのは、真ん中の1行だけです。

```
〇〇さん、5日間ありがとうございました。

アンケートも読ませていただきました。
【アンケートから、ひとこと】

もしよければ、30分だけお話しさせてもらえませんか。

初めての開催だったので、
受けてくださった方の話を、聞いておきたくて。

何かをおすすめする時間ではありません。
日程が合わなければ、気にしないでください。
```

**9行。** これ以上長くしない。

## 【アンケートから、ひとこと】に入れるもの

**相手が書いた言葉を、そのまま使う。** 言い換えない。

```
例　「朝、自分の時間ができた」と書いてくださっていたのが、嬉しかったです。
例　「3日目から変わった」とありましたが、そこをもう少し聞きたくて。
```

**ここが「あなたに送っている」の証明になります。**
ここがないと、2通とも同じに見えます。

## 入れないほうがいいもの

| | なぜ |
|---|---|
| 「今後のサービスについて」 | 売る時間だと思われる |
| 「ぜひ」「ぜひとも」 | 断りにくくなる |
| 5日間の感想を長く書く | **相手が返事を考えてしまう** |

**「何かをおすすめする時間ではありません」は、必ず残す。**
これがないと、来た人が身構えます。

## 日程の出し方

**返事が来たら、こちらから候補を3つ出す。**

```
ありがとうございます。
この中で、合うところはありますか。

　10月30日（木）10:00〜
　10月31日（金）13:00〜
　11月4日（火）10:00〜

どれも難しければ、言ってください。
```

**「いつがいいですか」と聞かない。** 相手が考える時間が増えます。
候補を出せば、往復が1回で済みます。

## 断られたとき

```
承知しました。アンケートだけで十分ありがたいです。
5日間、ありがとうございました。
```

**追わない。** ここで追うと、5日間が台無しになります。

# 4　30分で、何を聞くか

**5つ。順番も大事です。**

## はじめの2分

```
今日は、私が聞かせてもらう時間です。
うまく答えようとしなくて大丈夫です。
```

**先に言う。** これで相手の肩が下りて、残り28分の中身が変わります。

## ① 5日間のあと、何か残っていますか（5分）

```
終わってから今日まで、続いていることはありますか
逆に、やめたことはありますか
```

**「よかったです」を聞きに行かない。事実を聞く。**
続いていないなら、それが分かるほうが価値があります。

## ② 申し込む前、何にいちばん困っていましたか（8分）

```
申し込もうと思ったとき、何か困っていたことはありましたか
いつから、そう感じていましたか
```

**ここがいちばん長くていい。**
相手が使った言葉を、そのままメモしてください。

**その言葉が、次の案内文になります。**
こちらが考えた言葉より、必ず効きます。

## ③ ダイエットのこと（5分）

```
ダイエット、何回くらい挑戦したことがありますか
```

**10/12に決めた検証です。** 助産院で聞くつもりだったもの。

```
3回以上という人が多ければ　→　ダイエットを入口にする判断は正しい
```

**4名でも、聞く価値があります。**

## ④ 3,300円は、どうでしたか（5分）

```
正直なところ、あの金額はどう感じましたか
もし次があるとしたら、いくらくらいなら考えますか
```

**文字では絶対に出てこない答えです。**
言いにくそうなら「高かったですよね」とこちらから言ってしまう。

## ⑤ いまの場所を、そのまま伝える（5分）

**ここだけ、こちらが話します。**

```
いま、この続きとしてお渡しできる形が、まだできていません。

ジムの中でやっているものを、
もう少し広く届けられる形にしようとしているところです。

形になったら、ご連絡してもいいですか。
```

**「ない」と言うことが、いちばん信用されます。**
あるふりをして曖昧に匂わせるより、ずっといい。

**ここで「はい」と言ってもらえたら、この30分は成功です。**

---

# 5　終わったあとに、やること

2名ぶんを、**1枚にまとめる。**

| | |
|---|---|
| ②で出た言葉 | **そのまま書き写す。** 要約しない |
| ③の回数 | 数字だけ |
| ④の金額感 | 言われたまま |
| ⑤の返事 | 連絡していいか |

**名前は「Aさん」「Bさん」に置き換える**（公開リポジトリのため）。

これが、次の一般向けの企画の材料になります。

---

# 6　やらない場合

アンケートだけで終わらせるのも、間違いではありません。

**ただ、そのときに失うのは「②の言葉」です。**

```
次に一般向けのものを作るとき、
入口の言葉を、また自分で考えることになる
```

2名 × 30分 ＝ **1時間。**
1時間で、次の案内文の材料が手に入るなら、安いと思います。
