# 5DAYSの4名に、個別相談をするか（2026-10-26）

---

# 結論

**ヒアリングではなく、5日間の個別ふりかえりにする。**（2026-10-26 決定）

```
2名に、一人ずつ　30分
相手のためのふりかえり　15分
聞かせてもらう　　　　 12分
```

## なぜ、ヒアリングをやめたか

**いま、この4名に出せる商品がない。**
その状態で30分もらうと、**取るだけの時間**になる。誘うほうも気が重い。

**返すものを用意すれば、それが消える。** 商品でなくていい。

初日に「5日後こうなりたい」を1つ決めてもらっている。
**それを一緒に確かめて、ここからの1つを決める。**
しおりんさんが、いちばん得意なことです。

聞きたいことは、**その流れの中で自然に出ます。**

## 一人ずつ対応する

**2名に同時に投げない。**（2026-10-26 決定）

```
1人目に声をかける　→　やってみる　→　2人目
```

1人目で、**聞き方も、渡し方も変わります。**
2人同時だと、その直しが効きません。

---

# 1　アンケートでは足りないこと

アンケート（6問）で取れるのは、ここまで。

```
朝6:30と15分は、どうだったか
5日間で、何がいちばんよかったか
いま感じていること
```

**取れないのは、こちら。**

| | なぜ書かれないか |
|---|---|
| なぜ、申し込んだのか | 記述欄に、そこまで書く人はいない |
| その前、何にいちばん困っていたか | 聞かれていないから出てこない |
| 3,300円を、どう感じたか | **文字で値段の話はしにくい** |
| 5日が終わったあと、何が残っているか | アンケートは終わった直後。**まだ分からない** |

**この4つは、話さないと出ません。**
そして**この4つが、次をつくるときにいちばん要るもの**です。

---

# 2　ただし　──　いま、出せるものがありません

ここを先に認めておかないと、個別相談が崩れます。

```
一般レーンの行き先　→　ジムのサービス（ダイエット・コーチング）
ジムは　　　　　　 →　岡山
90日伴走プログラム →　まだ売れる形になっていない（残り7項目）
```

**4名が岡山の方でなければ、いま渡せるものは何もありません。**

だから、**売ろうとしないでください。**
出すものがないまま売ろうとすると、相手に伝わります。
**「聞きに来た」と決めて入れば、30分はきれいに終わります。**

---

# 3　誰に声をかけるか

**2名。** 全員ではない。

## 選び方

**「しおりんを応援したくて申し込んだ人」は、外す。**

その方の話は、ありがたい。でも**材料にはなりません。**
②で聞きたいのは「何に困っていたか」であって、
応援で申し込んだ人は、そこに答えを持っていないからです。

**選ぶのは、こちら。**

| | |
|---|---|
| ① | **5日間、よく来ていた方**（続いた理由が本人の中にある） |
| ② | **アンケートに、具体的に書いてくれた方**（話しても具体が出る） |
| ③ | **関係が近すぎない方**（近いほど、気をつかった答えになる） |

**3つ全部そろう必要はありません。** ①か②があれば足ります。

## 2名でいい理由

```
同じことを2人が言ったら　→　それは本物
違うことを2人が言ったら　→　4人に聞いても、ばらける
```

**4名から2名を選ぶのは、手を抜くことではありません。**
**聞く相手を決めることも、設計のうちです。**

---

# 3-2　送る文面

**一人ずつ。** 違うのは真ん中の1行だけです。

```
〇〇さん、5日間ありがとうございました。

アンケートも読ませていただきました。
【アンケートから、ひとこと】

もしよければ、30分だけ、
5日間のふりかえりを一緒にしませんか。

初日に決めた「5日後こうなりたい」を確かめて、
ここからの1つを決めるところまでやります。

何かをおすすめする時間ではありません。
```

**「話を聞かせてください」ではなく「ふりかえりをしませんか」。**
誘うほうも、気が重くならない。

## 【アンケートから、ひとこと】に入れるもの

**相手が書いた言葉を、そのまま使う。** 言い換えない。

```
例　「朝、自分の時間ができた」と書いてくださっていたのが、嬉しかったです。
例　「3日目から変わった」とありましたが、そこをもう少し聞きたくて。
```

**ここが「あなたに送っている」の証明になります。**

## 入れないほうがいいもの

| | なぜ |
|---|---|
| 「今後のサービスについて」 | 売る時間だと思われる |
| 「ぜひ」 | 断りにくくなる |
| 5日間の感想を長く書く | **相手が返事を考えてしまう** |

## 日程の出し方

**返事が来たら、こちらから候補を3つ出す。**

```
ありがとうございます。
この中で、合うところはありますか。

　10月30日（木）10:00〜
　10月31日（金）13:00〜
　11月4日（火）10:00〜

どれも難しければ、言ってください。
```

**「いつがいいですか」と聞かない。** 候補を出せば、往復が1回で済みます。

## 断られたとき

```
承知しました。アンケートだけで十分ありがたいです。
5日間、ありがとうございました。
```

**追わない。** ここで追うと、5日間が台無しになります。

# 4　30分の中身

**前半は相手のため。後半で聞かせてもらう。** 順番を入れ替えない。

## はじめの1分

```
今日は、5日間のふりかえりをしましょう。
最後に少しだけ、私からも聞かせてください。
```

**後半があることを、先に言っておく。**
言っておけば、後半が唐突になりません。

---

## 前半　15分　── 相手のため

### ① 初日に決めたこと、どうでしたか（5分）

```
初日に「5日後こうなっていたい」を1つ決めてもらいました。
あれ、どうでしたか。
```

**そうならなかった場合も、そのまま受ける。**
「できませんでした」が出たら、**なぜできなかったかを一緒に見る。**
そこがいちばん役に立ちます。

### ② 続いていること／やめたこと（5分）

```
終わってから今日まで、続いていることはありますか。
逆に、やめたことはありますか。
```

**「やめたこと」も必ず聞く。** 続いたことだけ聞くと、報告会になります。

### ③ ここからの1か月、1つだけ決めるなら（5分）

```
ここから1か月、1つだけ続けるとしたら、何にしますか。
```

**ここが、渡すもの。**

5日間と同じで、**1つだけ。** 増やさない。
決まったら、**その場で言葉にして返す。**「〇〇を1か月、ですね」

---

## 後半　12分　── 聞かせてもらう

```
ここからは、私が聞かせてもらっていいですか。
うまく答えようとしなくて大丈夫です。
```

### ④ 申し込む前、何にいちばん困っていましたか（8分）

```
申し込もうと思ったとき、何か困っていたことはありましたか。
いつから、そう感じていましたか。
```

**ここが本体。いちばん長く取る。**

**相手が使った言葉を、そのままメモする。**
その言葉が、次の案内文になります。こちらが考えた言葉より、必ず効きます。

### ⑤ ダイエットのこと（4分）

```
ダイエット、何回くらい挑戦したことがありますか。
```

**10/12に決めた検証です。**

```
3回以上という人が多ければ　→　ダイエットを入口にする判断は正しい
```

### 金額は、聞かない

前の版では「3,300円どうでしたか」を入れていた。**外しました。**

**あれがいちばん「取りに来た感」を出します。**
価格は、あとからでも分かる。**1つ落とすだけで、ずいぶん軽くなります。**

---

## 最後の2分

```
いま、この続きとしてお渡しできる形が、まだできていません。

形になったら、ご連絡してもいいですか。
```

**「ない」と言うことが、いちばん信用されます。**
あるふりをして匂わせるより、ずっといい。

**ここで「はい」をもらえたら、この30分は成功です。**

---

# 5　終わったあとに、やること

2名ぶんを、**1枚にまとめる。**

| | |
|---|---|
| ④で出た言葉 | **そのまま書き写す。** 要約しない |
| ⑤の回数 | 数字だけ |
| ③で決めた1つ | 1か月後に、こちらから聞ける |
| ⑤の返事 | 連絡していいか |

**名前は「Aさん」「Bさん」に置き換える**（公開リポジトリのため）。

これが、次の一般向けの企画の材料になります。

---

# 6　やらない場合

アンケートだけで終わらせるのも、間違いではありません。

**ただ、そのときに失うのは「④の言葉」です。**

```
次に一般向けのものを作るとき、
入口の言葉を、また自分で考えることになる
```

2名 × 30分 ＝ **1時間。**
1時間で、次の案内文の材料が手に入るなら、安いと思います。
