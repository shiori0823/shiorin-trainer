# 企業・学校・チーム向け お問い合わせフォーム

MOSHのバナー①「研修・講演のご相談はこちら」から飛ばす。

**設計の方針：名刺から来た人は、まだ案件を持っていない。**
「何月に研修をやります」と決まっている人は少数派。
**決まっていない人が送れるフォーム**にする。

```
必須　5問
任意　4問
所要　3分
```

---

# フォームのタイトル

```
研修・講演・ワークショップのご相談
```

# フォームの説明（タイトルの下）

```
お問い合わせありがとうございます。
メンタルトレーナーの佐藤栞（しおりん）です。

内容がまだ決まっていない段階でも大丈夫です。
「こんなことで困っている」だけでも、お送りください。

いただいた内容をもとに、2営業日以内にご連絡いたします。
無理にご提案することはありません。

所要3分ほどです。
```

**「まだ決まっていなくても大丈夫」を最初に書く。**
ここがないと、決まっていない人の手が止まる。

**ここで、こちらの話し方が変わる。** 必ず聞く。

## 5　ご関心　【必須・チェックボックス（複数選択可）】

```

```

選択肢：
```
社員・職員向けの研修

まだ決まっていない／まずは相談したい
```

**最後の選択肢がいちばん大事。** これがないと、決まっていない人が送れない。

## 6　いま困っていること　【必須・記述式（長文）】

```

```

```

・指導者がどう声をかけていいか分からない
・社員研修の内容を探している
```

**例を3つ出す。** 白紙だと手が止まる。9/26のセミナーで分かったこと。

# 送信後のメッセージ

Googleフォームの「設定 → プレゼンテーション → 確認メッセージ」に入れる。

```
お送りいただき、ありがとうございました。

2営業日以内に、いただいたメールアドレスへご連絡いたします。

内容をうかがったうえで、30分ほどオンラインでお話しさせてください。
そのうえで、必要があればご提案いたします。
無理にお勧めすることはありません。

ご不明な点がありましたら、いつでもご連絡ください。

メンタルトレーナー／パワーリフター
佐藤 栞（しおりん）
```

**「無理にお勧めすることはありません」を2回書いている。**
説明文と確認メッセージの両方。企業の担当者がいちばん警戒するのがここ。

# ★ 聞かなかったこと

## 予算

迷ったが、**最初の問い合わせでは聞かない。**

```
聞く　→　金額の話から始まる。断る理由を先に渡してしまう
聞かない→　まず困りごとを聞ける
```

30分お話ししたあと、提案と一緒に出す。

## 電話番号

**要らない。** メールで足りる。
項目が増えるほど送信率が下がるので、使わないものは置かない。

## 役職

**要らない。** 聞いても使い道がない。

# 設定でやること

```
□ 回答を1回に制限　→　オフ（Googleログインを求めない）
□ メールアドレスを収集　→　オン（質問3を消す場合）
□ 新しい回答の通知を受け取る　→　★ オン（必ず）
□ 進行状況バーを表示　→　オフ（短いので不要）
□ 確認メッセージ　→　上のテキスト
```

**通知をオンにし忘れると、来たことに気づきません。**
国スポのフォームのときと同じです。

```

② ★ 長いほうを、このファイルに追記する
```
