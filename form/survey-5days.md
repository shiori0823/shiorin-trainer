# 5DAYS アンケート（Googleフォーム）

10月23日（金）Day5の最後に、その場で答えてもらう。

```
6問　／　うち記述2　／　2分
```

**4名が、朝15分だけ時間を作ってくれた人たち。**
アンケートで、その5日分より長く考えさせない。

---

# 重くしないために、切ったもの

| 切った設問 | なぜ |
|---|---|
| 何日参加できましたか | **こちらが見ている。** 聞くと出欠を取られている感じになる |
| 初日に決めたことはどうなりましたか | **Day5の中で口頭で聞く。** 書かせる話ではない |
| ほかの人にすすめたいですか | 記述欄に出る。**重ねて聞かない** |
| よかったところを2つまで | **1つに。** 選ぶのに時間がかかる設問は、最初に手が止まる |
| 長文の必須を2つ | **1つに。** もう1つは任意 |

**メールアドレスは聞かない。** 4名とも、すでにつながっている。
**特典はつけない。** 次回開催が未定で、知り合いに気をつかわせる。
