# 5DAYS アンケート（Googleフォーム）

10月23日（金）Day5の最後に案内して、その場で答えてもらう。

```
必須　7問
任意　3問
所要　5分
```

**参加者は4名。** 統計を取る数ではない。**一人ひとりの言葉を、そのまま受け取るための紙。**
だから選択肢を細かく刻まず、**書いてもらう欄を多めにしてある。**

---

# 設計で決めたこと

## ① メールアドレスは聞かない

4名とも、すでにLINEかDMでつながっている。**聞く理由がない。**
聞けば、その分だけ答えるのが重くなる。

## ② 特典をつけない

参考にしたフォームは「次回無料ご招待」を特典にしていた。**今回は真似しない。**

理由は2つ。

```
① 次回の開催がまだ決まっていない（JVは当面進めないと決めている）
② 4名とも知り合い。お礼で釣ると、かえって気をつかわせる
```

**代わりに「全部読みます」と書く。** 4名なら、それが本当だと伝わる。

> どうしても特典をつけるなら、**5日間のふりかえりシート（PDF）**。
> 次回招待のように、渡せるか分からないものは約束しない。

## ③ みゆきさんのパートを、必ず分けて聞く

**初めてのJV。** 次に同じ形をやるかどうかの判断材料になる。
「どちらがよかったか」ではなく、**それぞれ別の設問にする。**

## ④ 最後に、個別相談の案内を置く

売り込みにしない。**「興味がある／ない」を選んでもらうだけ。**
`strategy/README.md` で決めたとおり、**商品名は出さない。**

# 質問

## Q1　お名前　*

```
短文
```

## Q2　5日間で、何日参加できましたか　*

```
ラジオ　5日 ／ 4日 ／ 3日 ／ 2日 ／ 1日
```

**責める設問ではない。** 何日来られたかで、他の答えの読み方が変わる。

## Q3　朝6:30から15分、という時間はどうでしたか　*

```
ラジオ
　ちょうどよかった
　早かったが、やってみたらできた
　早すぎてつらかった
　時間は大丈夫だったが、15分は短かった
　時間は大丈夫だったが、15分は長かった
```

**次にやるなら、ここが一番の変更点になる。**

## Q4　5日間で、いちばんよかったものを選んでください（2つまで）　*

```
チェックボックス（2つまで）
　初日のキックオフ（90分）
　しおりんの「正しく立つ」「身体を整える」
　みゆきさんの「所作を整える」
　毎朝の「今日の私、どうしたい？」
　朝、同じ時間に人と顔を合わせること
　5日後の自分を、初日に1つ決めたこと
　その他
```

## Q5　初日に決めた「5日後、こうなっていたい」は、どうなりましたか　*

```
ラジオ
　そうなった
　少し近づいた
　変わらなかった
　途中で、決めたこと自体を忘れていた
```

**「忘れていた」を選択肢に入れておく。** それが出たら、こちらの設計の問題。

## Q6　5日間を終えて、いま感じていることを教えてください　*

```
段落（長文）
```

**ここがこのアンケートの本体。** 他の設問は、この欄を書きやすくするための助走。

## Q7　もっとこうだったらよかった、というところを教えてください　*

```
段落（長文）
```

**必須にする。** 任意にすると、気をつかって空欄になる。

「特にありません」でも構いません、と補足文を添える。

```
補足：「特にありません」でも大丈夫です。
　　　小さなことでも、書いていただけると助かります。
```

## Q8　この5日間を、ほかの人にすすめたいと思いますか　*

```
ラジオ
　すすめたい
　相手による
　すすめない
```

**理由は聞かない。** Q7で出ている。

## Q9　いただいた感想を、今後の案内に使わせていただいてもよいですか　*

```
ラジオ
　名前つきで使ってよい
　イニシャルや「30代女性」などでなら使ってよい
　使わないでほしい
```

**必ず聞く。** 聞かずに使わない。

## Q10　このあと、30分お話しする時間に興味はありますか　（任意）

```
ラジオ
　興味がある
　いまはない
```

```
補足：5日間でやったことを、これからどう続けるかを一緒に見る時間です。
　　　無料で、何かに申し込む必要はありません。
```

**「興味がある」を選んだ方にだけ、あとから個別に連絡する。**
フォームの中でリンクを出さない。**その場で決めさせない。**

# 設定

| | |
|---|---|
| メールアドレスの収集 | **しない** |
| 回答のコピーを送信 | しない |
| 回答の編集 | 許可する |
| 新しい回答の通知 | **オンにする**（スプレッドシート → ツール → 通知設定） |
| 共有相手 | みゆきさんにも結果を共有する。**フォームの編集権限ではなく、回答のスプレッドシートを共有** |
