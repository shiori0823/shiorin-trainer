# 選手向け 無料個別相談（30分）申し込みフォーム

LPのCTA4か所から飛ばす。いまはMOSHのサービスページに繋がっている。

```
必須　5問
任意　3問
所要　3分
```

**MOSHと違って、日程の予約機能がない。** だから**候補日時をフォームで聞いて、
往復を1回減らす。** ここが設計のいちばん大事なところ。

---

# フォームのタイトル

```
無料個別相談（30分）のお申し込み
```

# フォームの説明

```
お申し込みありがとうございます。
メンタルトレーナーの佐藤栞（しおりん）です。

30分、Zoomでお話しします。

この時間で、次の3つを一緒に整理します。

　1　次の試合で、本当に取りたい結果は何か
　2　いま、その目標を邪魔しているものは何か
　3　次の試合までに、何をすればいいか

「講座を受けるか決めていない」段階でも大丈夫です。
相談したからといって、受講を決める必要はありません。

所要3分ほどです。
```

# 質問

## 1　お名前　【必須・記述式（短文）】

```
お名前
```

説明：
```
ニックネームでも大丈夫です。
```

## 2　メールアドレス　【必須・記述式（短文）】

```
メールアドレス
```

説明：
```
Zoomのリンクをこちらにお送りします。
```

※ 設定で「メールアドレスを収集する」をオンにする場合は、この質問は不要。

## 3　競技・階級　【必須・記述式（短文）】

```
競技と階級を教えてください
```

説明：
```
例：パワーリフティング 83kg級／ベンチプレス 59kg級
```

**パワーリフティング以外の方も来る。** 競技から聞く。

## 4　次の試合　【必須・記述式（短文）】

```
次の試合は、いつ・何の大会ですか
```

説明：
```
例：11月22日 広島パワー／まだ決まっていない

決まっていない場合は「未定」で大丈夫です。
```

## 5　いま困っていること　【必須・チェックボックス（複数選択可）】

```
いま困っていることを教えてください（複数可）
```

選択肢：
```
練習ではPRが出るのに、試合では出ない
一本失敗すると、そのあとを引きずってしまう
目標の数字を、どう決めればいいか分からない
試合が近づくと、練習が怖くなる
緊張して、いつも通りの動きができない
セコンドやコーチとの関わり方
その他
```

**この選択肢は、実際に選手が言った言葉から取っている。**
考えた悩みではないので、読んだ選手が「これだ」と止まる。

## 6　ご希望の日時　【必須・記述式（長文）】

```
ご希望の日時を、3つほど教えてください
```

説明：
```
例
　10月28日（火）20:00〜
　10月30日（木）21:00〜
　11月2日（日）9:00〜

いただいた候補から、こちらで調整してご連絡します。
```

**★ ここが、MOSHからフォームに変えたときのいちばんの穴。**
候補を先にもらわないと、メールが何往復もする。

## 7　もう少し詳しく　【任意・記述式（長文）】

```
もう少し詳しく聞かせてください（任意）
```

説明：
```
直近の試合で何が起きたか、いま一番気になっていることなど。
一行でも大丈夫です。
```

## 8　どこで知ったか　【任意・ラジオボタン】

```
差し支えなければ、どちらで知っていただいたか教えてください
```

選択肢：
```

Instagram

MOSH
ワークショップ・セミナー
ご紹介
その他
```

# 作ったあと

```
① 短縮URLと長いほうの両方を控える
② ★ LPのCTA4か所を、このフォームに差し替える
③ MOSHの個別相談サービス（404875）をどうするか決める
④ 自分で一度送信して、通知が届くか確かめる
```

## ② LPの差し替え箇所

```
lp/index.html　4か所
　・ヒーロー（画面いちばん上）
　・08 無料個別相談
　・FINAL CTA
　・下に固定で出ているバー
```

いまは4か所とも `https://mosh.jp/services/404875?openExternalBrowser=1`。

**URLをもらえたら、こちらで差し替えます。**

## ③ MOSHの個別相談ページ

LPがフォームに変わると、**MOSH側と2つの入口ができる。**

```
MOSH　→　60分と書いてあるはず（LPは30分に直した）
```

**どちらかに揃えてください。**

| | |
|---|---|
| 案A | MOSHの個別相談を30分に直して、両方残す |
| 案B | MOSHの個別相談を下げて、フォームに一本化する |

**推すのはB。** 2つあると、どちらに来たか分からなくなる。
MOSHは「サービス一覧を見せる場所」、申し込みはフォーム、と分けるほうが分かりやすい。
