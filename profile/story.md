# 長い版

## 本文ここから

### 練習どおりにできない、を11年やってきました

パワーリフティングという競技を、11年続けています。

日本一2回、スクワットの日本記録、世界大会出場。

こう書くと順調に見えますが、ずっと結果が出ていたわけではありません。

日本記録を取るつもりで臨んだ試合で、取れませんでした。
そこから取れるまでに、3年かかりました。

技術も筋力も、足りていました。
**足りなかったのは、本番で自分を戻す方法でした。**

その3年でやったことを、いま人に渡しています。

### もともとは、教員と支援員をしていました

辞めた事情はいろいろありましたが、いま思うのは、
**型にハマらなかったのだと思います。**

先生という肩書きに、自分がはまらなかった。

### 教えるのではなく、戻す

選手に技術を教える人は、たくさんいます。
私がやっているのは、そこではありません。

**すでに練習してきた人が、それを本番で出せるようにすること。**

だから、私は新しいことをあまり足しません。
やるのは、だいたいこの3つです。

```
決めておくことを、決める　　　　→　当日、考えることを減らす
できたことを、数える　　　　　　→　見えていないものを、見えるようにする
答えではなく、問いを渡す　　　　→　本人に決めてもらう
```

### 実際にやってきたこと

**大会前の設計とセコンド。**
試合の2〜4週間前に、第一試技の重量、目標、当日の順番を決めます。
当日は、決めたことをやるだけにします。
試合当日に選手へ渡す紙からは、励ます言葉を全部消しました。
**当日に、新しく考えてほしくないからです。**

**セミナーとワークショップ。**
2026年9月から始めて、試合の振り返りや、大会前の準備を一緒に組み立てています。
一人ずつ数字を出して、その場で組み替えて返します。

**「できたのかけら」。**
最近1か月の「できた」を10個書き出してもらいます。
ルールは1つだけ。**「こんなの当たり前」は禁止です。**
自己ベストを出したことだけが「できた」ではありません。
練習に行った。重量を下げた。休むと決めた。人に相談した。全部「できた」です。

**朝15分の5日間。**
2026年10月、マナー講師の方と一緒に、朝6:30から15分の5日間をやりました。
毎朝、同じ問いだけを出しました。「今日の私、どうしたい？」

**ジム。**
夫とウエイトトレーニングジムをやっています。

始めた理由は、単純です。
**二人ともパワーリフティングで強くなりたくて、その環境が近くになかった。**
だから、つくりました。

いまのジムは、こういう場所です。

```
来たら、やる気の出るジム
大人の放課後
ウエイトトレーニングから、挑戦を支える
```

来ている方は、本当にばらばらです。
パワーリフター、健康になりたい方、ダイエットをしたい方。
**高校生から、80歳の方まで。**

大会に挑戦する方の90日間を、いま一緒につくっているところです。

### 全部、同じことをしていました

長いあいだ、自分は別々のことをやっていると思っていました。

選手のメンタル。ジムの運営。セミナー。人の講座づくり。

でも、並べてみたら同じでした。

| 相手 | 持っているもの | 困っていること |
|---|---|---|
| 選手 | 技術・練習量 | 本番で出せない |
| ジムに通う方 | 動ける体 | 続かない |
| 専門を持っている方 | 知識・経験 | 伝わらない |

高校生も、80歳の方も、同じです。

**一人も、「何もしていない人」がいません。**

みんな、すでにやっています。
**やっているのに、手応えがないだけです。**

だから私は、足しません。

```
すでに持っているものを、使える形にする
```

これだけを、ずっとやってきました。

### 大事にしていること

「もっと頑張らなきゃ」と思うほど、人は動けなくなります。
何をすればいいかが、決まっていないからです。

だから、小さな「できた」を一つずつ数えます。

できたことが積み上がると、人は自分を信頼できるようになります。

**「できると思い込む」のではなく、
やってきた事実を根拠に、自分を信頼できる状態。**

そこまでいくと、本番が怖くなくなります。

# 競技歴の年数について（2026-10-28）

**「競技歴11年」は、いま16個のファイルに入っている。**

```
名刺／LP／セミナー63枚／ポスター2種／MOSHプロフィール
note記事4本／B2B企画書2種とA4 2枚／このファイル
```

## 直さない

**書いた時点の数字だから。** 記事もポスターも企画書も、その日付のもの。

## ただし、2つに分かれる

| | |
|---|---|
| その時点のもの | note記事、企画書、ポスター、セミナー資料 → **直さない** |
| ずっと出し続けるもの | **名刺、LP、MOSHプロフィール、このファイル** |

後者は、来年も再来年も同じものが人の目に触れる。

```
競技歴11年　→　毎年ズレる
2014年から　→　ズレない
```

**西暦に書き換えれば、二度と直さなくて済む。**

## 始めた年

社会人2年目から。35歳の時点で、**11年とも12年とも取れる。**

```
2014年に始めた　→　2026年で12年目
2015年に始めた　→　11年目
```

四大卒で35歳なら、社会人2年目は2014年度。**12年目が濃厚。**

**→ 西暦が確定したら、上の4つだけ直す。**
