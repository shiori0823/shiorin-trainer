# 無料個別相談のあとに送る文面

相談が終わったあと、決まった順番で送る文面をまとめています。
**そのままコピーして、【　】の中だけ書き換えれば送れます。**

| ファイル | 中身 |
|---|---|
| `mail-01-thanks.md` | 当日中に送るお礼（**一番大事**） |
| `mail-02-checkin.md` | 3日後の様子うかがい |
| `mail-03-deadline.md` | 1週間後の締切のお知らせ |
| `mail-04-signup.md` | お申し込みをいただいたとき |
| `mail-05-decline.md` | 「今回は見送ります」と言われたとき |
| `mail-06-last.md` | 返事がないまま2週間たったとき（これで最後） |

## いつ送るか

```
相談当日（その日のうちに）      → 01 お礼
3日後                          → 02 様子うかがい
1週間後                        → 03 締切のお知らせ
　├ 申し込みあり               → 04
　├ お断りの返事あり           → 05（ここで終わり）
　└ 返事なし                   → 2週間後に 06（ここで終わり）
```

**06を送ったら、そこで追うのをやめます。** これ以上は届きませんし、
「しつこかった」という記憶だけが残ります。狭い業界なので、そちらの
ほうが損です。

## 全部に共通する、たった1つのルール

**スライド30枚目で決めた「やること1つ／やらないこと1つ」を、必ず書いて返す。**

これがフォローの背骨です。ここさえ守れば、残りの文章は多少ぎこちなくても
問題ありません。逆にこれを書かずに講座の話だけすると、1時間かけて作った
「話してよかった」がその一通で消えます。

相談中に必ずメモを取ってください。相手が言った言葉を、**言い換えずにその
まま**書き写すのがコツです。「メンタルを整える」ではなく「3本目の前に
呼吸を3回」と、本人が言ったとおりに。

## 相談中のメモ欄（そのまま埋めてください）

文面の【　】は、ほぼこれで埋まります。相談の最後の5分で確認します。

```
お名前　　　　　　：
次の試合と時期　　：
やること 1つ　　　：
やらないこと 1つ　：
一番印象に残ったこと（本人の言葉のまま）：
連絡先（どこに返すか）：
締切日：
```

## 送る手段について

LINE・Instagram DM・メールのどれでも構いませんが、**相談の申し込みが来た
のと同じ場所**に返すのが一番自然です。

- **メール** … 下の文面をそのまま使えます
- **LINE / DM** … 各ファイルの末尾に短縮版を用意しています。長文はDMだと
  読まれにくいので、必ず短縮版のほうを使ってください

## 書き換えるところ

| 記号 | 入れるもの |
|---|---|
| `【お名前】` | 相手のお名前（呼んでいた呼び方で。ニックネームならそのまま） |
| `【やること】` | 30枚目で決めた「やること1つ」を、本人の言葉のまま |
| `【やらないこと】` | 同じく「やらないこと1つ」 |
| `【試合名・時期】` | 「11月の県大会」など、相手が言っていた次の試合 |
| `【一番印象に残ったこと】` | 38枚目で相手が言ったこと。その場でメモを |
| `【締切日】` | 5名に達していない場合の受付期限 |

## やってはいけないこと

- **返事を催促しない。** 「ご検討いかがでしょうか」は書かない
- **値引きしない。** 「今なら」を出した瞬間、98,000円の根拠が消えます
- **枠が埋まっていないのに「残りわずか」と書かない。** 事実だけ書く
- **相談で聞いた内容を、本人の許可なくSNSに書かない**（これは一番大事です）
