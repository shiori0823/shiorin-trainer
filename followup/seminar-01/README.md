# 第1回セミナー後のフォロー（2026-09-26）

参加3名。**一斉配信はしない。1人ずつ、その人が言ったことを返す。**

## 何を送るか

売り込みではなく、**記録の返却**です。

セミナーの中心はこれでした。

> 自分の「できた」は、自分ではいちばん見えにくい。

**だから、本人が言ったことを書いて返すと、それだけで講座の中身が一回実演されます。**
話した褒め言葉は消えますが、書いた記録は残ります。「証拠を持っていく」の実物になります。

## 入れないもの

| | なぜ |
|---|---|
| 講座のリンク | セミナーで案内済み。数日で繰り返すと、セミナー全体が集客だったことになる |
| 「ご検討ください」 | 検討を催促した時点で、相手の時間が自分のものでなくなる |
| 期限・残席 | 3名のセミナーに期限は不自然 |
| 感想のお願い | MOSHから自動で行く。二重で頼まない |
