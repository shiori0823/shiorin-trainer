# 05｜「今回は見送ります」と言われたとき

**送るタイミング：断りの返事をもらったら、その日のうちに。**

**この一通が、実は一番効きます。**

断ったあとに気持ちよく返してもらえた人は、相手のことを覚えています。
半年後に申し込む人もいますし、周りの選手に話してくれる人もいます。
パワーリフティングは狭い世界です。ここで気持ちよく終われるかどうかは、
そのまま先につながります。

**ここで粘らない。** それが一番の売り込みになります。

---

## 件名

```
ご連絡ありがとうございました
```

## 本文

```
【お名前】さん

ご連絡ありがとうございます。佐藤です。

わざわざ教えてくださって助かりました。
今回のお話は、これで終わりにしますね。


先日の相談でお話ししたことは、
講座を受けなくても使えるものばかりです。

　やること　　　【やること】
　やらないこと　【やらないこと】

これだけは、ぜひ続けてみてください。
本当に、これだけでも変わります。


【試合名・時期】、応援しています。
結果はどちらでも、よかったら教えてください。

またお話ししたくなったときは、いつでも連絡してください。
そのときは改めてご一緒しましょう。

佐藤 栞
```

---

## LINE / DM 用（短縮版）

```
【お名前】さん、ご連絡ありがとうございます！

わざわざ教えてくださって助かりました。
今回のお話はこれで終わりにしますね。

先日決めた
「【やること】」「【やらないこと】」だけは
ぜひ続けてみてください。これだけでも変わります🙌

【試合名・時期】、応援しています！
結果はどちらでも、よかったら教えてください😊
```

---

## 書くときの注意

- **理由を聞かない。** 「差し支えなければ理由を」は、断った人にもう一度
  説明させる行為です。相手はもう気を使って断ってくれています
- **「またの機会に」で終わらせず、具体的に応援して終わる。** 試合名を出して
  応援するだけで、営業の関係から人の関係に戻ります
- **「結果を教えてください」は入れておく。** ここから連絡が復活することが
  実際にあります。ただし催促はしません
- この一通のあと、**こちらから追加の連絡はしない**。次に動くのは相手からです
