# 04｜お申し込みをいただいたとき

**送るタイミング：申し込みを確認したらすぐ（当日中）。**

申し込み直後は、期待と同時に「本当に大丈夫かな」という不安が出ます。
**この一通で不安を消して、初回までにやることをはっきりさせます。**

---

## 件名

```
お申し込みありがとうございます／初回日程のご相談
```

## 本文

```
【お名前】さん

お申し込みいただき、ありがとうございます。
佐藤栞です。

【試合名・時期】に向けて、ここから3か月ご一緒します。
よろしくお願いします。


まず、初回の日程を決めさせてください。
以下から、都合のよいものをいくつか教えてください。

　・【候補日1】
　・【候補日2】
　・【候補日3】

上記が合わない場合は、ご希望の曜日と時間帯を教えていただければ
こちらで調整します。


初回までに、2つだけお願いがあります。

1つめ。次の試合の日程と、目標にしている記録を
　　　もう一度書き出しておいてください。

2つめ。直近の試合で「うまくいかなかった場面」を
　　　1つ思い出しておいてください。細かいほど助かります。

どちらも、うまく書けなくて大丈夫です。
初回に一緒に整理していきます。


相談のときに決めた「【やること】」は、そのまま続けていてください。
初回で、そこからの続きを組み立てます。

それでは、日程のご連絡をお待ちしています。

佐藤 栞
```

## LINE / DM 用（短縮版）

```
【お名前】さん、お申し込みありがとうございます！

【試合名・時期】に向けて、ここから3か月よろしくお願いします🔥

まず初回の日程を決めさせてください。
下から都合のいいものを教えてください。

　・【候補日1】
　・【候補日2】
　・【候補日3】

合わなければ、希望の曜日と時間帯を教えてもらえれば調整します！

初回までに2つだけお願いです。
①次の試合の日程と目標の記録を書き出しておく
②直近の試合でうまくいかなかった場面を1つ思い出しておく

どちらもうまく書けなくて大丈夫です。一緒に整理します🙆‍♀️
```

---

## 書くときの注意

- **「不安にさせない」が最優先。** 決済のあとは誰でも一瞬不安になります。
  ここで具体的な次の一歩を渡すと、その不安が期待に変わります
- 初回までの宿題は**2つまで**。3つ以上出すと、できなかった罪悪感で
  初回のテンションが下がります
- 相談で決めた「やること」を引き継いでいることを伝えると、無料相談と
  講座が地続きになります
