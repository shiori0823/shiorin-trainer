# 06｜返事がないまま2週間たったとき（これで最後）

**送るタイミング：03を送ってから2週間後。返事がないまま。**

**この一通で終わりにします。** これ以上は届きません。

返事がないのは、たいてい「断りにくい」からです。責めているように読める
文面を送ると、相手はますます返せなくなります。**こちらから終わらせて
あげる**のが、一番親切です。

---

## 件名

```
今回はここまでにしますね
```

## 本文

```
【お名前】さん

佐藤です。先日はありがとうございました。

講座の受付が終わりましたので、
今回のご案内はここまでにします。

お返事は不要です。
お忙しいところ、こちらから何度もすみませんでした。


先日の相談で決めた

　やること　　　【やること】
　やらないこと　【やらないこと】

これだけは、講座に関係なく続けてみてください。
【試合名・時期】に向けて、これが効いてくると思います。


また必要になったときは、いつでも連絡してください。
そのときはゼロから説明しなくて大丈夫です。覚えています。

【試合名・時期】、応援しています。

佐藤 栞
```

---

## 書くときの注意

- **「お返事は不要です」を必ず入れる。** これがこの一通の核心です。相手を
  返事の義務から解放します。皮肉に読まれないよう、責める言葉は一切入れません
- **「ご検討状況はいかがでしょうか」は書かない。** 催促です
- **「覚えています」は本当に効きます。** 半年後・1年後に連絡が来ることが
  あります。そのとき最初から説明しなくていいと分かっていると、
  連絡のハードルが下がります
- **これを送ったら、こちらからの連絡は止める。** リストに入れて一斉配信を
  送るようなことはしないでください。ここまで丁寧にやった意味がなくなります
