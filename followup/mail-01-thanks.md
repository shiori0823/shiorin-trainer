# 01｜当日中に送るお礼

**送るタイミング：相談が終わったその日のうち。できれば1〜2時間以内。**

この一通が、フォローの中で一番大事です。相手の熱が残っているうちに、
「決めたこと」を文字にして返します。

---

## 件名

```
【今日決めたこと】本日はありがとうございました
```

## 本文

```
【お名前】さん

本日はお時間をいただき、ありがとうございました。
佐藤栞です。

【試合名・時期】に向けたお話、しっかり聞かせていただきました。


今日、【お名前】さんが決めたことを書いておきます。

　やること　　　【やること】
　やらないこと　【やらないこと】

まずはこの2つだけで十分です。
次の練習から、試してみてください。

うまくいってもいかなくても、それが情報になります。
「やってみたらこうだった」が分かることが、次につながります。


最後に伺った「【一番印象に残ったこと】」というお話、
とても印象に残っています。


今日お話しした講座については、持ち帰ってゆっくり考えてください。
急いで決めていただく必要はまったくありません。

やってみて分からないことが出てきたら、
このまま返信して聞いていただいて大丈夫です。

次の試合、応援しています。

佐藤 栞（しおりん）
```

---

## LINE / DM 用（短縮版）

```
【お名前】さん、本日はありがとうございました！

今日決めたことを書いておきますね。

　やること：【やること】
　やらないこと：【やらないこと】

まずはこの2つだけで十分です。
次の練習から試してみてください🏋️

講座のことは、ゆっくり考えてもらって大丈夫です。
やってみて分からないことが出てきたら、いつでも聞いてください！
```

---

## 書くときの注意

- **講座の申し込みリンクは、この一通には貼らない。** 貼った瞬間、相談全体が
  申し込みへの前振りだったように見えます。案内は次の03で十分です
- 「【一番印象に残ったこと】」は、38枚目で相手が言った言葉をそのまま使います。
  ここが本人の言葉になっているかどうかで、テンプレか本物かが分かります
- 長さはこのくらいが上限です。読み返す気になる長さで止めます
