# 02｜3日後の様子うかがい

**送るタイミング：相談から3日後。**

売り込みではありません。**決めたことを実際にやったか**を聞くだけの一通です。
ここで相手が一度でも実行できていると、「あの相談は役に立った」という記憶に
変わります。

---

## 件名

```
その後、【やること】はいかがですか？
```

## 本文

```
【お名前】さん

先日はありがとうございました。佐藤です。

あれから3日たちましたが、
「【やること】」はやってみられましたか？

うまくいっていたら、そのまま続けてみてください。
やりにくかったら、もっと小さくして大丈夫です。

たとえば毎回やるのが難しければ、
「一番大事な一本の前だけ」に減らす、という形でも十分です。

続けられる形にすることが、一番大事です。


もし「やってみたけど、こういう時はどうすれば？」が出てきていたら、
このまま返信で聞いてください。お答えします。

佐藤 栞
```

---

## LINE / DM 用（短縮版）

```
【お名前】さん、その後どうですか？

「【やること】」はやってみられましたか？

やりにくかったら、もっと小さくして大丈夫です。
続けられる形にするのが一番大事なので🙆‍♀️

何か出てきたら気軽に聞いてくださいね！
```

---

## 書くときの注意

- **講座の話は一切しない。** この一通は完全に相手のためのものです
- 返事がなくても気にしない。読まれていれば効果はあります
- 返事が来たら、**そこで一往復ちゃんと答える**。ここで丁寧に答えられるかが、
  「この人に習ったらこうなる」の実演になります
