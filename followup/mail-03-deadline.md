# 03｜1週間後・締切のお知らせ

**送るタイミング：相談から1週間後。**

**この一通が、講座の話をする唯一の場所です。** 01と02で先に価値を渡して
あるので、ここで案内をしても押し売りになりません。

---

## 件名

```
講座のお申し込みについて（【締切日】まで）
```

## 本文

```
【お名前】さん

お世話になっております。佐藤です。

先日お話しした
「パワーリフターのための実践メンタルトレーニング」について、
受付の期限をお知らせします。

　　【締切日】まで／5名限定

一人ひとりの試合日程と課題に合わせて組み立てるため、
今回は5名までとさせていただいています。


改めて、内容です。

　完全1対1（Zoom）／全10回・1回60分／最長3か月
　受講料 98,000円（税込）

　▼ 詳しい内容とお申し込みはこちら
　https://mosh.jp/services/404875?openExternalBrowser=1


【お名前】さんの場合は、【試合名・時期】まで日があるので、
そこに合わせてペースを組むことができます。


ご検討の結果、今回は見送るということでもまったく問題ありません。
そのときは一言そう返していただければ、こちらからのご連絡は止めます。

先日決めた「【やること】」は、講座を受けても受けなくても
続けてみてください。あれだけでも変わります。

佐藤 栞
```

## 書くときの注意

- **「見送るなら一言ください」を必ず入れる。** これを書いておくと、相手は
  断りやすくなり、こちらは追いかけずに済みます。両方が楽になります
- **枠が埋まっていないのに「残り1名」と書かない。** 実際の残数だけを書きます。
  埋まっていないなら「5名限定」とだけ書けば十分です
- **値引きしない。** 迷っている人に安くすると、決め手が「値段」に変わります。
  そこで入った人は続きません
- 最後にもう一度「やること」に触れて終わります。この一通も、売り込みではなく
  応援として終わらせます
