# 60分 無料個別相談スライド（全32枚）

`consultation-deck.pptx` … PowerPoint／Keynote／Googleスライドで開けます。
Zoomの画面共有でそのまま使えます。

## 構成

| Phase | スライド | 内容 |
|---|---|---|
| 1 | 1–4 | 現在地を知る（次の試合・目標・気持ち・課題） |
| 2 | 5–9 | しおりんのストーリー |
| 3 | 10–14 | 3つの思い込みを壊す |
| 4 | 15–20 | メンタルトレーニングとは |
| 5 | 21–23 | 受講された方の変化 |
| 6 | 24 | あなたの場合を整理する |
| 7 | 25–30 | 講座のご案内・受講料・5名限定 |
| 8 | 31–32 | クロージング |

各スライドの左上にPhase名、右下にページ番号を入れています。時間は入れていません。

## デザイン

- 配色はLP・チラシと同じ。白を基調に、ワインレッド `#7A1524`（濃 `#540E19`）が主役
- **見出しは明朝体（游明朝）、本文はゴシック体（游ゴシック）**
- 本文は17〜21pt、見出しは28〜40pt。離れた画面でも読める大きさにしています
- 挿絵は使わず、文字と余白で構成。写真は3枚（表彰台・講座紹介・クロージング）

## 試合の時系列（写真と本文を合わせるための整理）

| 時期 | 出来事 |
|---|---|
| 2023年度 日本グランプリ | スクワット日本記録を狙ったが、直前の体調不良で重量を下げた。日本一にはなった |
| 2023年度 JCP | 日本グランプリより上の大会。ここでも日本一。記録はまだ |
| 2024年 世界大会 | 出場 |
| 2024年度 JCP | スクワット日本記録を達成 |

8枚目の表彰台の写真は **2023年度JCP** のものです。スライド上にも大会名の
キャプションを入れています。競技中のスクワット・デッドリフトの写真は
**2024年度JCP**（日本記録を取った試合）のものなので、それ以外の試合の話に
添えないよう注意してください。

## 文言を直したいとき

**PowerPointで直接編集できます。** テキストボックスをクリックして書き換えるだけです。

大きく作り直す場合は、`build.js` を編集して作り直します。

```sh
cd deck
npm install pptxgenjs           # 初回のみ
node build.js
```

- `build.js` … スライドの中身とレイアウト
- `images/closing-dark.jpg` … 最終スライドの背景（あらかじめ暗くした写真）

以前は各スライドに線画の挿絵を入れていました。必要になったら復元できます
（`illus.js` がgitの履歴に残っています）。

## 注意

文字数を増やすと枠からはみ出すことがあります。文言を大きく変えたときは、
一度スライドショーで通して確認してください。

フォントは見出しに「游明朝」、本文に「游ゴシック」を指定しています。どちらも
Windows・Macに入っている書体ですが、無い環境では別の書体に置き換わり、
文字幅が変わります。
