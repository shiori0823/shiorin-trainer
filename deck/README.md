# 60分 無料個別相談スライド（全39枚）

`consultation-deck.pptx` … PowerPoint／Keynote／Googleスライドで開けます。
Zoomの画面共有でそのまま使えます。

## 構成

| Phase | スライド | 内容 |
|---|---|---|
| 1 | 1–4 | 現在地を知る（次の試合・目標・気持ち・課題） |
| 2 | 5–9 | しおりんのストーリー |
| 3 | 10–14 | 3つの思い込みを壊す |
| 4 | 15–20 | メンタルトレーニングとは |
| 5 | 21–25 | **ケニーさんの声（対談より）** |
| 5 | 26–28 | 受講された方の変化 |
| 6 | 29–30 | あなたの場合を整理する／**今日持ち帰るものを1つ決める** |
| 7 | 31–36 | 講座のご案内・受講料・5名限定 |
| 8 | 37–39 | **今日決めなくて大丈夫です**／感想／クロージング |

各スライドの左上にPhase名、右下にページ番号を入れています。時間は入れていません。

## デザイン

- 配色はLP・チラシと同じ。白を基調に、ワインレッド `#7A1524`（濃 `#540E19`）が主役
- **見出しは明朝体（游明朝）、本文はゴシック体（游ゴシック）**
- 本文は17〜21pt、見出しは28〜40pt。離れた画面でも読める大きさにしています
- 挿絵は使わず、文字と余白で構成。写真は5枚（表彰台・ケニーさん2枚・講座紹介・クロージング）

## 30枚目と37枚目について（意図的に置いています）

この2枚は、**無料相談を「話してよかった」と思ってもらうため**の枚です。
削らないでください。

**30枚目「今日、持ち帰るものを1つ決めましょう」**
講座の案内（31枚目〜）に入る直前に置いています。先に持ち帰るものを渡して
しまうことで、そのあとの案内が「売り込み」ではなく「もっと必要ならこういう
手もあります」に変わります。ここを飛ばすと、1時間の話が案内のための前振り
だったように受け取られてしまいます。

**37枚目「今日、決めなくて大丈夫です」**
36枚目の「5名限定」の直後に置いています。急かされた記憶を持ち帰らせない
ための枚です。ここで一度ゆるめてから、38枚目で感想を聞きます。

38枚目で感想を聞いたあと、口頭でもう一問おすすめです。

> 「今日の話で、明日からやってみようと思えたことはありますか？」

ここに**具体的な答えが返ってきたら、その相談は成功**です。
「頑張ります」なら届いていません。「3本目の前の呼吸を決めます」なら
届いています。

## 文言を直したいとき

**PowerPointで直接編集できます。** テキストボックスをクリックして書き換えるだけです。

大きく作り直す場合は、`build.js` を編集して作り直します。

```sh
cd deck
npm install pptxgenjs           # 初回のみ
node build.js
```

- `build.js` … スライドの中身とレイアウト
- `images/closing-dark.jpg` … 最終スライドの背景（あらかじめ暗くした写真）

以前は各スライドに線画の挿絵を入れていました。必要になったら復元できます
（`illus.js` がgitの履歴に残っています）。

## 注意

文字数を増やすと枠からはみ出すことがあります。文言を大きく変えたときは、
一度スライドショーで通して確認してください。

フォントは見出しに「游明朝」、本文に「游ゴシック」を指定しています。どちらも
Windows・Macに入っている書体ですが、無い環境では別の書体に置き換わり、
文字幅が変わります。
