# 60分 無料個別相談スライド（全32枚）

`consultation-deck.pptx` … PowerPoint／Keynote／Googleスライドで開けます。
Zoomの画面共有でそのまま使えます。

## 構成

| Phase | スライド | 内容 |
|---|---|---|
| 1 | 1–4 | 現在地を知る（次の試合・目標・気持ち・課題） |
| 2 | 5–9 | しおりんのストーリー |
| 3 | 10–14 | 3つの思い込みを壊す |
| 4 | 15–20 | メンタルトレーニングとは |
| 5 | 21–23 | 受講された方の変化 |
| 6 | 24 | あなたの場合を整理する |
| 7 | 25–30 | 講座のご案内・受講料・5名限定 |
| 8 | 31–32 | クロージング |

各スライドの左上にPhase名、右下にページ番号を入れています。時間は入れていません。

## デザイン

- 配色はLP・チラシと同じ。白を基調に、ワインレッド `#7A1524`（濃 `#540E19`）が主役
- 本文は17〜20pt、見出しは28〜34pt。離れた画面でも読める大きさにしています
- 挿絵はすべて線画（`illus.js` で生成）。写真は競技中の3枚とヒーロー写真を使用

## 文言を直したいとき

**PowerPointで直接編集できます。** テキストボックスをクリックして書き換えるだけです。

大きく作り直す場合は、`build.js` を編集して作り直します。

```sh
cd deck
npm install pptxgenjs sharp     # 初回のみ
node build.js
```

- `build.js` … スライドの中身とレイアウト
- `illus.js` … 挿絵（SVGの線画）
- `images/closing-dark.jpg` … 最終スライドの背景（あらかじめ暗くした写真）

## 注意

文字数を増やすと枠からはみ出すことがあります。文言を大きく変えたときは、
一度スライドショーで通して確認してください。

フォントは「游ゴシック」を指定しています。Windows・Macどちらにも入っている
書体ですが、無い環境では別の書体に置き換わり、文字幅が変わります。
