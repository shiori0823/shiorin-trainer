# 90日伴走プログラムを、1,000万の側から見る（2026-10-16）

商品設計の話ではなく、**これが年間いくらを運ぶのかという話。**
`strategy/verify.md` の「② パーソナルを増やす」に入る数字。

---

# 1　先に結論

```
時間は、まったく足りる。
足りないのは、人数。
```

## 時間を数えてみる

| | 個別セッション | 2人で割る前の合計 |
|---|---|---|
| ベーシック | なし | **0分** |
| スタンダード | 120＋90＋60 | **270分（4.5時間）** |
| プレミアム | 270＋自由枠60×3 | **450分（7.5時間）** |

※月1ラリーの動画確認はオーナー担当。プレミアムのLINEは別。

**かりに1年でスタンダード10名・プレミアム5名を売ったとしても、**

```
10名 × 4.5時間 ＋ 5名 × 7.5時間 ＝ 82.5時間（2人ぶん）
```

**年82.5時間。** しおりんの担当がその半分なら、**年40時間。週1時間に届かない。**

**1〜2月を空けることも、高重量期を避けることも、この工数なら成り立つ。**

# 3　しおりんの400万に届かせるには

配分が半分として、**配分前で800万が要る。**

```
ベーシック50名　＋　スタンダード15名　＋　プレミアム8名　＝　約784万
```

**年73名。** 岡山のジムの中だけでは、まず埋まらない。

## 埋まらない理由は、ベーシック以外が岡山に縛られること

| | 場所 | 時間 | 上限 |
|---|---|---|---|
| ベーシック | **どこでも** | **使わない** | **ほぼ無い** |
| スタンダード | 施設利用込み＝岡山 | 4.5時間／人 | ジムに来られる人の数 |
| プレミアム | 同上 | 7.5時間／人 | 同上 |

**ベーシックだけが、岡山にも時間にも縛られていない。**

```
49,800円 × 100名 ＝ 498万円
```

**これが、しおりんの400万に届く唯一の形だと思う。**

## そして、ベーシックの入口は、もう全部ある

| | |
|---|---|
| `lp/` | パワーリフター向けLP |
| `note/` | 一般向けの記事 |
| `seminar/` | 63枚のワークショップ |
| `line/` | 公式LINEと診断 |
| `sheets/` | ワークシートの配布ページ |
| `secondo/` | セコンド指示書 |

**作ったものが全部ここにつながる。**
「できたのかけらの独立展開はしない」と決めたあと、**集めた人の行き先がこれになる。**

# 4　気になったところ（設計そのもの）

## ① 会員割引の幅が、プランでそろっていない

```
スタンダード　198,000 − 158,000 ＝ 40,000
プレミアム　　298,000 − 248,000 ＝ 50,000
施設利用の相当額　　　　　　　　 ＝ 26,400
```

**どちらも26,400円より大きく、幅も違う。** 意図したものなら問題ない。
聞かれたときに答えられるようにしておきたい。

## ② プレミアムのLINEと、1〜2月

**90日間いつでも相談可。** 申込が11月なら、90日は1月末まで届く。
**試合に集中する時期と重なる。**

「原則1営業日以内」は守れる設計だけれど、**重なる期間を先に決めておくほうが楽。**

```
例：プレミアムの申込は、◯月〜◯月の大会に向けた分まで
```

## ③ ベーシックを買った人との接点が、ゼロになる

対面なし、LINEなし。**買ったあと、こちらから触れる手段がない。**

売って終わりにしないなら、**差額でスタンダードへ上がれる道**を先に作っておく。

```
ベーシック 49,800 　→　差額 148,200 でスタンダードへ
```

アップセルの一覧には「追加個別セッション」「追加動画添削」があるので、
**そこへ案内する仕組み**（教材の最後、または購入後のメール）が要る。

## ④ オーナーの工数が、上限になる

月1ラリーも、プレミアムのLINEも、**技術側はオーナー担当。**
しおりんの時間は余っていても、**オーナーが同時に何名持てるかで売れる数が決まる。**

**→ そこを聞いておく。** 400万の計算は、そこで止まる。

## ⑤ いいと思ったところ

```
プレミアムを「時間」ではなく「判断」を売る形にしたこと
セコンドをプレミアム限定にしなかったこと
ベーシックを49,800円に下げて、教材商品として独立させたこと
メンタルを別講座にせず、節目に埋め込んだこと
```

**特に最後の1つ。** メンタルを切り離すと「必要な人だけのもの」になる。
節目に埋め込めば、**全員が通る。** できたのかけらの置き場所として、これ以上の形はない。

# 6　これまで作ったものは、どうなるか（2026-10-16）

## そのまま活きるもの（選手向け）

| | 新しい役目 |
|---|---|
| `lp/` パワーリフター向けLP | **ベーシックの販売ページの土台。** 対象がそのまま一致している |
| `note/` 選手向けの記事 | ベーシックへの入口。岡山の外にも届く |
| `seminar/` 63枚のワークショップ | **ベーシックの手前の入口。** 中身が教材と同じ系統なので、体験版として使える |
| `sheets/` ワークシート配布ページ | 9試技戦略シート・大会準備チェックシートは**ベーシックの同梱物そのもの** |
| `secondo/` セコンド指示書 | **オプション「セコンドサポート」の納品物そのもの** |
| `line/` 公式LINE | 受け皿。どの入口から来ても、ここで持てる |

**作り直しは要らない。行き先の名前が変わるだけ。**

## 役目が変わるもの（一般向け）

| | |
|---|---|
| `note/tadashiku-tatsu.md`（正しく立つ） | 一般の読者に届く記事。**ただし、その先のダイエット・コーチングはジム内＝岡山** |
| `line/` できたのかけら診断 | 同じ。診断を受けた人の行き先が、岡山に限られる |

**記事そのものは無駄にならない。** 名前を知ってもらう役目は残る。
ただし、**岡山の外の一般読者には、いま売るものがない。**

ここは割り切る。**選手向けは全国、一般向けは岡山。**

## まとめ

```
選手向けに作ったもの　→　ほぼ全部、そのまま使える
一般向けに作ったもの　→　記事は残る。行き先が岡山に限られる
できたのかけら　　　 →　捨てない。90日伴走の節目の中身になる
```
