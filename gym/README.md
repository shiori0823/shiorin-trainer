2026-10-15 会議決定版をそのまま記録したもの。

# 1　商品の中心価値

| | |
|---|---|
| しおりん | **安心感。**「自分にも挑戦できる」「何をすればいいか分かる」「一人ではない」 |
| オーナー | **強くなる道筋が分かること。** 指示されたとおりにやるのではなく、90日で「こう取り組むと強くなる」を体験する |

```
安心して挑戦しながら、自分が強くなる道筋を体験する90日間
```

# 2　オンライン教材は全プラン共通

12モジュール・約70レッスン。**全員が学ぶ基本部分。**

大会申込、道具、ルール、BIG3技術、身体特性、サイクルトレーニング、ピーキング、
試技戦略、当日準備、メンタル、振り返り。

```
事前に学ぶ　→　実践する　→　必要なところに個別指導を入れる
```

**ここで個別時間を使わない。**

# 3　個別指導は「回数」ではなく「タイミング」

| | 中身 | 目安 |
|---|---|---|
| ① 開始時 | 集中評価・方向性決定。BIG3フォーム、身体特性、現在地、課題と優先順位、プログラム、大会目標設定、挑戦する目的と不安の整理 | **120分** |
| ② サイクル終了時 | 振り返りと次のサイクル設計。成果確認、フォームの変化、できたこと／できなかったこと、技術課題、プログラム修正、できたのかけらの振り返り | **90分前後** |
| ③ 大会直前 | ピーキング確認、BIG3の状態、第一〜第三試技戦略、第一試技の最終決定、当日の流れ、不安整理、「これだけ準備してきた」の確認 | **60分前後** |

# 4　メンタルは、切り離さない

**トレーニングサイクルの節目と連動させる。**

| | |
|---|---|
| 開始時 | 納得感のある目標設定。「自分もこれなら挑戦できる」 |
| サイクル中 | **できたのかけら**を記録し、成長を見失わない |
| サイクル終了時 | できたこと／成長したこと／まだ不安なこと／思うようにいかなかったこと／次に挑戦したいこと |
| 大会直前 | 「できると思い込む」のではなく、**やってきた事実を根拠に自分を信頼する** |
| 大会後 | 結果で終わらせず、次の挑戦へつなぐ |

# 5　3プラン　──　差は「学べる内容」ではなく「どこまで任せられるか」

## ベーシック　49,800円（税込）

**自分で学び、自分で進めるオンラインコース。**

- 12モジュール・約70レッスン
- 各種ワークシート／大会準備チェックシート／9試技戦略シート／できたのかけらワークブック
- 個別対面：なし　／　LINE個別サポート：なし

以前の148,000円案から変更し、**動画教材商品として独立させた。**

## スタンダード　198,000円（非会員・施設利用込み）／ 158,000円（会員）

**重要な節目で、専門家に現在地を確認してもらいながら大会へ進む。**

- 個別セッション **固定3回**（開始時・サイクル終了時・大会直前）
- LINE・動画フィードバック **月1ラリー**

### 1ラリーの定義

```
動画提出　→　オーナーが全体を確認してフィードバック
　　　　　→　実際に修正して再提出　→　再評価
```

**本人が指定した部分だけでなく、本人がまだ気づいていない改善点も見る。**

大会前には SQ・BP・DL それぞれの直近最重量動画を提出し、
**その状態を見て第一試技重量を決定する。**

日常的な無制限添削ではない。**必要な節目で、大会に直結する判断をもらえるサポート。**

## プレミアム　298,000円（非会員・施設利用込み）／ 248,000円（会員）

**「たくさん指導してもらえる」ではなく、重要な判断を深く任せられる最上位。**

固定3回に加えて、**自由枠3回**（1回約60分）。

内容は固定しない。フォームチェック／技術修正／プログラム相談／サイクル修正／
メンタルコーチング／不安整理。**フォーム2＋メンタル1でも、メンタル3でもよい。**

```
こちらが決めた節目3回　＋　本人が「今必要」と感じたときに使える3回
```

### LINEサポート

```
90日間いつでもLINE相談可／返信は原則1営業日以内
```

**「何往復でも即返信」ではない。** 深い相談は自由枠3回を使う。
**安心感と、提供側の時間を守る仕組みの両立。**
