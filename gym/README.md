# ★ どこで作るか（先に決めること）

## 結論：別のリポジトリ（非公開）を推す

理由は1つで、それが決定的。

## このリポジトリは公開されている

```
ジムの講座　→　オーナーさんと一緒にやる
　　　　　　→　料金・分配・オーナーの担当範囲が入る
　　　　　　→　それは栞さん一人のものではない
```

いまこのリポジトリには栞さん自身の値段（10万円／30万円／29万8000円）が
書いてある。**これは自分のことなので、自分で決められる。**

ジムの講座は**オーナーさんの経営の話が混ざる。**
ジムの名前、取り分、オーナーさんの担当範囲。
公開の場所に置くかどうかを、栞さん一人では決められない。

**「後で消す」ができないのが公開リポジトリの怖いところ。** 履歴に残る。

## このリポジトリを非公開にするのはダメ

```
kakera/dekita-shindan.pdf　→　LINEで配りはじめたURL
ichihon/ichihon-sheet.pdf　→　LINEで配りはじめたURL
lp/                        →　公開中のLP
```

**非公開にすると全部のURLが開けなくなる。** ここは触らない。

## おすすめの形

```
① 新しいリポジトリを作る（Private）
② そこで新しいセッションを開く
③ オーナーさんにも見せたくなったら、そのリポジトリだけ共有する
```

**③ができるのが一番大きい。** オーナーさんと一緒に見ながら作れる。
