# どこで作るか → **ここ（このリポジトリの `gym/`）で作る**

**2026-10-01 決定。**

## 当初の「別の非公開リポジトリ」は取り下げ

Claudeが「オーナーさんは第三者」という前提で言っていた。
**オーナーはご主人。** 家庭も事業も一緒に進めているので、前提が成り立たない。

## ここで作る理由

```
① 第三者の経営情報ではない
② ご主人もClaude Codeを使える　→　同じリポジトリで作業できる
③ ジムの講座はこのファネルの入り口　→　90日講座やLPと同じ場所にある方がいい
```

**引き継ぎ書も不要。** 前提を全部持っているセッションでそのまま作れる。

# ★ 料金と分配だけは公開しない

栞さん自身の値段（10万円／30万円／29万8000円）は**自分のことなので公開していい。**

**ジムの売上の分け方は、ジムの経営数字。**
競合や取引先が見て得することはあっても、栞さんが得することはない。

名刺のメールアドレスと同じやり方でいく。

| ファイル | |
|---|---|
| `gym/README.md` | **公開**（カリキュラム・対象・進め方） |
| `gym/terms.md` | **非公開**（料金・分配）※ `gym/.gitignore` で除外済み |

**決まったら `gym/terms.md` に書けば、自動的に公開されない。**
（`namecard/mail.txt` と同じ仕組み）
