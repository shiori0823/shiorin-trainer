## 件名

```
【ご確認】当日の60分、こんな流れで進めます
```
（23文字）

## 本文

```
【お名前】さん

個別相談にお申し込みいただき、ありがとうございます。
佐藤栞です。

まず、お伝えしたいことがあります。

申し込みボタンを押すのは、けっこう勇気がいったと思います。
「メンタルの相談をする」というのは、
試合の重量を上げるより、ずっと言い出しにくいことだからです。

その一歩を踏み出してくださったこと、本当にうれしいです。


　▼ 当日のZoomはこちらです（今すぐカレンダーに入れてください）
　【ZoomURL】


さて、申し込んだあとに、
こんなことを考えていませんか。

　「何を話せばいいんだろう」
　「うまく説明できる自信がない」
　「売り込まれたらどうしよう」

全部、当然のことだと思います。


なので、先に全部お見せします。

当日の60分は、この順番で進みます。

　1. 次の試合で、絶対に取りたい一本を聞かせてもらう
　2. 私が日本記録を取るまでに、何で3年つまずいたかを話す
　3. メンタルについての「3つの思い込み」を壊す
　4. 具体的な考え方を、その場で使える形で渡す
　5. 実際に受けた選手が、何をどう変えたかを見てもらう
　6. あなたの場合を整理して、明日やることを1つ決める

そのあと講座のご案内もしますが、
当日決めていただく必要はまったくありません。

私が一番大事にしているのは、
この60分のあとに、あなたが次の試合に向けて
動き出せることです。


準備は、1つだけお願いします。

　次の試合の日程と、絶対に取りたい一本。

この2つだけ、頭の中で決めておいてください。
紙に書く必要もありません。
「11月の県大会で、スクワット180」くらいのざっくりで大丈夫です。

これさえ決まっていれば、60分まるごと
あなたの試合の話に使えます。


実際に受けてくださった選手も、
最初はこう言っていました。

　「正直、何をするのか分かっていなかった。
　　でも、この人なら学べるものがあると思って受けた」

分からないまま来ていただいて大丈夫です。
それを整理するのが、この60分です。


　▼ 当日はこちらから
　【ZoomURL】

当日、お会いできるのを楽しみにしています。

佐藤 栞（しおりん）


P.S.
次のメールで、
「練習ではPRが出るのに、試合で出ない人」に
共通している、たった1つの勘違いについて書きます。

当日の話の核心にあたる部分なので、
届いたら読んでみてください。
```

## 自己評価（60点満点）

| 項目 | 点 | 判断 |
|---|---|---|
| 件名の引力 | 8 | 【ご確認】で開封率は取れる。煽らない路線を初手で示せている |
| 共感度 | 10 | 「申し込みボタンを押すのは勇気がいった」から入るのが最大の武器 |
| 価値提供度 | 9 | 60分の中身を全部開示。不安の正体をその場で消している |
| 数字・事例の説得力 | 7 | ケニーさんの引用が1つのみ。ここは2通目で回収する設計 |
| ストーリー一貫性 | 10 | 相談スライドと完全に同じ順番・同じ思想 |
| CTAの明確さ | 9 | Zoomリンク1本に絞り、上部・下部に自然配置 |
| **合計** | **53** | |

**修正して上げたところ**
- 初稿では宿題を3つ出していた → **1つに削減**。申し込み直後に宿題が多いと、
  それ自体が心理的負担になり、当日の欠席理由になる
- 初稿の件名は「お申し込みありがとうございます」 → 開封動機がゼロなので、
  **中身が分かる件名**に変更
- 「売り込まれたらどうしよう」を**こちらから先に言語化**。相手が心の中で
  思っていることを先に言うと、その時点で警戒が半分落ちる

**あえて上げなかったところ**
- 数字・事例（7点）は意図的です。1通目で実績を並べると自慢に見えます。
  1通目は「この人は安全だ」だけを作り、証拠は2通目に集中させています
