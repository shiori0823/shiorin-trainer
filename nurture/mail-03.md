# 3通目｜個別相談の前日

**役割：期待の最大化／不安の除去／当日への引き渡し**
**CTA：明日のZoomリンク**

---

## 件名

```
明日の60分のために、1つだけ準備してください
```
（23文字）

　【ZoomURL】

## 自己評価（60点満点）

| 項目 | 点 | 判断 |
|---|---|---|
| 件名の引力 | 9 | 「1つだけ」で負担感を消しつつ、開かないと損な形にしている |
| 共感度 | 9 | 「言葉にならないから困っている」が刺さる位置にある |
| 価値提供度 | 9 | 5ステップを技術練習と同じ構造だと示し、当日の理解を前倒し |
| 数字・事例の説得力 | 8 | しおりん自身の失敗談。数字は少ないが、前日は体温のほうが効く |
| ストーリー一貫性 | 10 | 2通目の予告を回収し、当日のPhase 1へそのまま接続 |
| CTAの明確さ | 10 | Zoomリンクのみ。冒頭・末尾の2箇所 |
| **合計** | **55** | |

**修正して上げたところ**
- 初稿は準備を「3つ思い出す」だった → **1つに削減**。前日に負担を増やすと
  ドタキャンの理由になります
- 初稿では日本記録の話を成功談として書いていた → **失敗談に書き換え**。
  前日に実績を誇示すると、相手との距離が開きます。ここで縮めておかないと、
  当日の1問目（絶対に取りたい一本）で本音が出ません
- 「講座の案内もします」を**あえて書いた**。書かずに当日案内すると、
  だまし討ちになります。先に言っておけば、案内の時間に身構えられません

**受講料について（しおりんさんのご判断どおり、金額は入れていません）**

先にお伝えしておくと、私の当初案は「前日に98,000円を開示する」でした。
狙いは、当日の価格ショックをなくして、60分を丸ごと相談に使ってもらうことです。

ただ、しおりんさんのご指摘のとおり、**価値が伝わりきる前に金額を出すと、
そこから先が全部「10万円の話」として読まれる**というリスクがあります。
LPにも金額を載せていない今の設計とも、ちぐはぐになります。

なので**金額は入れず、「案内があること」だけ予告する形**にしました。
不意打ち感は消えて、価格が先に立つことはありません。ここが折り合いの位置だと
考えています。

もし途中で「やっぱり先に出したい」となったら、末尾のP.S.の上に
この3行を差し込むだけで切り替わります。

```
なお、講座は全10回・完全1対1で98,000円（税込）です。
明日その場で金額を見て驚かないように、先にお伝えしておきます。
内容だけ見ていただければ大丈夫です。
```
