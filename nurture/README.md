# 個別相談までの3日間ステップメール

**申し込み直後から個別相談当日まで**に送る、3通のナーチャリングメールです。
ゴールは「当日、前のめりで来てもらうこと」。

相談が**終わったあと**に送る文面は `../followup/` にあります。

| ファイル | 送るタイミング | 役割 |
|---|---|---|
| `mail-01.md` | 申し込み直後（その日のうち） | 期待値の設計・不安の除去 |
| `mail-02.md` | 相談の前々日 | 価値提供・思い込みを1つ壊す |
| `mail-03.md` | 相談の前日 | 準備の指示・当日への引き渡し |

### 3通を貫くストーリー

```
1通目　この人は安全だ・ここで何が起きるか分かった
　　↓（予告：試合で出ない人に共通する勘違い）
2通目　え、そうだったのか・これ明日から使える
　　↓（予告：当日の準備が1つある）
3通目　この人も同じだったのか・明日が楽しみだ
　　↓
当日　　Phase 1「次の試合で、絶対に取りたい一本はありますか？」
```

3通目の最後が、**そのままスライド1枚目の問いに接続**します。当日その質問が
来たとき、相手はすでに答えを用意した状態で座っています。

### リードタイムがバラバラな場合

送信日を「当日から逆算」で固定してください。

| 空き日数 | 送り方 |
|---|---|
| 3〜4日 | 直後 → 前々日 → 前日（そのまま） |
| 1週間以上 | 直後 → 前々日 → 前日（**間は空けたままで構いません**） |
| 2日しかない | 直後 → 翌日（2通目） → 前日（3通目） |
| 前日に申し込み | 1通目と3通目だけ送る。2通目は飛ばす |

**「毎日送る」ことより「前日に3通目が届く」ことのほうが大事です。**
2通目は間が空いても効果が落ちません。

## やってはいけないこと

- **3通とも読まれる前提で書かない。** 2通目だけ読む人もいます。各通が
  単独で価値を持つように書いてあります
- **返信を求めない。** 「ご質問があればお返事ください」は書いていますが、
  返事を催促する文は入れていません
- **煽らない。** 「残席わずか」「今だけ」は1通も使っていません。相談後の
  フォロー（`../followup/`）と思想を合わせています
- **当日の中身を全部書かない。** 思い込みは3つのうち1つだけ渡しています。
  ここを守らないと、当日の60分が消化試合になります
