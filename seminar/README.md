# 「できたのかけら」ワークショップ｜90分セミナー（全58枚）

`seminar-dekita.pptx` … PowerPoint／Keynote／Googleスライドで開けます。
Zoomの画面共有でも、会場のプロジェクターでもそのまま使えます。

フロント（入口）のセミナー用です。60分の無料個別相談で使うスライドは `../deck/` です。

## WORKスライドは色が変わります

**20枚目・31枚目・37枚目**の3枚だけ、背景がワインレッドになります。
参加者が「手を動かす番だ」と一目で分かるようにしたものです。

左上の表示も `WORK` に変わり、ページ番号は左下に出ます。
この3枚に来たら、説明をやめて**書く時間を取ってください。**

| 枚 | WORK | 書いてもらうもの |
|---|---|---|
| 20 | WORK 1 | 最近1か月の「できたのかけら」を10個 |
| 31 | WORK 2 | 次の試合で狙いたい数字と、120・100・80の3つ |
| 37 | WORK 3 | MY DO 3つ／MY DON'T 3つ |

21枚目は、WORK 1で手が止まった人のための質問リストです。
**書けない人が必ず出るので、飛ばさないでください。**

## デザイン

- 配色はLP・チラシ・個別相談スライドと同じ。白を基調に、ワインレッド `#7A1524`（濃 `#540E19`）
- **見出しは明朝体（游明朝）、本文はゴシック体（游ゴシック）**
- 本文は15〜21pt、見出しは26〜46pt。離れた画面でも読める大きさ
- 挿絵・写真は使っていません。文字と余白と色面だけで構成

### 色の使い分け

| 色 | 意味 |
|---|---|
| グレーの枠 | 「これではない」「以前の自分」 |
| ワインレッドの枠 | 「これ」「今の自分」「大事なこと」 |
| 濃いワインレッドの全面 | 章の切り替え・WORK・いちばん言いたい一言 |

14〜17枚目の `✕`／`◯` も同じ考え方です。グレーが思い込み、ワインレッドが答え。

## 43枚目の注記について

「受講された方の体験であり、同じ結果を保証するものではありません。」
という一文を小さく入れています。実際の受講者の変化を載せるときの定型なので、
**削除しないでください。**

## 50枚目以降の流れ（なぜこの順番か）

```
50  特典の紹介          → 今日の続きは一人でもできる
51  特典01 ワークシート
52  特典02 チェックシート
53  一人ひとり違います   → でも「自分の場合は？」までは一人では難しい
54  無料個別相談        ← ここが導線の着地
55  こんな方に来てほしい
56  講座の案内について   → その場で決めなくていい、と先に言う
57  今日のゴールは達成   → 相談に来ない人も、手ぶらでは帰さない
58  クロージング
```

**先に特典を渡してから個別相談の話をする**のがこの順番の肝です。
「今日の内容は一人でも続けられます」と言い切ったうえで、それでも
「自分の場合は何を変える？」までは一人では難しい、という流れで53枚目に入ります。

56枚目で「その場で決める必要はありません」と先に言っておくと、
54〜55枚目で身構えた人がここでゆるみます。**この1枚を飛ばさないでください。**

そして57枚目で、相談に来ない人にも「今日のゴールはもう達成している」と
渡して終わります。個別相談が目的のセミナーに見えないための枚です。

## ⚠ 特典のシート2枚は、まだ作っていません

51・52枚目で紹介している2つのシートは、**スライド上の紹介だけ**で、
配布物の実物はまだありません。セミナーまでに用意が必要です。

| 特典 | 中身 |
|---|---|
| 01 できたのかけら 見つけるワークシート | 最近できたこと／続けられたこと／挑戦したこと／休めたこと／失敗した後にできたこと |
| 02 「できた」を結果につなげるチェックシート | 何ができた？／なぜできた？／どんな力を使った？／次の目標にも使える？／次に何をする？／何をやらない？ |

A4・1枚ずつのPDFで作れます。20枚目のWORK 1とそのまま対応させると、
セミナー中に書いたものを持ち帰ってそのまま続けられます。

## 54枚目に申し込み方法が入っていません

無料個別相談のスライドに、URLもQRコードも入れていません。
口頭やチャットで案内する前提ならこのままで大丈夫ですが、
会場でやる場合はQRコードがあったほうが確実です。

チラシで使っているQRコード（`../flyer-mental/images/qr.svg`）を
そのまま置けます。

## 文言を直したいとき

**PowerPointで直接編集できます。** テキストボックスをクリックして書き換えるだけです。

大きく作り直す場合は `build.js` を編集して作り直します。

```sh
cd seminar
npm install pptxgenjs     # 初回のみ
node build.js
```

`build.js` の上のほうに、色（`C`）・書体（`F` / `FS`）・部品（`title` `card`
`bullets` `numbered` `band` `xo` `work`）がまとまっています。

## 注意

文字数を増やすと枠からはみ出すことがあります。文言を大きく変えたときは、
一度スライドショーで通して確認してください。

フォントは見出しに「游明朝」、本文に「游ゴシック」を指定しています。どちらも
Windows・Macに入っている書体ですが、無い環境では別の書体に置き換わり、
文字幅が変わります。
