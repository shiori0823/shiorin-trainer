# 「できたのかけら」ワークショップ｜90分セミナー（全49枚）

`seminar-dekita.pptx` … PowerPoint／Keynote／Googleスライドで開けます。
Zoomの画面共有でも、会場のプロジェクターでもそのまま使えます。

フロント（入口）のセミナー用です。60分の無料個別相談で使うスライドは `../deck/` です。

左上にセクション名、右下にページ番号。時間は入れていません。

## WORKスライドは色が変わります

**20枚目・31枚目・37枚目**の3枚だけ、背景がワインレッドになります。
参加者が「手を動かす番だ」と一目で分かるようにしたものです。

左上の表示も `WORK` に変わり、ページ番号は左下に出ます。
この3枚に来たら、説明をやめて**書く時間を取ってください。**

| 枚 | WORK | 書いてもらうもの |
|---|---|---|
| 20 | WORK 1 | 最近1か月の「できたのかけら」を10個 |
| 31 | WORK 2 | 次の試合で狙いたい数字と、120・100・80の3つ |
| 37 | WORK 3 | MY DO 3つ／MY DON'T 3つ |

21枚目は、WORK 1で手が止まった人のための質問リストです。
**書けない人が必ず出るので、飛ばさないでください。**

## デザイン

- 配色はLP・チラシ・個別相談スライドと同じ。白を基調に、ワインレッド `#7A1524`（濃 `#540E19`）
- **見出しは明朝体（游明朝）、本文はゴシック体（游ゴシック）**
- 本文は15〜21pt、見出しは26〜46pt。離れた画面でも読める大きさ
- 挿絵・写真は使っていません。文字と余白と色面だけで構成

### 色の使い分け

| 色 | 意味 |
|---|---|
| グレーの枠 | 「これではない」「以前の自分」 |
| ワインレッドの枠 | 「これ」「今の自分」「大事なこと」 |
| 濃いワインレッドの全面 | 章の切り替え・WORK・いちばん言いたい一言 |

14〜17枚目の `✕`／`◯` も同じ考え方です。グレーが思い込み、ワインレッドが答え。

## 43枚目の注記について

という一文を小さく入れています。実際の受講者の変化を載せるときの定型なので、
**削除しないでください。**

## 文言を直したいとき

**PowerPointで直接編集できます。** テキストボックスをクリックして書き換えるだけです。

大きく作り直す場合は `build.js` を編集して作り直します。

```sh
cd seminar
npm install pptxgenjs     # 初回のみ
node build.js
```

`build.js` の上のほうに、色（`C`）・書体（`F` / `FS`）・部品（`title` `card`
`bullets` `numbered` `band` `xo` `work`）がまとまっています。

## 注意

文字数を増やすと枠からはみ出すことがあります。文言を大きく変えたときは、
一度スライドショーで通して確認してください。

フォントは見出しに「游明朝」、本文に「游ゴシック」を指定しています。どちらも
Windows・Macに入っている書体ですが、無い環境では別の書体に置き換わり、
文字幅が変わります。
