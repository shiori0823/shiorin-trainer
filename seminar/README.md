## WORKスライドは色が変わります

**20枚目・31枚目・37枚目**の3枚だけ、背景がワインレッドになります。
参加者が「手を動かす番だ」と一目で分かるようにしたものです。

左上の表示も `WORK` に変わり、ページ番号は左下に出ます。
この3枚に来たら、説明をやめて**書く時間を取ってください。**

| 枚 | WORK | 書いてもらうもの |
|---|---|---|
| 20 | WORK 1 | 最近1か月の「できたのかけら」を10個 |
| 31 | WORK 2 | 次の試合で狙いたい数字と、120・100・80の3つ |
| 37 | WORK 3 | MY DO 3つ／MY DON'T 3つ |

21枚目は、WORK 1で手が止まった人のための質問リストです。
**書けない人が必ず出るので、飛ばさないでください。**

## デザイン

- 配色はLP・チラシ・個別相談スライドと同じ。白を基調に、ワインレッド `#7A1524`（濃 `#540E19`）
- **見出しは明朝体（游明朝）、本文はゴシック体（游ゴシック）**
- 本文は15〜21pt、見出しは26〜46pt。離れた画面でも読める大きさ
- 挿絵・写真は使っていません。文字と余白と色面だけで構成

### 色の使い分け

| 色 | 意味 |
|---|---|
| グレーの枠 | 「これではない」「以前の自分」 |
| ワインレッドの枠 | 「これ」「今の自分」「大事なこと」 |
| 濃いワインレッドの全面 | 章の切り替え・WORK・いちばん言いたい一言 |

14〜17枚目の `✕`／`◯` も同じ考え方です。グレーが思い込み、ワインレッドが答え。

## 50枚目以降の流れ（なぜこの順番か）

```
50  特典の紹介          → 今日の続きは一人でもできる
51  特典01 ワークシート
52  特典02 チェックシート
53  一人ひとり違います   → でも「自分の場合は？」までは一人では難しい
54  無料個別相談        ← ここが導線の着地
55  こんな方に来てほしい
56  講座の案内について   → その場で決めなくていい、と先に言う
57  今日のゴールは達成   → 相談に来ない人も、手ぶらでは帰さない
58  クロージング
```

**先に特典を渡してから個別相談の話をする**のがこの順番の肝です。
「今日の内容は一人でも続けられます」と言い切ったうえで、それでも
「自分の場合は何を変える？」までは一人では難しい、という流れで53枚目に入ります。

56枚目で「その場で決める必要はありません」と先に言っておくと、
54〜55枚目で身構えた人がここでゆるみます。**この1枚を飛ばさないでください。**

そして57枚目で、相談に来ない人にも「今日のゴールはもう達成している」と
渡して終わります。個別相談が目的のセミナーに見えないための枚です。

## 54枚目のQRコードについて

無料個別相談のスライド（54枚目）の右側に、申し込み用のQRコードを入れています。

- 読み取り先：`https://mosh.jp/services/404875`
- 画像：`images/qr.png`（誤り訂正レベルH。多少隠れても読めます）
- QRの下にURLの文字も併記してあるので、読み取れない人も手入力できます

**Zoomでやる場合も、同じURLをチャットに貼ってください。** スライドにも
「Zoomのチャットにも貼ります」と書いてあります。画面共有中のQRはスマホで
読み取れますが、共有が止まると消えるので、チャットに残しておくのが確実です。

URLを変えるときは、QRも作り直してください。

```sh
python3 -c "import segno; segno.make('新しいURL', error='h').save('seminar/images/qr.png', scale=20, border=2, dark='#540E19', light='#FFFFFF')"
```

作り直したら、**必ずスマホで実際に読み取って確認**してください。

## 文言を直したいとき

**PowerPointで直接編集できます。** テキストボックスをクリックして書き換えるだけです。

大きく作り直す場合は `build.js` を編集して作り直します。

```sh
cd seminar
npm install pptxgenjs     # 初回のみ
node build.js
```

`build.js` の上のほうに、色（`C`）・書体（`F` / `FS`）・部品（`title` `card`
`bullets` `numbered` `band` `xo` `work`）がまとまっています。

## 注意

文字数を増やすと枠からはみ出すことがあります。文言を大きく変えたときは、
一度スライドショーで通して確認してください。

フォントは見出しに「游明朝」、本文に「游ゴシック」を指定しています。どちらも
Windows・Macに入っている書体ですが、無い環境では別の書体に置き換わり、
文字幅が変わります。

# 開催のルール（2026-09-26 決定）

## 日程：大会から逆算する（月1回・土曜 9:30–11:00）

**「毎月第4土曜」で固定しようとしたが、取り下げた。大会日程に勝てない。**

正しいルールはこれ。

> **大会の2〜4週間前の土曜に置く。**

中身が目標の点数分け・やらないこと・試合当日の手順なので、
**大会が終わってから受けても遅い。**

2週間という距離には根拠がある。ケニーさんが国スポの2週間前にコーチングを受け、
翌日から早起きを始めて当日に間に合っている。**行動を変える時間として足りる。**

## 定員6名（新規4・再参加2）

第1回は3名全員に対して、一人ずつ数字を聞いて組み替えて返していた。
**それが効いた理由。**

時間配分から見て、**6名を超えると「全員に返す」が物理的に無理**になる。
7人目からは別のセミナーになる。

## ★ 過去の参加者は再参加を無料にする

第1回で、いちばん効いたのはこれだった。

もっちさん（個別相談を先に受けていた）が感想を話した**直後**に講座の案内へ入った。
**自分で「いいですよ」と言うより、受けた人が言うほうが通る。**

さらに、**もっちさんの答えがいちばん深かった。**
一度掘られている人の言葉を聞くと、**他の参加者の基準が上がる。**

講座で大事にしている「仲間のかけらを聞くことで見える」が、そのまま起きていた。

→ **毎回、経験者を1〜2人入れる。** 再参加を無料にすれば手間はゼロ。

### 「聞いたことある話」にならない理由

もっちさんは個別相談で同じ話を聞いていたが、セミナーでも真剣に聞いていた。

**2回目だから聞けている。**

1回目は「知らない話」として聞く。
2回目は、**一度やってみたあとで聞く。** 同じ話でも、聞いている場所が違う。

**再参加を無料にしていい根拠は、ここにある。**

## 導線は一方通行ではない

```
セミナー → 個別相談30分 → 3か月講座
個別相談60分 → セミナー → 3か月講座　← もっちさんの経路。これも正しい
```

**どちらから入ってもいい。** 個別相談から入った人は、次のセミナーに誘う。

## 料金：当面は無料のまま

定価3,300円・クーポンで無料を継続。

いま欲しいのは売上ではなく**事例と証言**。
3,300円×5名＝16,500円は、98,000円の講座1件に比べれば誤差。**人数が減るほうが損。**

### 無料の本当のコストは「来ないこと」

第1回でも、山ピーさんが前日の飲み会で参加を迷っていた。

→ **対策は値段ではなく、前日のリマインド。** 1行でいい。

**3回やって平均人数を見てから**、有料にするか決める。
