# SNS投稿用の画像（Instagram）

「できたのかけら」ワークショップ（9/26）の告知画像です。

| ファイル | サイズ | 用途 |
|---|---|---|
| `story-1080x1920.png` | 1080×1920 | Instagram・LINEのストーリーズ |
| `feed-1080x1350.png` | 1080×1350 | Instagramのフィード投稿 |
| `captions.md` | — | **投稿文・DM文・6日間の動かし方** |

投稿する文章は `captions.md` にあります。そのままコピーして使えます。

## ストーリーズにはリンクステッカーを貼ってください

画像に「↓ リンクから申し込めます」と入れてあります。**その矢印の下に
リンクステッカーを置いてください。**貼り忘れると、申し込む方法がなくなります。

リンク先はこちらです。

```
https://mosh.jp/services/76e3ba8b9a1e4ad8ae079de96bbebc56?openExternalBrowser=1
```

`?openExternalBrowser=1` を必ず付けたまま使ってください。これがないと、
InstagramやLINEのアプリ内ブラウザでMOSHのページが開かないことがあります。

## なぜQRコードを入れていないか

**ストーリーズやフィードを見ている人は、自分のスマホの画面をスキャンできません。**
SNSではリンクステッカーとプロフィールのリンクが正解です。

QRコードが要るのは、紙に印刷するポスター（`../poster/`）だけです。

## 作り直すとき

```sh
cd seminar/social
python3 build.py
```

`build.py` は中身が枠からはみ出していないか確認して表示します。
「→ OK」と出れば問題ありません。

- `story.html` / `feed.html` … それぞれの原稿
- `common.css` … 2枚共通の体裁
- `bg-story.jpg` / `bg-feed.jpg` … 背景写真（LPと同じもの）

### ストーリーズの安全余白について

上下250pxは、Instagramのアイコンや返信欄で隠れます。`story.html` の
`.in{ padding:250px 80px 260px }` がその余白です。**ここは詰めないでください。**
