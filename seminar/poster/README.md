## 申し込み情報（入力済み）

QRコードは `qr.png`。**印刷解像度（300dpi）から正しく読み取れることを確認済み**です。

URLに `?openExternalBrowser=1` を付けたまま入れています。LINEのQRリーダーで
読む人が多いため、アプリ内ブラウザではなく外部ブラウザで開かせるためです。
これがないと、MOSHのページが開かないことがあります。

### 直したいとき

クーポンコードは `poster.html` のこの行です。

```html
<p class="v">dekita01</p>
```

URLを変えた場合は、QRも作り直してください。

```sh
cd seminar/poster
python3 -c "import segno; segno.make('新しいURL', error='m').save('qr.png', scale=24, border=2, dark='#540E19', light='#FFFFFF')"
python3 build-pdf.py
```

`build-pdf.py` は中身と枠の高さを比べて、**はみ出していれば教えてくれます。**
「→ OK」と出ればA4 1ページに収まっています。

作り直したら、**必ずご自身のスマホで実際に読み取って確認**してください。

## 構成の意図

ジムの掲示は**立ち止まって3秒**で判断されます。その3秒で伝わるように、
上から順にこう並べています。

1. **誰に向けた話か**（練習では挙がるのに、試合で取り切れないパワーリフターへ）
2. **無料であること**（右上の丸。3,300円→0円と明記）
3. **いつ・どこで・いくら**（3つに区切った横帯）
4. **自分のことだと分かる6項目**（ここで止まった人が申し込みます）
5. **当日やること3つ**（何をするか分からない会には申し込めません）
6. **特典**
7. **誰がやるのか**
8. **申し込み方法**

パワーリフティング向けに、症状を競技の言葉にしてあります。
「3本目が、毎回こわい」は、この競技の人にしか書けない一行です。

## 印刷について

- **A4・等倍（100%）で印刷**してください。「フチなし」は使わないでください。
  縮小するとQRコードが読み取りにくくなります
- 白黒でも読めますが、右上の「無料」の丸が弱くなります。**できればカラー**で
- ジムの掲示板なら、A4のままで十分読めます。A3に拡大するとさらに目立ちます
