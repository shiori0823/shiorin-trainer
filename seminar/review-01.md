# 1. 手が止まった場所（3か所）

## ① WORK1「できたのかけら10個」

最初の1分で書けたのは **最大5個**。
「1個は書けますか？」まで下げて確認している。

**その後、6つの質問を出したら書けた。**

```
続けられたことはありますか？
辞められたことはありますか？
休むと決められたことはありますか？
誰かに頼れたことはありますか？
失敗した後にやったことはありますか？
以前より少しできるようになったことはありませんか？
```

→ **「10個」と言われて止まっている。質問があれば書ける。**
　 質問はあと出しではなく、**最初から紙に載せる。**

## ② WORK3「やらないことを決める」← いちばん止まった

「出てきましたか？」「あんまり思いつかないですか？」で沈黙。

**例を出したら動いた。** しかも動いた例が重要。

| 出した例 | 反応 |
|---|---|
| 夜更かし／携帯／練習後だらだら／セット間／飲み会（競技の例） | 山ピーが1つ（飲み会）、流星くんが1つ（ケアの妥協） |
| **皿洗い／トイレ掃除／離乳食（生活の例）** | **もっちさん「あ、そっか」→「出てきそうです」** |

もっちさんは最初にこう言っている。

> **「しないことを決めるのが本当に苦手で」**

→ **「やらないこと」は競技の中からは出てこない。生活の中から出る。**
　 練習のことだけ聞くと、止まる。

## ③ 目標の点数分け（120／100／80）

山ピーは100点に650kgと書いた。
試合ベストは610kg、**+40kg**。

その場で **レップベスト**（200kg×8発 など）を聞き出して換算し、
**「それは120点に置いた方がいい」** と組み替えている。

→ **本人が書いた数字だけでは分類できない。レップの記録が要る。**

# 2. チェックシートに入れるもの

記録から、入れるべきものがはっきりした。

| 入れるもの | なぜ |
|---|---|
| **6つの質問を印刷しておく** | 質問があれば書ける。「10個」だけでは書けない |
| **個数を10個にしない** | 5個で止まっている。3個＋追加欄にする |
| **やらないことの欄を「生活」と「競技」に分ける** | 生活の例でしか動かなかった |
| **「やめる」ではなく「置き換える」** | 下記 |
| **レップベストの記入欄**（重量×回数） | これがないと120／100／80を分けられない |
| **失敗した後の3つ**（何が起きたか／変えること／変えないこと） | 当日その場で使う唯一の部分 |

## ★「やめる」と書いてはいけない

もっちさんの質問が重要だった。

> **「辞めた自分を認められなくなりそう」**
> 「例えばその離乳食を作らない自分が許せないみたいな」

**やめることが、新しい自己否定になる。**
この講座が壊しにいっているものと同じものが、ここで生まれる。

しおりんさんの答えが正解だった。

> **「強くなる選手は、その時間に何をしてるかな」**

→ シートの欄名は **「やめること」ではなく「何に置き換えるか」** にする。
　 空いた時間に何が入るかまで書かせると、罪悪感が出ない。
