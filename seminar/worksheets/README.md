# セミナーの特典シート（A4・各1枚）

「できたのかけら」ワークショップの参加者にお渡しする2枚です。
スライドの51・52枚目で紹介しているものの実物です。

| ファイル | 特典 | 対応するWORK |
|---|---|---|
| `worksheet-01-dekita.pdf` | 01 できたのかけら 見つけるワークシート | WORK 1（20枚目） |
| `worksheet-02-tsunageru.pdf` | 02「できた」を結果につなげるチェックシート | 22〜23枚目の流れ |

**どちらもA4・1ページです。** そのまま印刷して配れます。

## 使い方

**セミナー中に配る場合**

WORK 1（20枚目）の直前に1枚目を配ってください。10本の罫線がそのまま
「できたのかけら10個」の記入欄になります。21枚目の質問リストは、シートの
下にも同じものを載せてあるので、手が止まった人はそこを見れば進めます。

2枚目は、セミナーの最後（50枚目の特典紹介）で「持ち帰り用」として
渡すのがおすすめです。セミナー中に全部書かせようとすると時間が足りません。

**あとから配る場合**

2枚をPDFのまま送れます。1枚目だけでも成立します。

## 中身

### 01 できたのかけら 見つけるワークシート

- 最近1か月の「できた」を書く罫線が10本
- 「ルールは1つ。『こんなの当たり前』は禁止です。」を冒頭に明記
- 下部に「手が止まったら、この質問を使ってください」8問
  （スライド21枚目の7問＋「予定を変えて、正解だったことは？」）
- メッセージ：**「できた」は、探せば増える。**

### 02「できた」を結果につなげるチェックシート

- 上部に「選んだ『できた』」の記入欄（10個から1つ選ぶ）
- 6つの質問。それぞれに小さなヒントを添えています
  1. 今回、何ができた？（事実だけを、そのまま）
  2. なぜ、できた？（運ではなく、理由を探す）
  3. 自分の、どんな力を使った？（「私は〇〇できる人だ」の形で）
  4. その力は、次の目標にも使える？（どの場面で使えそうか）
  5. 次に、何をする？
  6. 何を、やらない？
- メッセージ：**振り返りを、次の一本へ。**

5と6を横並びにしているのは、DO と DON'T をセットで決めてほしいからです
（35・36枚目と同じ考え方）。

## 作り直すとき

文言を変えたい場合は `sheet-01.html` / `sheet-02.html` を編集して、
PDFを作り直してください。

```sh
cd seminar/worksheets
python3 build-pdf.py
```

- `common.css` … 2枚共通の体裁（A4・余白・見出し・罫線）
- 配色はLP・スライドと同じワインレッド `#7A1524`
- 見出しは明朝、本文はゴシック

`build-pdf.py` は最後に本文の高さをmmで表示します。**297.1 と出れば1ページに
収まっています。** これより大きい数字が出たら2ページに割れているので、
文字数を減らすか罫線の高さを詰めてください。

## 印刷について

余白は上下14mm・左右15mmで作ってあります。家庭用プリンタの「フチなし」
設定は使わず、**等倍（100%）で印刷**してください。縮小されると罫線の
間隔が狭くなって書きにくくなります。
